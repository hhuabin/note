# 标签

1. 列出标签（`-l`）

   ```bash
   # 查看所有标签（按字母排序）
   git tag            # git tag -l 简写
   
   # 按字母倒序查看标签（-l可以省略）
   git tag -l --sort=-version:refname
   
   # 按创建时间顺序（-l可以省略）
   git tag -l --sort=creatordate
   
   # 按创建时间倒序(creatordate前面多了-)
   git tag -l --sort=-creatordate
   ```

   ```bash
   # 查看所有 v1 开头的标签：
   git tag -l "v1.*"
   
   git tag -l "*1.*"
   
   # 查找包含 beta 的标签
   git tag -l "*beta*"
   ```

   ```sql
   # 查看带提交信息的标签
   git tag -n
   ```

2. 创建标签

   ```bash
   git tag v1.0
   ```

3. 给指定版本创建标签

   ```bash
   git tag v1.0 commitHash
   ```

4. 查看特定标签

   ```bash
   git show v1.0
   ```

5. 删除标签

   ```bash
   git tag -d v1.0
   ```

6. 创建标签分支

   ```bash
   git checkout -b 'v1.0'
   ```

7. 推送指定分支

   ```bash
   git push origin v1.0
   ```

8. 推送所有分支

   ```bash
   git push origin --tags
   ```
