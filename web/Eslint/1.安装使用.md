# 三、`Vue` 版本

1.   安装

     ```shell
     npm i -D eslint, @eslint/js, globals, typescript-eslint, eslint-plugin-vue
     ```

2.   `TS` 适配

     ```shell
     npm i -D @typescript-eslint/parser @typescript-eslint/eslint-plugin
     ```

3.   手动创建 `eslint.config.js` 或 `.eslintrc.cjs` 配置文件，并在 `package.json` 的 `scripts` 里加一条 `"lint": "eslint . --report-unused-disable-directives --max-warnings 0"` 方便运行
