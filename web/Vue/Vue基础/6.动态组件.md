# 动态组件

有些场景会需要在两个组件间来回切换，比如 Tab 界面

```html
<component :is="tabs[currentTab]"></component>
```

传给 `:is` 的值可以是以下几种

1. 被注册的组件名（字符串）
2. 导入的组件对象



## 传入组件对象⭐（使用这个）

传入组件对象，直接渲染

```vue
<script setup>
import { ref, computed } from 'vue'

import Home from './components/Home.vue'
import User from './components/User.vue'
import Settings from './components/Settings.vue'

const current = ref('home')

const componentMap = {
    home: Home,
    user: User,
    settings: Settings
}

const currentComponent = computed(() => {
    return componentMap[current.value]
})
</script>

<template>
    <button @click="current = 'home'">
        首页
    </button>

    <button @click="current = 'user'">
        用户管理
    </button>

    <button @click="current = 'settings'">
        设置
    </button>

    <component :is="currentComponent" />
</template>
```



## 传入组件名

`Vue` 会根据这个名字去查找已经注册的组件；字符串 -> 根据名字查找组件 -> 找到 Home -> 渲染

```vue
<script setup>
import { ref } from 'vue'

import Home from './Home.vue'
import User from './User.vue'

const currentComponent = ref('Home')
</script>

<template>
    <div>
        <button @click="currentComponent = 'Home'">
            首页
        </button>

        <button @click="currentComponent = 'User'">
            用户
        </button>

        <component :is="currentComponent" />
    </div>
</template>
```



# `React` 实现动态组件的方式

把组件当成变量，然后用 `JSX` 渲染这个变量

```jsx
import { useState } from 'react'

import Home from './Home'
import User from './User'
import Settings from './Settings'

export default function App() {

    // 状态变化触发刷新，渲染新组件
    const [current, setCurrent] = useState('home')

    const componentMap = {
        home: Home,
        user: User,
        settings: Settings
    }

    const Component = componentMap[current]

    return (
    <>
        <button onClick={() => setCurrent('home')}>
            首页
        </button>

        <button onClick={() => setCurrent('user')}>
            用户管理
        </button>

        <button onClick={() => setCurrent('settings')}>
            设置
        </button>

        <Component />
    </>
    )
}
```
