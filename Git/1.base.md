# 基础

1. 初始化仓库

   ```bash
   git init
   ```

2. 暂存所有

   ```bash
   git add ./
   ```

3. 提交

   ```bash
   git commit -m 'commit'
   ```

4. 更改分支名

   ```bash
   git branch -M main
   ```

5. 创建仓库别名

   ```bash
   git remote add origin link
   ```

   ```bash
   git remote set-url origin <new_url>     # 重设仓库地址
   ```

   ```bash
   git remote rm 仓库别名                   # 删除仓库别名
   ```

6. 显示仓库 `url`

   ```bash
   git remote -v
   ```

7. 默认推送分支

   ```bash
   git push -u origin main
   ```

8. 查看哪些内容修改了

   ```bash
   git diff
   ```

   



## 推送

推送默认分支

```shell
git push
```

推送指定分支

```shell
git push origin branchName
```

拉取

```shell
git pull origin branchName
```

强制推送

```shell
git push --force
```



# 查看修改内容

1.   查看工作区（未提交）的修改

     ```bash
     git diff          # 已修改但未暂存的内容
     
     git diff --staged # 已暂存但未提交的内容（旧版用 --cached）
     ```

2.    查看提交的修改

     ```bash
     # 查看最近一次提交的修改
     git show
     
     # 查看某个提交的修改
     git show <commit-hash>
     ```

3.   查看某次提交改动了哪些文件

     ```bash
     git show --stat <commit-hash>
     ```

4.   查看两个提交之间的差异

     ```bash
     git diff <commit1> <commit2>
     ```

5.   查看某个文件的修改历史

     ```bash
     git log -p <文件名>       # 每次提交对该文件的改动
     git log --follow -p <文件名>  # 包含重命名历史
     ```

6.   查看某次提交中单个文件的改动

     ```bash
     git show <commit-hash>:<文件路径>
     ```

7.   常用组合

     ```bash
     git log --oneline          # 简洁的提交列表
     git log --stat             # 每次提交改了哪些文件及行数
     git log -p                 # 每次提交的完整 diff
     ```



# 版本信息

查看版本信息

```bash
git reflog
```

查看版本详细日志信息

```bash
git log
```

查看版本信息，一行显示

```bash
git log --oneline

# 过滤需要的提交信息
git log --oneline | grep 你好
```



# 用户信息

设置用户信息

```shell
git config --global user.name 用户名
git config --global user.email 用户邮箱

git config --global user.name huabin.huang
git config --global user.email huabin.huang.email.com
```

查看用户信息

```shell
git config --list
```
