# 枚举

```java
// 定义
enum Status {
    WAITING,
    SUCCESS,
    FAILED
}

// 使用
Status status = Status.SUCCESS;
if (status == Status.SUCCESS) {
    System.out.println("支付成功");
}
```



## 1.1 基本方法

| 方法              | 作用                              |
| ----------------- | --------------------------------- |
| `values()`        | 获取所有枚举值                    |
| `valueOf(String)` | 根据名称获取枚举值                |
| `name()`          | 获取枚举名称                      |
| `ordinal()`       | 获取枚举声明时的下标，从 `0` 开始 |
| `toString()`      | 返回枚举的字符串表示              |

```java
enum Status {
    WAITING,     // -> 0
    SUCCESS,     // -> 1
    FAILED       // -> 2
}

Status status = Status.valueOf("SUCCESS");

System.out.println(status);           // SUCCESS
```

```java
Status status = Status.SUCCESS;

System.out.println(status.name());     // SUCCESS
System.out.println(status.ordinal());  // 1
```



## 1.2 枚举可以定义成员变量

```java
enum Status {

    WAITING(0, "待支付"),
    SUCCESS(1, "支付成功"),
    FAILED(2, "支付失败");

    // 私有变量
    private final int code;
    private final String message;

    Status(int code, String message) {
        this.code = code;
        this.message = message;
    }

    // 公共方法，获取私有变量
    public int getCode() {
        return code;
    }

    public String getMessage() {
        return message;
    }
}
```

```java
// 使用
Status status = Status.SUCCESS;

System.out.println(status.getCode());        // 1
System.out.println(status.getMessage());     // 支付成功
```



## 1.3 遍历所有枚举值

```java
for (Status status : Status.values()) {
    System.out.println(status);
}

// WAITING
// SUCCESS
// FAILED
```



# 自定义枚举（看看就好）

```java
// 自定义枚举类
class MyEnumCity {
    public String name;
    public int code;

    private MyCity(String name, int code) {
        this.name = name;
        this.code = code;
    }

    public static final MyCity BEIJING = new MyCity("北京", 1001);
    public static final MyCity SHANGHAI = new MyCity("上海", 1002);
}

public static void main(String[] args) {
    System.out.println(MyCity.BEIJING.name);  // 北京
}
```
