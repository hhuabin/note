# 枚举

```java
// 定义
enum Status {
    WAITING,
    SUCCESS,
    FAILED
}

// 使用
Status status = Status.SUCCESS;
if (status == Status.SUCCESS) {
    System.out.println("支付成功");
}
```



## 1.1 基本方法

| 方法              | 作用                              |
| ----------------- | --------------------------------- |
| `values()`        | 获取所有枚举值                    |
| `valueOf(String)` | 根据名称获取枚举值                |
| `name()`          | 获取枚举名称                      |
| `ordinal()`       | 获取枚举声明时的下标，从 `0` 开始 |
| `toString()`      | 返回枚举的字符串表示              |

```java
enum City {
    BEIJING,     // -> 0
    SHANGHAI,    // -> 1
    GUANGZHOU,   // -> 2
    SHENZHEN     // -> 3
}

City city = City.valueOf("GUANGZHOU");
System.out.println(city);              // GUANGZHOU
```

```java
City city = City.SHANGHAI;

System.out.println(city.name());       // SHANGHAI
System.out.println(city.ordinal());    // 1
```



## 1.2 枚举可以定义成员变量

```java
enum City {

    BEIJING(1001, "北京"),
    SHANGHAI(1002, "上海"),
    GUANGZHOU(1003, "广州");

    // 私有变量
    private final int code;
    private final String name;

    City(int code, String name) {
        this.code = code;
        this.name = name;
    }

    // 公共方法，获取私有变量
    public int getCode() {
        return code;
    }

    public String getName() {
        return name;
    }
}
```

```java
public static void main(String[] args) {
    System.out.println(City.BEIJING.getCode()); // 1001
    System.out.println(City.BEIJING.getName()); // 北京

    System.out.println(City.SHANGHAI.getCode()); // 1002
    System.out.println(City.GUANGZHOU.getName()); // 广州
}
```



## 1.3 遍历所有枚举值

```java
for (City city : City.values()) {
    System.out.println(city);
}

// BEIJING
// SHANGHAI
// GUANGZHOU
// SHENZHEN
```



# 自定义枚举（看看就好）

```java
// 自定义枚举类
class MyEnumCity {
    public String name;
    public int code;

    private MyEnumCity(String name, int code) {
        this.name = name;
        this.code = code;
    }

    public static final MyEnumCity BEIJING = new MyEnumCity("北京", 1001);

    public static final MyEnumCity SHANGHAI = new MyEnumCity("上海", 1002);
}

public static void main(String[] args) {
    System.out.println(MyEnumCity.BEIJING.name); // 北京
}
```
