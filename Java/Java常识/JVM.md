# `JVM`、`JRE`、`JDK`

## 定义

- **`JDK（Java Development Kit）`：**

  `JDK` 是 `Java` 开发工具包，提供了 `Java` 程序开发和编译的所有工具和库

- **`JRE（Java Runtime Environment）`：**

  `JRE` 是 `Java` 运行时环境，用于在计算机上运行 `Java` 应用程序

- **`JVM（Java Virtual Machine）`：**

  `JVM` 是 `Java` 虚拟机，是 `Java` 程序运行的环境



## 关系

`JDK`包含 `JRE`，而 `JRE` 包含 `JVM`。

1. 开发人员使用 `JDK` 来编写、编译和调试 `Java` 应用程序，
2. 而终端用户则需要安装 `JRE` 来运行 `Java` 应用程序。
3. `JVM` 则是在运行时负责执行 `Java` 应用程序的核心组件
