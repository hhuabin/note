# 一、正则表达式

## 1.1 常用元字符

| 符号 | 含义                 | 说明                                            |
| ---- | -------------------- | ----------------------------------------------- |
| `^`  | 匹配字符串的开始位置 | 当 `^` 用在方括号 `[]` 内时，表示“除……之外”     |
| `$`  | 匹配字符串的结尾位置 | 匹配字符串末尾                                  |
| `\b` | 匹配单词边界         | 匹配单词与非单词字符之间的位置                  |
| `\B` | 匹配非单词边界       | 与 `\b` 相反                                    |
| `.`  | 任意字符             | 通常匹配除换行符以外的任意单个字符              |
| `\d` | digit，数字          | 等价于 `[0-9]`                                  |
| `\D` | 非数字               | 等价于 `[^0-9]`                                 |
| `\s` | 空格类字符           | 包括空格、制表符、换行等，例如 `[\t\n\x0B\f\r]` |
| `\S` | 非空格类字符         | 与 `\s` 相反                                    |
| `\w` | word，单词字符       | 通常等价于 `[a-zA-Z_0-9]`                       |
| `\W` | 非单词字符           | 与 `\w` 相反                                    |
| `g`  | 全局匹配             | 匹配所有符合条件的内容，而不是只匹配第一个      |
| `i`  | 忽略大小写           | 匹配时不区分大小写                              |



## 1.2 常用方括号表达式

| 表达式         | 含义                                       | 等价写法 / 说明   |
| -------------- | ------------------------------------------ | ----------------- |
| `[xyz]`        | 匹配 `x`、`y`、`z` 中任意一个字符          | —                 |
| `[^xyz]`       | 匹配除 `x`、`y`、`z` 之外的任意一个字符    | —                 |
| `[a-d]`        | 匹配 `a` ~ `d` 中任意一个字符              | 等价于 `[abcd]`   |
| `[a-zA-Z]`     | 匹配 `a` ~ `z` 或 `A` ~ `Z` 中任意一个字符 | —                 |
| `[a-d[m-q]]`   | 匹配 `a` ~ `d` 或 `m` ~ `q` 中任意一个字符 | 等价于 `[a-dm-q]` |
| `[a-z&&[def]]` | 匹配 `a` ~ `z` 与 `def` 的交集             | 等价于 `[def]`    |
| `[a-f&&[^de]]` | 匹配 `a` ~ `f` 中除 `d`、`e` 外的字符      | 等价于 `[abcf]`   |



## 1.3 常用限定字符

| 表达式   | 含义                  | 等价写法 / 说明 |
| -------- | --------------------- | --------------- |
| `X?`     | `X` 最多出现 1 次     | 等价于 `X{0,1}` |
| `X*`     | `X` 出现 0 次或多次   | 等价于 `X{0,}`  |
| `X+`     | `X` 出现 1 次或多次   | 等价于 `X{1,}`  |
| `X{n}`   | `X` 恰好出现 `n` 次   | —               |
| `X{n,}`  | `X` 至少出现 `n` 次   | —               |
| `X{n,m}` | `X` 出现 `n` ~ `m` 次 | —               |
| `X|Y`    | 匹配 `X` 或 `Y`       | 二选一          |



## 1.4 量词总结

| 量词    | 含义        |
| ------- | ----------- |
| `?`     | `0 ~ 1` 次  |
| `*`     | `0 ~ ∞` 次  |
| `+`     | `1 ~ ∞` 次  |
| `{n}`   | 恰好 `n` 次 |
| `{n,}`  | 至少 `n` 次 |
| `{n,m}` | `n ~ m` 次  |
| `|`     | 或          |



# 二、正则表达式应用

```tex
Java 的正则校验流程：正则字符串(String)  --编译(compile)-->  Pattern对象  --匹配-->  Matcher对象  --> 结果
```

>   关于和 `js` 的差别：`js` 的预编译不在代码中体现 `const PHONE_REGEX = /^1[3-9]\\d{9}$/` 定义的时候顺便预编译了

```java
// matches 方法源码
public static boolean matches(String regex, CharSequence input) {
    // 编译正则（compile）
    Pattern p = Pattern.compile(regex);
    // 创建 Matcher 匹配器
    Matcher m = p.matcher(input);
    // 整体匹配
    return m.matches();
}
```

>   工作流程
>
>   ```tex
>      正则字符串,如 "1[3-9]\\d{9}"
>           │
>           │  Pattern.compile(regex)   ← 编译（把文字变成机器能执行的规则）
>           ▼
>      ┌─────────────┐
>      │   Pattern   │  ← 编译产物：一条"规则"，与具体文本无关，可反复复用
>      └─────────────┘
>           │
>           │  pattern.matcher(text)    ← 绑定一段具体文本，产出执行器
>           ▼
>      ┌─────────────┐
>      │   Matcher   │  ← 执行器：持有 Pattern + 文本，负责真正比对、提取、替换
>      └─────────────┘
>           │
>           │  matches() / find() / group() / replaceAll()
>           ▼
>         匹配结果
>   ```



## 2.1 `Pattern` 编译类

| 方法                            | 作用                                            | 示例                                   |
| :------------------------------ | :---------------------------------------------- | :------------------------------------- |
| `Pattern.compile(String regex)` | 把正则字符串编译成 `Pattern` 对象（最核心入口） | `Pattern p = Pattern.compile("\\d+");` |
|                                 |                                                 |                                        |



## 2.2 `Matcher` 匹配器类

| 方法        | 作用                                     | 示例          |
| :---------- | :--------------------------------------- | :------------ |
| `matches()` | 判断**整串**是否完全匹配（隐含 `^...$`） | `m.matches()` |
|             |                                          |               |



# 三、字符串正则使用

1.   正则校验字符串

     ```java
     String phone = "13812345678";
     
     // 校验手机号格式（matches 方法里面调用了 Pattern）
     boolean valid = phone.matches("^1[3-9]\\d{9}$");
     
     System.out.println(valid); // true
     ```

     >   关于正则预编译的问题：其实只要不在循环里面不断的 `matches` 有没有预编译其实影响不大，不用太在意

2.   正则分隔

     ```java
     String str = "abc";
     
     str.split("\\d")            // 根据数字对字符串进行分割
     ```

     

# 四、正则工具类

1.   正则表达式

     `constant.RegexConstants`

     ```java
     public class RegexConstants {
     
         /** 常量类，禁止实例化 */
         private RegexConstants() {}
     
         /** 身份证号码正则 */
         public static final String IDNO_STR = "^([1-6][1-9]|50)\\d{4}(19|20)\\d{2}((0[1-9])|1[0-2])(([0-2][1-9])|10|20|30|31)\\d{3}[0-9Xx]$";
     
         /** 手机号正则 */
         public static final String PHONE_STR = "^(13[0-9]|14[01456879]|15[0-35-9]|16[2567]|17[0-8]|18[0-9]|19[0-35-9])\\d{8}$";
     
         /** 邮箱正则 */
         public static final String EMAIL_STR = "^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$";
     
         /** 身份证号码正则（预编译） */
         public static final Pattern IDNO = Pattern.compile(IDNO_STR);
     
         /** 手机号正则（预编译） */
         public static final Pattern PHONE = Pattern.compile(PHONE_STR);
     
         /** 邮箱正则（预编译） */
         public static final Pattern EMAIL = Pattern.compile(EMAIL_STR);
     
     }
     ```

2.   正则校验类

     `utils.RegexUtils`

     ```java
     public final class RegexUtils {
     
         /** 工具类，禁止实例化 */
         private RegexUtils() {}
     
         /**
          * 判断指定字符串是否完全匹配给定的正则表达式
          *
          * @param value 待校验的字符串
          * @param regex 正则表达式
          */
         public static boolean matches(String value, String regex) {
             return value != null && Pattern.matches(regex, value);
         }
     
         /**
          * 校验是否为合法的 18 位身份证号码
          */
         public static boolean isIdNo(String value) {
             return value != null && RegexConstants.IDNO.matcher(value).matches();
         }
     
         /**
          * 校验是否为合法的大陆手机号
          */
         public static boolean isMobile(String value) {
             return value != null && RegexConstants.PHONE.matcher(value).matches();
         }
     
         /**
          * 校验是否为合法的邮箱地址
          */
         public static boolean isEmail(String value) {
             return value != null && RegexConstants.EMAIL.matcher(value).matches();
         }
     
     }
     ```

3.   使用正则类

     ```java
     boolean phoneValid = RegexUtils.isMobile("13812345678");
     ```
