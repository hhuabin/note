# 常用元字符

| 符号 | 含义                 | 说明                                            |
| ---- | -------------------- | ----------------------------------------------- |
| `^`  | 匹配字符串的开始位置 | 当 `^` 用在方括号 `[]` 内时，表示“除……之外”     |
| `$`  | 匹配字符串的结尾位置 | 匹配字符串末尾                                  |
| `\b` | 匹配单词边界         | 匹配单词与非单词字符之间的位置                  |
| `\B` | 匹配非单词边界       | 与 `\b` 相反                                    |
| `.`  | 任意字符             | 通常匹配除换行符以外的任意单个字符              |
| `\d` | digit，数字          | 等价于 `[0-9]`                                  |
| `\D` | 非数字               | 等价于 `[^0-9]`                                 |
| `\s` | 空格类字符           | 包括空格、制表符、换行等，例如 `[\t\n\x0B\f\r]` |
| `\S` | 非空格类字符         | 与 `\s` 相反                                    |
| `\w` | word，单词字符       | 通常等价于 `[a-zA-Z_0-9]`                       |
| `\W` | 非单词字符           | 与 `\w` 相反                                    |
| `g`  | 全局匹配             | 匹配所有符合条件的内容，而不是只匹配第一个      |
| `i`  | 忽略大小写           | 匹配时不区分大小写                              |



# 常用方括号表达式

| 表达式         | 含义                                       | 等价写法 / 说明   |
| -------------- | ------------------------------------------ | ----------------- |
| `[xyz]`        | 匹配 `x`、`y`、`z` 中任意一个字符          | —                 |
| `[^xyz]`       | 匹配除 `x`、`y`、`z` 之外的任意一个字符    | —                 |
| `[a-d]`        | 匹配 `a` ~ `d` 中任意一个字符              | 等价于 `[abcd]`   |
| `[a-zA-Z]`     | 匹配 `a` ~ `z` 或 `A` ~ `Z` 中任意一个字符 | —                 |
| `[a-d[m-q]]`   | 匹配 `a` ~ `d` 或 `m` ~ `q` 中任意一个字符 | 等价于 `[a-dm-q]` |
| `[a-z&&[def]]` | 匹配 `a` ~ `z` 与 `def` 的交集             | 等价于 `[def]`    |
| `[a-f&&[^de]]` | 匹配 `a` ~ `f` 中除 `d`、`e` 外的字符      | 等价于 `[abcf]`   |



# 常用限定字符

| 表达式   | 含义                  | 等价写法 / 说明 |
| -------- | --------------------- | --------------- |
| `X?`     | `X` 最多出现 1 次     | 等价于 `X{0,1}` |
| `X*`     | `X` 出现 0 次或多次   | 等价于 `X{0,}`  |
| `X+`     | `X` 出现 1 次或多次   | 等价于 `X{1,}`  |
| `X{n}`   | `X` 恰好出现 `n` 次   | —               |
| `X{n,}`  | `X` 至少出现 `n` 次   | —               |
| `X{n,m}` | `X` 出现 `n` ~ `m` 次 | —               |
| `X|Y`    | 匹配 `X` 或 `Y`       | 二选一          |

## 量词总结

| 量词    | 含义        |
| ------- | ----------- |
| `?`     | `0 ~ 1` 次  |
| `*`     | `0 ~ ∞` 次  |
| `+`     | `1 ~ ∞` 次  |
| `{n}`   | 恰好 `n` 次 |
| `{n,}`  | 至少 `n` 次 |
| `{n,m}` | `n ~ m` 次  |
| `|`     | 或          |
