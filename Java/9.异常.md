# 一、`Exception`

```java
// Exception 继承于 Throwable
public class Exception extends Throwable {}
```



 ## 1.1 `Exception` 常用构造方法

- **`Exception`**类源码只有构造方法，普通方法继承自 `Throwable`

```java
public Exception() {
    super();
}

public Exception(String message) {
    super(message);
}
```



## 1.2 `Throwable` 常用构造方法

```java
public Throwable() {
	fillInStackTrace();
}

public Throwable(String message) {
    fillInStackTrace();
    detailMessage = message;
}

public Throwable(String message, Throwable cause) {
    fillInStackTrace();
    detailMessage = message;
    this.cause = cause;
}
```



## 1.3 `Throwable` 类常用的方法

| 方法                                         | 说明                                                         |
| -------------------------------------------- | ------------------------------------------------------------ |
| `public String getMessage()`                 | 返回描述该异常对象的信息                                     |
| `public String toString()`                   | 返回描述当前 `Exception` 类信息的字符串，包含**异常类的全名**、**冒号（`:`）**和 `getMessage()` 返回的信息 |
| `public void printStackTrace()`              | 输出程序执行过程中调用的方法调用链，即异常发生时的**堆栈信息** |
| `public StackTraceElement[] getStackTrace()` | 返回与该异常对象相关的**堆栈信息数组** `StackTraceElement[]` |

```java
public String getMessage() {
    return detailMessage;
}

public void printStackTrace() {
    printStackTrace(System.err);
}

public StackTraceElement[] getStackTrace() {
    return getOurStackTrace().clone();
}
```



# 二、异常的基本使用

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println(e.getMessage());   // 输出异常对象的信息
    System.out.println(e.toString());     // 输出异常信息的字符串
    e.printStackTrace();                  // 输出异常堆栈信息
}
```



## 2.1 方法中声明 可能 抛出异常

| 关键字   | 作用                                                         |
| -------- | ------------------------------------------------------------ |
| `throw`  | **真正抛出**一个异常对象                                     |
| `throws` | **声明**方法 可能 抛出哪些异常<br />（是可能抛，不是一定抛，方法完全可以正常执行的） |

```java
public static void test() throws Exception {
    if (true) {
        throw new Exception("出错了");
    }
    // 正常执行
}
```



## 2.2 自定义异常

```java
public class AgeException extends RuntimeException {

    public AgeException(String message) {
        super(message);
    }
}
```

```java
public static void checkAge(int age) {

    if (age < 18) {
        // throw 抛出异常
        throw new AgeException("年龄不能小于18岁");
    }
}

try {
    checkAge(15);
} catch (AgeException e) {
    System.out.println(e.getMessage());     // 年龄不能小于18岁
}
```
