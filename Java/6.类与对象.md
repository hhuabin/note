# 一、类 修饰符

| 修饰符            | 作用                                 | 示例                               |
| ----------------- | ------------------------------------ | ---------------------------------- |
| `public`          | 类可以被其他包访问                   | `public class User {}`             |
| `缺省`（不写）    | 只能被同一个包访问                   | `class User {}`                    |
| `abstract`        | 抽象类，只能被继承，不能直接创建对象 | `abstract class Animal {}`         |
| `final`           | 最终类，不能被继承                   | `final class StringUtil {}`        |
| `public abstract` | 公共抽象类                           | `public abstract class Animal {}`  |
| `public final`    | 公共最终类                           | `public final class StringUtil {}` |



# 二、成员变量修饰符

| 修饰符         | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| `public`       | 公共变量，可以被任何对象访问                                 |
| `private`      | 私有变量，只能自己访问，**子类也不可访问**                   |
| `protected`    | 保护变量，只能**自己及其子类访问**，在相同包下也能访问，可以被子类**覆盖** |
| `缺省`（不写） | 不写访问修饰符，在同一个包 `package` 下才能访问              |
| `final`        | 最终修饰符，**只能赋值一次**，赋值后不能再次修改             |
| `static`       | 静态变量，被所有对象共享，即所有的实例类都能调用，可以被继承 |
|                |                                                              |
| `transient`    | 过度修饰符，指定是系统保留变量，暂无别的作用的临时性变量     |
| `volatitle`    | 易失修饰符，指定该变量可以同时被多个线程控制修改             |

除 `private` 私有变量外都可以被继承

# 三、成员方法修饰符

| 修饰符         | 说明                                                     |
| -------------- | -------------------------------------------------------- |
| `public`       | 公共方法，可以被任何对象访问                             |
| `private`      | 私有方法，只能自己访问，**子类也不可访问**               |
| `protected`    | 保护方法，只能**自己及其子类访问**，在相同包下也能访问   |
| `缺省`（不写） | 不写访问修饰符，在同一个包 `package` 下才能访问          |
| `final`        | 最终修饰符，**不能被子类重写（`Override`）**             |
| `static`       | 静态方法，被所有对象共享，即所有的实例类都能调用         |
|                |                                                          |
| `abstract `    | 抽象方法，子类必须实现                                   |
| `synchronized` | 同步修饰符，施加同步锁，防止其他线程访问，运行结束后解锁 |
| `native`       | 本地修饰符，指定该方法是用其他语言（如C）外部编写的      |

除 `private` 私有方法外都可以被继承



# 四、`static` 静态成员

>   被 `static` 修饰的成员成为静态成员，让成员“属于类”，而不是属于对象
>
>   静态方法只能访问**静态变量**或者**静态方法**

```java
class User {

    static int count = 0;

    // 静态方法只能访问 静态变量 或者 静态方法
    static int add(int a, int b) {
        return a + b;
    }
}
```

访问方式：

1.  `类名.静态变量名`（建议使用这个）

    ```java
    User.count++;
    
    User.add(1, 2);
    ```

2.  对象名.静态变量名

    ```java
    User user = new User();
    
    System.out.println(user.count);   // 0
    user.add(1, 2);
    ```



## 4.1 `static` 变量可以被继承

1.   `static`  变量继承

     ```java
     class Parent {
         static int A = 10;
     }
     
     class Child extends Parent {}
     
     System.out.println(Child.A); // 10
     ```

2.   子类定义与父类同名的 `static` 变量（字段隐藏）以子类为准

     子类可以把父类的 `static` 字段隐藏掉，只有访问父类才可以访问到

     ```java
     class Parent {
         static int A = 10;
     }
     
     class Child extends Parent {
         static int A = 20;
     }
     
     System.out.println(Parent.A); // 10
     System.out.println(Child.A);  // 20
     ```

     对比没有`static`的情况

     ```java
     class Parent {
         int A = 10;
     }
     
     class Child extends Parent {
         int A = 20;
     }
     
     Parent p = new Child();
     System.out.println(p.A);   // 20
     ```



## 4.2 `static` 方法可以被继承

1.   方法继承

     ```java
     class Parent {
     
         public static void sayHello() {
             System.out.println("Hello Parent");
         }
     }
     
     class Child extends Parent {
     }
     
     Child.sayHello();       // Hello Parent
     ```

2.   子类定义与父类同名的 `static` 方法（方法隐藏）以子类为准

     ```java
     class Parent {
     
         public static void sayHello() {
             System.out.println("Parent");
         }
     }
     
     class Child extends Parent {
     
         public static void sayHello() {
             System.out.println("Child");
         }
     }
     ```

     ```java
     Parent.sayHello();        // Parent
     Child.sayHello();         // Child
     ```

     



## 4.3 静态初始化器 `static {}`

```java
public class Test {

    // 静态初始化器
    static {
        System.out.println("静态代码块");
    }

    public Test() {
        System.out.println("构造方法");
    }
}
```

1.   执行时机：只在创建类时执行，创建实例类不执行，即与创建多少个实例化对象无关

     ```java
     Test t1 = new Test();
     Test t2 = new Test();
     
     // 静态代码块
     // 构造方法
     // 构造方法
     ```

2.   用法：静态初始化器（`static {}`）并没有特别高频，一般只类加载时，需要执行一些“一次性、比较复杂”的静态初始化逻辑

     >   开发中用的很少

     ```java
     public class Config {
     
         public static Map<String, String> config;
     
         // 初始化静态集合
         static {
             config = new HashMap<>();
             config.put("name", "Java");
             config.put("version", "21");
             config.put("env", "dev");
         }
     }
     ```



# 五、`final`最终成员

👉 **让东西“不能被改变 / 不能被重写 / 不能被继承（`final` 类不可以被继承，变量和方法都可以被继承）”**

`final` 只能赋值一次，本质是常量，限制的是**“引用不变”**

```java
final int a = 10;
```

```java
final List<String> list = new ArrayList<>();
list.add("a");              // ✅
list = new ArrayList<>();   // ❌
```



## 5.1 `final` 变量可以被继承

1.   变量继承

     ```java
     class Parent {
         final int A = 10;
     }
     
     class Child extends Parent {}
     
     Child c = new Child();
     System.out.println(c.A); // 10
     ```

2.   子类 `final` 同名变量（隐藏父类变量）以子类为准

     两个类中的 `A` 是两块独立内存

     ```java
     class Parent {
         final int A = 10;
     }
     
     class Child extends Parent {
         // 可以定义同名的 变量
         final int A = 20;
     }
     ```

     ```java
     Child c = new Child();
     System.out.println(((Parent)c).A);  // 10
     System.out.println(c.A);            // 20
     ```



## 5.2 `final`方法可以被继承

1.   方法继承

     ```java
     class Parent {
         final void test() {
             System.out.println("Parent");
         }
     }
     
     class Child extends Parent {}
     
     Child c = new Child();
     c.test();          // ✅
     ```

2.   子类不可以定义  `final` 同名方法

     `final` 方法继承中不可以被重写/隐藏

     ```java
     class Parent {
         final void test() {
             System.out.println("Parent");
         }
     }
     
     // 子类不能重写
     class Child extends Parent {
         final void test() {              // ❌
             System.out.println("Parent");
         }
     }
     ```
