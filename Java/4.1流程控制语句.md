# 一、`if`

```java
public static void main(String[] args) {

    int score = 85;

    if (score >= 90) {
        System.out.println("优秀");
    } else if (score >= 80) {
        System.out.println("良好");
    } else if (score >= 60) {
        System.out.println("及格");
    } else {
        System.out.println("不及格");
    }
}
```



# 二、`switch`

```java
switch (表达式) {
    case 值1:
        // 表达式匹配值1时执行
        break;

    case 值2:
        // 表达式匹配值2时执行
        break;

    case 值3:
        // 表达式匹配值3时执行
        break;

    default:
        // 所有 case 都不匹配时执行
        break;
}
```

```java
public static void main(String[] args) {

        int num = 1;

        switch (num) {
            case 1:
                System.out.println("星期一");

            case 2:
                System.out.println("星期二");

            case 3:
                System.out.println("星期三");
                break;

            default:
                System.out.println("其他日期");
                break;
        }
    }
```



# 三、`while`

1.   基本使用

     ```java
     while (i < 5) {
         System.out.println(i);
         i++;
     }
     ```

2.   `do-while`

     先执行循环体，再判断条件，至少执行一次

     ```java
     do {
         // 循环体
     } while (循环条件);
     ```

     

# 四、三目运算符

`条件表达式 ? 表达式1 : 表达式2;`

```java
int age = 20;

String result = age >= 18 ? "成年人" : "未成年人";

System.out.println(result);   // 成年人
```
