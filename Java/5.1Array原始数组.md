## 2.4`Arrays.asList()`（`Integer[]` -> `List<Integer>`）

`Arrays.asList`返回值：返回的是一个固定长度的 `List`，不能使用 `add` 和 `remove` 等方法

  ```java
Integer[] arr = {1, 2, 3};

List<Integer> list = Arrays.asList(arr);

// List 可以修改元素，但不能增加、删除元素
list.set(0, 10);
  ```

  ```java
// 把固定数组变成可变数组
Integer[] arr = {1, 2, 3};

List<Integer> arrays = Arrays.asList(arr);
List<Integer> list = new ArrayList<>(arrays);
// List<Integer> list = new ArrayList<>(Arrays.asList(arr));
  ```

  >   **`Arrays.asList()` 方法不适用于基本数据类型的数组**。比如 `int[]`、`double[]`、`char[]` 等，具体查看泛型章节
  >
  >   该方法只适用于对象类型的数组，因为它返回的是一个泛型列表。只适用于类似 `Integer[]` 的



## 2.5 `int[]` 转 `List<Integer>`

`int[]` **不能直接**通过 `Arrays.asList()` 转成 `List<Integer>`，因为 `int` 是基本类型。开发中遇到该情况的也少，如果需要 `List<Integer>`，直接把原数组改成 `Integer[]` 更好

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

int[] arr = {1, 2, 3, 4};

List<Integer> list = Arrays.stream(arr)    // int[] → IntStream
        .boxed()                           // int → Integer
        .collect(Collectors.toList());     // Stream<Integer> → List<Integer>
```



# 三、`System.arraycopy()` 原始数组合并

`System.arraycopy()` 是 `Java` 中用于复制数组的方法

```java
public static void arraycopy(Object src, int srcPos, Object dest, int destPos, int length);
```

```java
System.arraycopy(
    原数组,
    原数组开始位置,
    目标数组,
    目标数组开始位置,
    复制长度
);
```

使用 `System.arraycopy()`

```java
可以
public class MergeArrays {
    public static void main() {
        int[] arr1 = {1, 2, 3};
        int[] arr2 = {4, 5, 6};

        int[] result = new int[a.length + b.length];

        System.arraycopy(a, 0, result, 0, a.length);        // 复制 arr1
		System.arraycopy(b, 0, result, a.length, b.length); // 复制 arr2
        
        // 输出合并后的数组
        for (int num : result) {
            System.out.print(num + " ");    // 1 2 3 4 5 6
        }
    }
}
```



## `concat utils` 封装方法

```java
public class ArrayUtils {

    /**
     * 合并两个 int 数组
     *
     * @param arr1 第一个数组
     * @param arr2 第二个数组
     * @return 合并后的新数组
     */
    public static int[] concat(int[] arr1, int[] arr2) {
        int[] result = new int[arr1.length + arr2.length];

        System.arraycopy(arr1, 0, result, 0, arr1.length);
        System.arraycopy(arr2, 0, result, arr1.length, arr2.length);

        return result;
    }
}

// 调用： int[] result = ArrayUtils.concat(arr1, arr2);
```
