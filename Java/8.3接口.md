# `interface` 接口

接口具有**数据成员**、**抽象方法**、**私有方法**、**静态方法**、**默认方法**。但是不能定义一般方法，默认是**抽象方法**

```java
[public] interface 接口名 [extends] {
    // 1. 数据成员
    [public] [static] [final] 数据类型 常量名 = 常量;
    
    // 2. 抽象方法；没有方法体
    [public] [abstract] 返回类型 方法名(参数表);

    // 3. 私有方法，必须有方法体
    private 返回类型 方法名(参数表) {
        方法体
    }

    // 4. 静态方法，必须有方法体
    [public] static 返回类型 方法名(参数表) {
        方法体
    }

    // 5. 默认方法，必须有方法体
    [public] default 返回类型 方法名(参数表) {
        方法体
    }
}
```

1.  修饰符：抽象方法修饰符 `public abstract` 可以省略

    ```java
    public interface Demo {
        // 以下三种写法是等价的
        Order getUser();
    
        public Order getUser();
    
        public abstract Order getUser();
    }
    ```

2.  方法体：**私有方法**、**静态方法**、**默认方法** 必须有方法实现，即方法体，只有抽象方法没有

3.  成员变量：接口可以有成员变量，但是变量必须是**静态常量**且必须赋值，默认前缀名为 `public static final`

    ```java
    public interface Demo {
        // 以下写法是等价的
        int MAX = 100;
    
        public static final int MAX = 100;
    }
    ```

4.  **接口方法不能是** `protected`、`final`（抽象方法）、`synchronized`、`native`



## 1.1 数据成员

默认前缀名为 `public static final`



## 1.2 `public abstract` 抽象方法

```java
interface MyInterface {
    public abstract Order getUser();
}
```

1.   抽象方法必须被类实现



## 1.3 `private` 私有方法（内部方法调用）

1.  定义：私有方法在接口中使用 `private` 关键字定义
2.  调用：**私有方法不能在接口外部被调用**，只能在接口的默认方法或静态方法内部使用
3.  用法：这些方法主要用于在接口内部重用代码，避免代码重复

```java
interface MyInterface {
    default void defaultMethod() {
        // 调用私有方法
        privateMethod();
    }

    private void privateMethod() {
        System.out.println("Private method in interface.");
    }
}
```



## 1.4 `static` 静态方法（不可以继承）

1.  定义：静态方法在接口中使用 `static` 关键字定义
2.  调用：这些方法可以直接通过接口名称调用，无需实例化接口
3.  不能继承：静态方法不能被**子接口**继承，也不能被**实现类**继承。(即不能被继承)
4.  用法：静态方法主要用于提供与接口相关的工具方法或功能

调用： 接口名.静态方法名()

```java
interface MyInterface {
    public static void staticMethod() {
        System.out.println("Static method in interface.");
    }
}

// 调用静态方法
MyInterface.staticMethod();
```



## 1.5 `default` 默认方法（可以继承/重写）

1.  定义：默认方法在接口中使用 `default` 关键字定义
2.  可以继承：默认方法可以被**子接口**继承，也能被**实现类**继承。(即永远被继承)
3.  可以重写：默认方法可以被重写，子接口或实现类定义同名方法即可

调用：`对象名.默认方法名()`

```java
interface MyInterface {
    public default void defaultMethod() {
        System.out.println("Default method in interface.");
    }
}

// 实现接口并调用默认方法
class MyClass implements MyInterface {
    public static void main(String[] args) {
        MyClass obj = new MyClass();
        obj.defaultMethod();
    }
}
```



# :star: 抽象类 vs 接口

| 对比         | 抽象类           | 接口                         |
| ------------ | ---------------- | ---------------------------- |
| 是否能有实现 | ✅ 可以           | ✅（default/static）          |
| 成员变量     | ✅ 可以有普通变量 | ❌ 只能 `public static final` |
| 构造函数     | ✅ 有             | ❌ 没有                       |
| 继承         | 单继承           | 多实现                       |
| 适用场景     | 有“共性代码”     | 纯规范                       |
