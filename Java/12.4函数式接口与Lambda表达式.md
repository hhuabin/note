# 函数式接口

函数式接口：有且只有一个抽象方法的接口

### `Java` 标准库提供的常用函数式接口模板

| 接口            | 参数 | 返回值    | 抽象方法    | 常见用途  | `Lambda`          |
| --------------- | ---- | --------- | ----------- | --------- | ----------------- |
| `Consumer<T>`   | 1个  | 无        | `accept(T)` | 消费/处理 | `x -> {}`         |
| `Supplier<T>`   | 0个  | 1个       | `get()`     | 提供数据  | `() -> x`         |
| `Function<T,R>` | 1个  | 1个       | `apply(T)`  | 转换      | `x -> y`          |
| `Predicate<T>`  | 1个  | `boolean` | `test(T)`   | 判断      | `x -> true/false` |

1.   `Consumer` 源码

     ```java
     @FunctionalInterface  // 指定该接口必须是函数式接口
     public interface Consumer(T) {
         void accept(T t);
     }
     ```

     ```java
     // 使用
     Consumer<String> consumer = name -> System.out.println(name);
     consumer.accept("张三");
     ```

2.   `Supplier<T>` 源码

     ```java
     @FunctionalInterface
     public interface Supplier<T> {
         T get();
     }
     ```

     ```java
     // 使用
     Supplier<String> supplier = () -> "Hello";
     
     String result = supplier.get();
     
     System.out.println(result);
     ```

3.   `Function<T,R>` 源码

     ```java
     @FunctionalInterface
     public interface Function<T, R> {
         R apply(T t);
     }
     ```

     ```java
     // 使用
     Function<String, Integer> function = name -> name.length();
     
     Integer result = function.apply("张三");
     
     System.out.println(result);
     ```

4.   `Predicate<T>` 源码

     ```java
     @FunctionalInterface
     public interface Predicate<T> {
         boolean test(T t);
     }
     ```

     ```java
     // 使用
     Predicate<Integer> predicate = age -> age >= 18;
     
     boolean result = predicate.test(20);
     
     System.out.println(result);
     ```



# `Lambda` 表达式

`Lambda` 表达式是 `Java 8` 引入的一项重要特性，用于简化代码编写，特别是在函数式编程中。**`Lambda` 表达式可以看作是一种匿名函数**，它可以替代某些使用匿名内部类的情况

```java
Consumer con = new Consumer<String>() {
    @Override
    public void accept(String s) {
        System.out.println(s);
    }
};
con.accept("你好");
```

```java
// 简写
Consumer<String> con = (s) -> System.out.println(s);
con.accept("你好");

// 方法引用
Consumer<String> con = System.out::println
con.accept("你好");
```



1. **无参数的 `Lambda` 表达式：**

   ```java
   () -> System.out.println("Hello Lambda!");
   ```

2. **有参数的 `Lambda` 表达式：**

   ```java
   (int x, int y) -> x + y
   ```

3. **`Lambda` 表达式作为变量：**

   ```java
   BinaryOperator<Integer> sum = (a, b) -> a + b;
   ```

4. **`Lambda` 表达式与集合的结合：**

   ```java
   List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
   names.forEach(name -> {         // 多行执行需要添加 {}
       System.out.println(name);
       System.out.println("处理完成");
   });
   ```

   ```java
   List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
   for (String name : names) {
       System.out.println(name);
       System.out.println("处理完成");
   }
   ```

5. **方法引用：**

   ```java
   List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
   names.forEach(System.out::println);
   ```




### 1.`Consumer` 类的 `Lambda` 表达式

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

names.forEach(name -> {
    System.out.println("姓名：" + name);
    System.out.println("处理完成");
});
```



### 2.`Supplier` 类的 `Lambda` 表达式

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

List<Integer> lengths = names.stream()
        .map(name -> {
            System.out.println("处理：" + name);
            return name.length();
        })
        .toList();
```



### 3.`Function` 类的 `Lambda` 表达式

```java
List<Integer> ages = Arrays.asList(15, 18, 20, 25);

List<Integer> adults = ages.stream()
        .filter(age -> {
            System.out.println("检查：" + age);
            return age >= 18;
        })
        .toList();
```



### 4.`Predicate` 类的 `Lambda` 表达式

```java
Optional<String> name = Optional.empty();

String result = name.orElseGet(() -> {
    System.out.println("没有姓名，生成默认值");
    return "未知用户";
});
```



### 5.`Comparator` 类的 `Lambda` 表达式

```java
List<Integer> numbers = Arrays.asList(
        5, 2, 8, 1, 3
);

numbers.sort((a, b) -> a - b);
```



# 自定义方法接收 `Lambda` 表达式

1.   定义方法

     ```java
     public static void myForEach(
             List<String> list,
             Consumer<String> action
     ) {
         for (String item : list) {
             action.accept(item);
         }
     }
     ```

2.   调用方法

     ```java
     List<String> names = Arrays.asList(
         "Alice",
         "Bob",
         "Charlie"
     );
     
     myForEach(names, name -> {
         System.out.println(name);
         System.out.println("处理完成");
     });
     ```
