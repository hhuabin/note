# 一、`Java 8` 日期类

`Java 8` 日期时间 `API` 中比较常用的类：

| 类              | 作用                     | 示例                     |
| --------------- | ------------------------ | ------------------------ |
| `LocalDate`     | 日期，不包含时间         | `2026-11-27`             |
| `LocalTime`     | 时间，不包含日期         | `09:30:00`               |
| `LocalDateTime` | 日期和时间，不包含时区   | `2026-11-27T09:30:00`    |
| `Instant`       | 时间线上的一个时间点     | `UTC` 时间戳             |
| `ZonedDateTime` | 带时区的日期时间         | `2026-11-27T09:30+08:00` |
| `ZoneId`        | 时区标识                 | `Asia/Shanghai`          |
| `Period`        | 日期间隔（年、月、日）   | `2年3个月`               |
| `Duration`      | 时间间隔（时、分、秒等） | `2小时30分钟`            |
| `Year`          | 年份                     | `2026`                   |
| `YearMonth`     | 年份和月份               | `2026-11`                |
| `MonthDay`      | 月份和日期               | `--11-27`                |

其中，最常用的是 `LocalDate`、`LocalTime`、`LocalDateTime` 和 `DateTimeFormatter`



## 1.1 `LocalDate` 日期

>   `LocalDate` 用于表示年月日，不包含具体时间和时区

| 方法                   | 返回值      | 作用                 |
| ---------------------- | ----------- | -------------------- |
| `now()`                | `LocalDate` | 获取当前日期         |
| `of(year, month, day)` | `LocalDate` | 创建指定日期         |
| `parse(text)`          | `LocalDate` | 字符串转日期         |
| `getYear()`            | `int`       | 获取年份             |
| `getMonthValue()`      | `int`       | 获取月份             |
| `getDayOfMonth()`      | `int`       | 获取日期             |
| `getDayOfWeek()`       | `DayOfWeek` | 获取星期             |
| `plusDays(n)`          | `LocalDate` | 增加天数             |
| `minusDays(n)`         | `LocalDate` | 减少天数             |
| `plusMonths(n)`        | `LocalDate` | 增加月份             |
| `plusYears(n)`         | `LocalDate` | 增加年份             |
| `isBefore(date)`       | `boolean`   | 判断是否早于指定日期 |
| `isAfter(date)`        | `boolean`   | 判断是否晚于指定日期 |
| `lengthOfMonth()`      | `int`       | 获取当月总天数       |
| `isLeapYear()`         | `boolean`   | 判断是否为闰年       |

```java
public static void testLocalDate() {

    // 获取当前日期
    LocalDate date1 = LocalDate.now();

    // 指定年月日
    LocalDate date2 = LocalDate.of(2026, 11, 27);

    // 通过字符串创建日期
    LocalDate date3 = LocalDate.parse("2026-11-27");

    System.out.println(date1);               // 2026-11-27
    System.out.println(date2);               // 2026-11-27
    System.out.println(date3);               // 2026-11-27

    // 获取年、月、日
    int year = date1.getYear();              // 2026
    int month = date1.getMonthValue();       // 11
    int day = date1.getDayOfMonth();         // 27

    // 获取星期
    DayOfWeek week = date1.getDayOfWeek();   // FRIDAY

    // 获取一年中的第几天
    int dayOfYear = date1.getDayOfYear();    // 331

    // 获取当月总天数
    int length = date1.lengthOfMonth();      // 30

    // 是否为闰年
    boolean leapYear = date1.isLeapYear();   // false
}
```



## 1.2 `LocalTime` 时间

>   表示时分秒，不包含日期

| 方法                       | 返回值      | 作用                 |
| -------------------------- | ----------- | -------------------- |
| `now()`                    | `LocalTime` | 获取当前时间         |
| `of(hour, minute, second)` | `LocalTime` | 创建指定时间         |
| `parse(text)`              | `LocalTime` | 字符串转时间         |
| `getHour()`                | `int`       | 获取小时             |
| `getMinute()`              | `int`       | 获取分钟             |
| `getSecond()`              | `int`       | 获取秒               |
| `plusHours(n)`             | `LocalTime` | 增加小时             |
| `plusMinutes(n)`           | `LocalTime` | 增加分钟             |
| `minusHours(n)`            | `LocalTime` | 减少小时             |
| `minusMinutes(n)`          | `LocalTime` | 减少分钟             |
| `isBefore(time)`           | `boolean`   | 判断是否早于指定时间 |
| `isAfter(time)`            | `boolean`   | 判断是否晚于指定时间 |

```java
public static void testLocalTime() {

    // 获取当前时间
    LocalTime time1 = LocalTime.now();

    // 指定时分秒
    LocalTime time2 = LocalTime.of(9, 30, 15);

    // 通过字符串创建时间
    LocalTime time3 = LocalTime.parse("09:30:15");

    System.out.println(time1);               // 14:46:07.787485500
    System.out.println(time2);               // 09:30:15
    System.out.println(time3);               // 09:30:15

    // 获取时、分、秒
    int hour = time2.getHour();              // 9
    int minute = time2.getMinute();          // 30
    int second = time2.getSecond();          // 15

    // 获取纳秒
    int nano = time1.getNano();              // 787485500
    System.out.println(nano);

    // 增加时间
    LocalTime time4 = time2.plusHours(2);        // 11:30:15
    LocalTime time5 = time2.plusMinutes(30);   // 10:00:15
    LocalTime time6 = time2.plusSeconds(10);   // 09:30:25

    // 减少时间
    LocalTime time7 = time2.minusHours(1);   // 08:30:15

    // 时间比较
    boolean before = time2.isBefore(time7);  // false
    boolean after = time2.isAfter(time7);    // true
    boolean equal = time2.equals(time3);     // true
}
```



## 1.3 `LocalDateTime` 日期和时间

>   表示年月日时分秒，不包含时区

| 方法                 | 返回值          | 作用                 |
| -------------------- | --------------- | -------------------- |
| `now()`              | `LocalDateTime` | 获取当前日期时间     |
| `of(...)`            | `LocalDateTime` | 创建指定日期时间     |
| `parse(text)`        | `LocalDateTime` | 字符串转日期时间     |
| `getYear()`          | `int`           | 获取年份             |
| `getMonthValue()`    | `int`           | 获取月份             |
| `getDayOfMonth()`    | `int`           | 获取日期             |
| `getHour()`          | `int`           | 获取小时             |
| `getMinute()`        | `int`           | 获取分钟             |
| `getSecond()`        | `int`           | 获取秒               |
| `toLocalDate()`      | `LocalDate`     | 获取日期部分         |
| `toLocalTime()`      | `LocalTime`     | 获取时间部分         |
| `plusDays(n)`        | `LocalDateTime` | 增加天数             |
| `minusDays(n)`       | `LocalDateTime` | 减少天数             |
| `plusHours(n)`       | `LocalDateTime` | 增加小时             |
| `isBefore(dateTime)` | `boolean`       | 判断是否早于指定时间 |
| `isAfter(dateTime)`  | `boolean`       | 判断是否晚于指定时间 |
| `format(formatter)`  | `String`        | 格式化为字符串       |

```java
public static void testLocalDateTime() {

    // 获取当前日期时间
    LocalDateTime dateTime1 = LocalDateTime.now();

    // 指定年月日时分秒
    LocalDateTime dateTime2 = LocalDateTime.of(2026, 11, 27, 9, 30, 15);

    // 通过字符串创建日期时间
    LocalDateTime dateTime3 = LocalDateTime.parse("2026-11-27T09:30:15");

    System.out.println(dateTime1);           // 2026-11-27T14:41:17.725499900
    System.out.println(dateTime2);           // 2026-11-27T09:30:15
    System.out.println(dateTime3);           // 2026-11-27T09:30:15

    // 获取年、月、日
    int year = dateTime2.getYear();          // 2026
    int month = dateTime2.getMonthValue();   // 11
    int day = dateTime2.getDayOfMonth();     // 27

    // 获取时、分、秒
    int hour = dateTime2.getHour();          // 9
    int minute = dateTime2.getMinute();      // 30
    int second = dateTime2.getSecond();      // 15

    // 获取日期部分
    LocalDate date = dateTime2.toLocalDate();// 2026-11-27

    // 获取时间部分
    LocalTime time = dateTime2.toLocalTime();// 09:30:15

    // 增加日期时间
    LocalDateTime dateTime4 = dateTime2.plusDays(1);
    // 2026-11-28T09:30:15

    LocalDateTime dateTime5 = dateTime2.plusHours(2);
    // 2026-11-27T11:30:15

    // 减少日期时间
    LocalDateTime dateTime6 = dateTime2.minusMonths(1);
    // 2026-10-27T09:30:15

    // 修改指定字段
    LocalDateTime dateTime7 = dateTime2.withYear(2025);
    // 2025-11-27T09:30:15

    LocalDateTime dateTime8 = dateTime2.withHour(12);
    // 2026-11-27T12:30:15

    // 日期时间比较
    boolean before = dateTime2.isBefore(dateTime4); // true
    boolean after = dateTime2.isAfter(dateTime4);   // false
    boolean equal = dateTime2.isEqual(dateTime3);   // true
}
```



## 1.4 `Instant` 时间戳

>   用于表示时间线上的时间点，常用于时间戳处理

| 方法               | 返回值    | 作用               |
| ------------------ | --------- | ------------------ |
| `now()`            | `Instant` | 获取当前时间点     |
| `ofEpochMilli(n)`  | `Instant` | 根据毫秒时间戳创建 |
| `ofEpochSecond(n)` | `Instant` | 根据秒时间戳创建   |
| `toEpochMilli()`   | `long`    | 获取毫秒时间戳     |
| `getEpochSecond()` | `long`    | 获取秒时间戳       |
| `plusSeconds(n)`   | `Instant` | 增加秒数           |
| `minusSeconds(n)`  | `Instant` | 减少秒数           |

```java
public static void testInstant() {

    // 获取当前时间点
    Instant instant1 = Instant.now();

    // 指定秒级时间戳
    Instant instant2 = Instant.ofEpochSecond(1795771800L);

    // 指定毫秒级时间戳
    Instant instant3 = Instant.ofEpochMilli(1795771800000L);

    System.out.println(instant1);            // 2026-11-27T06:44:39.915739100Z
    System.out.println(instant2);            // 2026-11-27T01:30:00Z
    System.out.println(instant3);            // 2026-11-27T01:30:00Z

    // 获取秒级时间戳
    long seconds = instant3.getEpochSecond(); // 1795771800

    // 获取毫秒级时间戳
    long millis = instant3.toEpochMilli();    // 1795771800000

    // 获取纳秒部分
    int nano = instant1.getNano();            // 915739100
    System.out.println(nano);

    // 增加时间
    Instant instant4 = instant3.plusSeconds(60);
    // 2026-11-27T01:31:00Z

    // 减少时间
    Instant instant5 = instant3.minusSeconds(30);
    // 2026-11-27T01:29:30Z

    // 时间点比较
    boolean before = instant3.isBefore(instant4); // true
    boolean after = instant3.isAfter(instant4);   // false
}
```



## 1.5 `DateTimeFormatter` 日期格式化类

负责日期时间与字符串之间的转换。

| 方法                 | 返回值              | 作用                     |
| -------------------- | ------------------- | ------------------------ |
| `ofPattern(pattern)` | `DateTimeFormatter` | 创建日期格式化器         |
| `format(temporal)`   | `String`            | 日期时间转字符串         |
| `parse(text)`        | `TemporalAccessor`  | 字符串解析为通用日期对象 |

常用格式符：

| 格式符 | 含义     | 示例 |
| ------ | -------- | ---- |
| `yyyy` | 年份     | 2026 |
| `MM`   | 月份     | 11   |
| `dd`   | 日期     | 27   |
| `HH`   | 24小时制 | 09   |
| `mm`   | 分钟     | 30   |
| `ss`   | 秒       | 15   |
| `SSS`  | 毫秒     | 123  |

```java
public static void testDateTimeFormatter() {

    // 创建日期时间对象
    LocalDateTime dateTime = LocalDateTime.of(2026, 11, 27, 9, 30, 15);

    // 定义日期格式
    DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

    // 日期时间转字符串
    String str1 = dateTime.format(formatter);
    System.out.println(str1);                // 2026-11-27 09:30:15

    // 字符串转日期时间
    String str2 = "2026-11-27 09:30:15";
    LocalDateTime dateTime2 = LocalDateTime.parse(str2, formatter);
    System.out.println(dateTime2);           // 2026-11-27T09:30:15

    // 日期格式化
    LocalDate date = LocalDate.of(2026, 11, 27);
    DateTimeFormatter formatter2 = DateTimeFormatter.ofPattern("yyyy年MM月dd日");

    String str3 = date.format(formatter2);
    System.out.println(str3);                // 2026年11月27日

    // 时间格式化
    LocalTime time = LocalTime.of(9, 30, 15);
    DateTimeFormatter formatter3 = DateTimeFormatter.ofPattern("HH:mm:ss");

    String str4 = time.format(formatter3);
    System.out.println(str4);                // 09:30:15
}
```

# 四、`JDK 8` 之前的日期类（过期）

>   新代码中不推荐使用 `Date` 和 `Calendar`
>
>   1.    线程安全性不好
>   2.   `Date` 和 `Calendar` 都是可变对象



## 4.1 `Date` 日期类

>   `JDK 1.0` 的 `java.util.Date`

```java
public static void testDate() {
    // 创建 Date 对象，获取当前日期和时间
    Date date1 = new Date();
    // 年份需要减去 1900
    // Date date1 = new Date(2026 - 1900, 11, 27);

    // 获取时间戳（毫秒）1795747083627
    long timestamp = date1.getTime();

    // 日期比较
    Date date2 = new Date(timestamp + 86400000L);
    boolean before = date1.before(date2);
    boolean after = date1.after(date2);

    // 日期格式化
    SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
    String dateStr = sdf.format(date1);

    System.out.println("当前日期：" + date1);                 // 当前日期：Fri Nov 27 10:38:03 CST 2026
    System.out.println("时间戳：" + timestamp);               // 1795747083627
    System.out.println("格式化日期：" + dateStr);              // 2026-11-27 10:38:03
    System.out.println("date1 是否在 date2 之前：" + before);  // true
    System.out.println("date1 是否在 date2 之后：" + after);   // false
}
```



### 4.1.1 `java.sql.Date`

>   `java.sql.Date` 是 `java.util.Date` 的子类

1.   `java.util.Date` → `java.sql.Date`

     ```java
     java.util.Date utilDate = new java.util.Date();
     
     // 方式一：通过毫秒值构造（推荐，语义清晰）
     java.sql.Date sqlDate = new java.sql.Date(utilDate.getTime());
     ```

2.   `java.sql.Date` → `java.util.Date`

     ```java
     java.sql.Date sqlDate = new java.sql.Date(System.currentTimeMillis());
     
     // 直接赋值（子类 → 父类，自动向上转型）
     java.util.Date utilDate = sqlDate;
     ```



### 4.1.2 `SimpleDateFormat` 日期格式化类

1.   日期格式化 `format()`

     `String format(Date date)`

     ```java
     public static void main(String[] args) {
         // 获取当前时间
         Date date = new Date();
     
         // 创建日期格式化对象
         SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
     
         // 格式化日期
         String result = sdf.format(date);
     
         System.out.println(result);
         // 例如：2026-11-27 11:30:00
     }
     ```

2.   日期解析 `parse()`

     `Date parse(String source) throws ParseException`；可能抛出 `ParseException`

     ```java
     public static void testSimpleDateFormat() throws ParseException {
         // 日期字符串
         String dateStr = "2026-11-27 11:30:00";
     
         // 创建日期格式化对象
         SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
     
         // 解析日期字符串
         Date date = sdf.parse(dateStr);
     
         System.out.println(date);    // Fri Nov 27 11:30:00 CST 2026
     }
     ```

>   `SimpleDateFormat` 使用特定的字母表示日期和时间。
>
>   | 格式符号 | 含义           | 示例     |
>   | -------- | -------------- | -------- |
>   | `y`      | 年             | `2026`   |
>   | `M`      | 月             | `11`     |
>   | `d`      | 日             | `27`     |
>   | `H`      | 24小时制       | `14`     |
>   | `h`      | 12小时制       | `02`     |
>   | `m`      | 分钟           | `30`     |
>   | `s`      | 秒             | `45`     |
>   | `S`      | 毫秒           | `123`    |
>   | `E`      | 星期           | `星期五` |
>   | `a`      | 上午/下午      | `下午`   |
>   | `D`      | 一年中的第几天 | `331`    |
>   | `w`      | 一年中的第几周 | `48`     |
>
>   **常见格式示例：**
>
>   | 格式表达式                | 格式化结果                |
>   | ------------------------- | ------------------------- |
>   | `yyyy-MM-dd`              | `2026-11-27`              |
>   | `yyyy/MM/dd`              | `2026/11/27`              |
>   | `yyyy年MM月dd日`          | `2026年11月27日`          |
>   | `HH:mm:ss`                | `14:30:45`                |
>   | `yyyy-MM-dd HH:mm:ss`     | `2026-11-27 14:30:45`     |
>   | `yyyy-MM-dd HH:mm:ss.SSS` | `2026-11-27 14:30:45.123` |
>   | `yyyy-MM-dd E`            | `2026-11-27 星期五`       |

```java
    // 获取时间戳
    long timestamp = calendar.getTimeInMillis(); // 毫秒时间戳
    System.out.println(timestamp);

    // set 方法
    // add() 方法

    // getTime 返回 Date
    Date date = calendar.getTime();
}
```
