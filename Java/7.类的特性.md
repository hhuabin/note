# 一、类的构造方法

1.  构造方法名与类名完全相同

2.  **默认构造方法**：`Java` 编译器会为自动为类生成默认的构造方法，创建对象时，会自动调用默认构造方法

    如果类中有有参数的构造方法，则必须显示为类添加默认构造方法

3.  **返回值**：构造返回值是该**类本身**，故不能用 `void` 修饰构造方法

4.  构造方法也可以重载

5.  在构造方法中调用另一构造方法时，`this()` 必须放在第一行

6.  **继承**：继承时，如果父类中只有带参数的构造方法，则子类中必须有 `super(...args)`

```java
public class User {

    String name;
    int age;

    public User() {}

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

```java
User user = new User("张三", 18);

System.out.println(user.name);    // 张三
System.out.println(user.age);     // 18
```





# 二、方法的重载

`Java` 可以定义多个同名的方法，只要这些方法的**参数**不同即可

1.   方法重载

     ```java
     public class Calculator {
     
         // 两个 int 参数
         public int add(int a, int b) {
             return a + b;
         }
     
         // 三个 int 参数
         public int add(int a, int b, int c) {
             return a + b + c;
         }
     
         // 两个 double 参数
         public double add(double a, double b) {
             return a + b;
         }
     }
     ```

     ```java
     Calculator calculator = new Calculator();
     
     calculator.add(1, 2);          // 调用 add(int, int)
     calculator.add(1, 2, 3);       // 调用 add(int, int, int)
     calculator.add(1.5, 2.5);      // 调用 add(double, double)
     ```

2.   仅返回值不同，不算重载

     ```java
     public int add(int a, int b) {
         return a + b;
     }
     
     // 编译报错
     public double add(int a, int b) {
         return a + b;
     }
     ```
