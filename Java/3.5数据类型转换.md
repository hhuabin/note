# 一、数据类型转换

## 1.1 数值类型间的转换

1.   自动转换

     `byte → short → int → long → float → double`

     ```java
     public static void main(String[] args) {
     
         // byte 自动转换为 int
         byte a = 10;
         int b = a;
     
         // int 自动转换为 double
         int e = 100;
         double f = e;
     
         // char 自动转换为 int
         char g = 'A';
         int h = g;
     
         System.out.println(b); // 10
         System.out.println(f); // 100.0
         System.out.println(h); // 65
     }
     ```

2.   强制类型转换

     `目标类型 变量名 = (目标类型) 原变量;`

     ```java
     long num1 = 100L;
     int num2 = (int) num1;
     
     double num3 = 12.56;
     float num4 = (float) num3;
     ```

3.   整型与浮点类型的转换

     ```java
     public static void main(String[] args) {
     
         double num1 = 12.99;
         int num2 = (int) num1;
     
         float num3 = 15.68F;
         int num4 = (int) num3;
     
         System.out.println(num2); // 12
         System.out.println(num4); // 15
     }
     ```



## 1.2 字符串与数值类型转换

| 包装类    | 转换方法               | 返回类型 |
| --------- | ---------------------- | -------- |
| `Byte`    | `Byte.parseByte()`     | `byte`   |
| `Short`   | `Short.parseShort()`   | `short`  |
| `Integer` | `Integer.parseInt()`   | `int`    |
| `Long`    | `Long.parseLong()`     | `long`   |
| `Float`   | `Float.parseFloat()`   | `float`  |
| `Double`  | `Double.parseDouble()` | `double` |

1.   字符串转数值

     ```java
     public static void stringToNumber() {
         String str1 = "10";
         byte num1 = Byte.parseByte(str1);
     
         String str2 = "100";
         short num2 = Short.parseShort(str2);
     
         String str3 = "1000";
         int num3 = Integer.parseInt(str3);
     
         String str4 = "10000";
         long num4 = Long.parseLong(str4);
     
         String str5 = "12.5";
         float num5 = Float.parseFloat(str5);
     
         String str6 = "15.68";
         double num6 = Double.parseDouble(str6);
     
         System.out.println(num1);    // 10
         System.out.println(num2);    // 100
         System.out.println(num3);    // 1000
         System.out.println(num4);    // 10000
         System.out.println(num5);    // 12.5
         System.out.println(num6);    // 15.68
     }
     ```
     
2.   数值转字符串

     `String.valueOf()`

     ```java
     public static void main(String[] args) {
     
         int num1 = 100;
         String str1 = String.valueOf(num1);
     
         long num2 = 200L;
         String str2 = String.valueOf(num2);
     
         double num3 = 12.56;
         String str3 = String.valueOf(num3);
     
         System.out.println(str1); // "100"
         System.out.println(str2); // "200"
         System.out.println(str3); // "12.56"
     }
     ```

     包装类的 `toString()`

     ```java
     public static void main(String[] args) {
     
         int num1 = 100;
         String str1 = Integer.toString(num1);
     
         double num2 = 12.56;
         String str2 = Double.toString(num2);
     
         System.out.println(str1); // "100"
         System.out.println(str2); // "12.56"
     }
     ```
