# 一、函数的使用

## 1.1 参数默认值的问题

>   `Java` 没有类似 `javascript` 的参数默认值的东西，只能自己兜底

1.   参数判空 赋上 默认值（推荐）

     ```java
     public void sayHello(String name) {
     
         if (name == null || name.isEmpty()) {
             name = "张三";
         }
     
         System.out.println("Hello, " + name);
     }
     ```

2.   方法重载

     ```java
     public void sayHello() {
         sayHello("张三");
     }
     
     public void sayHello(String name) {
         System.out.println("Hello, " + name);
     }
     ```

     >   这个我觉得是骚操作来的，因为 `sayHello(null)` 会调用到 `sayHello(String name)`，`name` 还是 `null`。只能说有用但不多

3.   使用 `Optional`

     适合需要明确表达参数可能不存在的场景，但一般不建议仅为了默认值而使用

     ```java
     public void sayHello(Optional<String> name) {
         String value = name.orElse("张三");
         System.out.println("Hello, " + value);
     }
     ```
