# 一、基本数据类型

>   基本数据类型作为成员变量时具有默认值，开发中要注意（最好不要乱用基本数据类行，报错报死你）

| 数据类型     | 关键字    | 占用字节数 | 默认值     | 取值范围                                                     | MySQL 常用类型           |
| ------------ | --------- | ---------- | ---------- | ------------------------------------------------------------ | ------------------------ |
| 字节型       | `byte`    | 1          | `0`        | `-2⁷ ~ 2⁷ - 1`（-128 ~ 127）                                 | `TINYINT`                |
| 短整型       | `short`   | 2          | `0`        | `-2¹⁵ ~ 2¹⁵ - 1`（-32,768 ~ 32,767）                         | `SMALLINT`               |
| 整型         | `int`     | 4          | `0`        | `-2³¹ ~ 2³¹ - 1`（-2,147,483,648 ~ 2,147,483,647）           | `INT`                    |
| 长整型       | `long`    | 8          | `0L`       | `-2⁶³ ~ 2⁶³ - 1`（-9223372036854775808 ~ 9223372036854775807） | `BIGINT`                 |
| 单精度浮点型 | `float`   | 4          | `0.0f`     | 约 `±3.4 × 10³⁸`（约 7 位有效数字）                          | `FLOAT`                  |
| 双精度浮点型 | `double`  | 8          | `0.0d`     | 约 `±1.7 × 10³⁰⁸`（约 15 位有效数字）                        | `DOUBLE`                 |
| 字符型       | `char`    | 2          | `'\u0000'` | `'\u0000' ~ '\uffff'`（0 ~ 65,535）                          | `CHAR` / `VARCHAR`       |
| 布尔型       | `boolean` | 1          | `false`    | `true` / `false`                                             | `BOOLEAN` / `TINYINT(1)` |

`Java` 基本数据类型作为成员变量时具有默认值，作为局部变量时没有默认值，必须初始化后才能使用。开发中需要注意默认值可能对业务逻辑产生影响

```java
public class User {

    // 成员变量：自动赋予默认值
    private int age; // 0

    public void test() {

        // 局部变量：必须手动初始化
        int num;

        // 编译错误：变量 num 可能尚未初始化
        // System.out.println(num);
    }

    // 方法参数没有默认值。Java是强类型语言，调用该方法必须传参，否则就报错
    // PS：Java 不支持像 JavaScript 一样直接在方法定义中为参数设置默认值
    public String data(char name, int age) {}
}
```



# 二、包装数据类型

>   包装数据类型是基本数据类型对应的引用类型，默认值为 `null`

| 基本数据类型 | 包装数据类型 | 默认值 | `MySQL` 常用类型      |
| ------------ | ------------ | ------ | --------------------- |
| `byte`       | `Byte`       | `null` | `TINYINT`             |
| `short`      | `Short`      | `null` | `SMALLINT`            |
| `int`        | `Integer`    | `null` | `INT`                 |
| `long`       | `Long`       | `null` | `BIGINT`              |
| `float`      | `Float`      | `null` | `FLOAT`               |
| `double`     | `Double`     | `null` | `DOUBLE`              |
| `char`       | `Character`  | `null` | `CHAR` / `VARCHAR`    |
| `boolean`    | `Boolean`    | `null` | `BOOLEAN` / `TINYINT` |



## 2.1 包装类型的作用

1.  允许为 `null`：可以表示字段尚未赋值、数据库字段为空等状态。
2.  支持泛型：`Java` 泛型不能直接使用基本数据类型，例如 `List<Integer>`，不能使用 `List<int>`。
3.  提供工具方法：包装类提供字符串转换、数值比较等方法。
4.  支持自动装箱和拆箱：基本数据类型和包装类型可以自动转换



## 2.2 自动装箱与自动拆箱

1.   自动装箱（`Autoboxing`）：基本数据类型自动转换为对应的包装类型

     ```java
     int num = 10;
     
     // 自动装箱
     Integer integer = num;
     ```

2.   自动拆箱（`Unboxing`）：包装类型自动转换为对应的基本数据类型

     ```java
     Integer integer = 10;
     
     // 自动拆箱
     int num = integer;
     ```

     >包装类型为 `null` 时，进行自动拆箱会抛出 `NullPointerException`
     >
     >```java
     >Integer num = null;
     >
     >// NullPointerException
     >int value = num;
     >```
