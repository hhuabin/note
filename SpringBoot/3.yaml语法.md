# 一、`yaml` 基本语法规则

`YAML` 文件通常使用 `.yaml` 或 `.yml` 作为扩展名，两者没有本质区别

主要遵循以下规则：

1.  大小写敏感：`name` 和 `Name` 是不同的字段
2.  使用空格缩进：不能使用 `Tab` 键缩进，通常每级缩进 2 个空格
3.  冒号后面要有空格：例如 `name: 张三`
4.  使用换行表示结构：通常不需要使用大括号、分号等符号
5.  通过缩进表示层级关系：同一层级的字段必须保持相同缩进
6.  不推荐使用驼峰：如 `niHao` 改为 `ni-hao`





# 二、基本数据类型



## `2.1` 字符串（`String`）

字符串可以直接书写，也可以使用单引号或双引号

```yaml
name: 张三
city: Guangzhou

# 单引号
message1: 'Hello YAML'

# 双引号
message2: "Hello YAML"

# 包含冒号等特殊字符时，可以使用引号
url: "https://example.com:8080"
```

单引号和双引号的区别：

| 写法           | 特点                           |
| -------------- | ------------------------------ |
| `name: 张三`   | 普通字符串通常可以不加引号     |
| `name: '张三'` | 单引号中的内容通常按字面值处理 |
| `name: "张三"` | 双引号支持转义字符，如 `\n`    |



## `2.2` 整数和浮点数

```yaml
age: 25
count: 100
price: 99.99
```



## `2.3` 布尔值（`Boolean`）

```yaml
enabled: true
disabled: false
```



## `2.4` 空值（`Null`）

```yaml
value1: null
value2: ~
value3:
```

这三种写法通常都表示空值



# 三、对象（`Object / Map`）

`YAML` 使用缩进表示对象的层级结构

```yaml
user:
  id: 1001
  name: 张三
  contact:
    phone: "13800000000"
    email: zhangsan@example.com
```



# 四、数组（`Array / List`）

`YAML` 使用短横线 `-` 表示数组中的一个元素

1.   基本数组

     ```yaml
     arr: 
         - '1'
         - '2'
     ```

     也可以

     ```yaml
     arr: ['1', '2']
     ```

2.   对象数组

     ```yaml
     users:
       - id: 1001
         name: 张三
         age: 25
       - id: 1002
         name: 李四
         age: 30
     ```

     等价于

     ```json
     {
       "users": [
         {
           "id": 1001,
           "name": "张三",
           "age": 25
         },
         {
           "id": 1002,
           "name": "李四",
           "age": 30
         }
       ]
     }
     ```

     注意第二个对象的 `id`、`name` 和 `age` 必须属于同一个数组元素，不能因为缩进错误而改变层级



# 五、注释

使用 `#` 添加注释

```yaml
# 服务端口
server:
  port: 8080
```

```yaml
port: 8080 # HTTP 服务端口
```

>   注意：`#` 前面有空格时，通常才会被识别为行尾注释的开始
>
>   ```yaml
>   password: abc#123
>   ```
>
>   这里 `abc#123` 通常会作为字符串内容，而不是把 `#123` 当成注释



# 六、多行字符串

`YAML` 支持使用 `|` 和 `>` 处理多行文本

1.   使用 `|` 保留换行

     ```yaml
     description: |
       这是第一行。
       这是第二行。
       这是第三行。
     ```

     解析后的字符串会保留各行之间的换行

2.   使用 `>` 折叠换行

     ```yaml
     description: >
       这是第一行。
       这是第二行。
       这是第三行。
     ```

     普通换行通常会被**折叠为空格**，最终形成一段连续文本



# 七、特殊语法

1.   空对象与空数组

     ```yaml
     user: {}
     hobbies: []
     ```

     -   `{}` 表示空对象
     -   `[]` 表示空数组

2.   同一行定义对象

     ```yaml
     user: {name: 张三, age: 25}
     ```

     这是合法的行内对象写法，但配置文件中通常更推荐使用多行缩进，方便阅读和维护

3.   多个文档

     使用 `---` 分隔多个 `YAML` 文档

     ```yaml
     ---
     name: application-a
     port: 8080
     
     ---
     name: application-b
     port: 8081
     ```



# 八、自定义类 `yaml` 提示插件

`IDEA` 基于 `Spring Boot` 内置属性已有元数据提示，但是如果自定义类（比如使用了 `@ConfigurationProperties`）绑定了配置文件的属性，可能需要一个提示插件，避免写错

```xml
<dependencies>
    <!-- 自定义类的 yaml 提示插件，编译期生成配置元数据，供 IDE 提示 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-configuration-processor</artifactId>
        <optional>true</optional>
    </dependency>
</dependencies>

<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
            <!-- 打包构建排除该插件，该插件对生产毫无作用 -->
            <configuration>
                <excludes>
                    <exclude>
                        <groupId>org.springframework.boot</groupId>
                        <artifactId>spring-boot-configuration-processor</artifactId>
                    </exclude>
                </excludes>
            </configuration>
        </plugin>
    </plugins>
</build>
```

>   这个只是提示的插件，避免写错，其实可以不用这个插件的，自己保证不写错就好

---

举例个需要使用的情况

1.   假设你有一个配置类

     ```java
     @Component
     @ConfigurationProperties(prefix = "myapp.pay")
     public class PayProperties {
         /** 支付超时时间（毫秒） */
         private long timeout = 30000;
         /** 支付渠道 */
         private String channel = "alipay";
         // getter / setter
     }
     ```

2.   在 `application.yml` 里写

     ```yaml
     myapp:
       pay:
         timeout: 5000
         channel: wechat
     ```

3.   配置类绑定了配置属性，这时候就可以用这个插件，但是我觉得是没必要
