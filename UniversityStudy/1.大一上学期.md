## `markdowm` 笔记软件

> 建议学习时长：3 天，；**学习一定要做笔记，不做笔记，今天学明天忘**

`markdown` 官方文档：[https://markdown.com.cn/basic-syntax/](https://markdown.com.cn/basic-syntax/ 'markdown 官网')；学些如何使用 `markdown` 格式笔记

`Typora` 官网：[https://typoraio.cn/](https://typoraio.cn/)；通过该链接下载 `Typora` 软件，用来作笔记；正版免费试用30天，购买正版需89元，或者使用破解版



### `markdown` 使用说明

1. `markdown` 文件以 `.md`结尾

2. `markdown` 对代码笔记相当友好，可以贴代码片段，可以指定使用语言等。比如：

   ```c++
   for (int i = 1; i < 10; i++) {
       if (i == 7) {
           break;       // 到7结束循环
       }
   }
   ```

3. `markdown` 对于图片的处理相对麻烦些，不可以像 `Word` 一样直接把图片复制、粘贴到 `md` 中，只能引用图片路径（建议图片放在和文件同级的`images`文件夹下）

4. 不可以使用 `Word` 等软件做笔记

5. 其他笔记软件：听说**有道笔记**也不错，可以自己搜索看看，

# 3. 软考

软考报名网址：[中国计算机职业技术资格网](https://www.ruankao.org.cn/ "ruankao")

> 软考包括：**初级、中级、高级**
>
> 考试时间：下半年 9月报名，11月考试；上半年 3月报名，5月考试
>
> 考试科目：初级中级考两门，高级加一门论文共3门
>
> 分数：满分75分，全部 45 分及格即通过；

刷题小程序：微信搜索 **51CTO软考题库** 小程序，里面可以刷题



### 建议考试进度

- 大一 需要通过**初级**：建议报考 **程序员** 或 **信息技术处理员**

  初级很简单的，找个网课看看，有手就行

  大一考不过初级就不要考了，大二直接开始考中级就行

- 大二/大三 需要通过**中级**：建议报考 **软件设计师**

- **高级**：大三/大四考，高级考哪一门都行，看兴趣；有些人考好几门的。其中 **系统架构设计师**最难，**信息系统项目管理师**最简单

  通过中级后，这个尽力就行

  > 大学至少要通过初级和中级，高级看命，努力就好
