# MySQL 用户 `mysql.user`

MySQL 中，一个用户通常由两部分组成

```sql
# '用户名'@'主机'
'root'@'localhost'        # 用户名是 root，只能从本机连接 MySQL。
'zhangsan'@'%'            # 用户名是 zhangsan，允许从任意 IP 地址连接
```



## 创建删除用户

1. 查看用户

    MySQL 的用户信息保存在系统数据库 `mysql` 中

    ```sql
    SELECT user, host FROM mysql.user;
    ```

2. 创建用户

    > `'zhangsan'@'localhost'` 和 `'zhangsan'@'%'` 是两个不同的用户

    ```sql
    CREATE USER 'zhangsan'@'localhost'
    IDENTIFIED BY '123456';
    
    # 允许任意 IP 连接
    CREATE USER 'zhangsan'@'%'
    IDENTIFIED BY '123456';
    
    # 指定ip
    CREATE USER 'zhangsan'@'192.168.1.100'
    IDENTIFIED BY '123456';
    
    # 指定网段
    CREATE USER 'zhangsan'@'192.168.1.%'
    IDENTIFIED BY '123456';
    ```

3. 修改用户名

    直接改表，比较少用

    ```sql
    UPDATE mysql.user
    SET USER = '新用户名'
    WHERE USER = '旧用户名';
    
    # 刷新权限
    FLUSH PRIVILEGES;
    ```

4. 修改用户密码

    ```sql
    ALTER USER 'zhangsan'@'localhost'
    IDENTIFIED BY '新密码';
    ```

    ```sql
    # 修改当前登录用户密码
    ALTER USER USER()
    IDENTIFIED BY '123456';
    
    SET PASSWORD = '123456';
    
    # root 修改其他用户的密码
    SET PASSWORD FOR 'zhangsan'@'localhost' = '12345';
    ```

5. 删除用户

    删除用户只会删除账号和相关权限，不会删除数据库中的数据

    ```sql
    DROP USER 'zhangsan'@'localhost';
    ```

6. 给 root 用户授权 `SYSTEM_USER` 权限，`MySQL8` 的 `root` 用户好像都缺少这个权限。主要是为了防止一个普通的“超级管理员”通过 `GRANT ALL PRIVILEGES`，就可以随意修改真正的系统管理员

    > `SYSTEM_USER`：可以管理/操作其他系统级用户的权限

    ```sql
    # 给 root 用户授权 SYSTEM_USER
    GRANT SYSTEM_USER
    ON *.*
    TO 'root'@'localhost';
    ```



# 用户权限管理 `GRANT`

```sql
GRANT 权限列表
ON 数据库名.对象名
TO '用户名'@'主机';

# 授权 `授权权限`
GRANT 权限
ON 数据库.表
TO '用户名'@'主机'
WITH GRANT OPTION;          # 慎用，很容易造成权限混乱
```

1. 授予**所有数据库**权限

    > 使用`*.*`通配符的话，后续新增的数据库和表，也将会有权限

    ```sql
    GRANT ALL PRIVILEGES
    ON *.*              # *.* 是通配符，表示所有数据库.所有表
    TO 'zhangsan'@'%';
    ```

2. 给**某个数据库**授权

    ```sql
    GRANT ALL PRIVILEGES
    ON testdb.*          # testdb 数据库中的所有表
    TO 'zhangsan'@'%';
    ```

3. 给**某张表**授权

    ```sql
    GRANT SELECT, INSERT
    ON testdb.users
    TO 'zhangsan'@'%';
    ```



## 查看用户权限

```sql
# 查看当前用户权限
SHOW GRANTS;

SHOW GRANTS FOR 'zhangsan'@'%';

# 查看 MySQL 支持哪些权限类型
SHOW PRIVILEGES;

```

> 权限末尾的`WITH GRANT OPTION` 是授权权限，一般 `root` 用户才有



## 撤销权限 `REVOKE`

```sql
REVOKE INSERT, UPDATE
ON testdb.*
FROM 'zhangsan'@'%';
```



## 常见权限

| 权限                | 作用                                                         |
| ------------------- | ------------------------------------------------------------ |
| `SELECT`            | 查询数据                                                     |
| `INSERT`            | 插入数据                                                     |
| `UPDATE`            | 修改数据                                                     |
| `DELETE`            | 删除数据                                                     |
| `CREATE`            | 创建数据库/表                                                |
| `DROP`              | 删除数据库/表                                                |
| `ALTER`             | 修改表结构                                                   |
| `INDEX`             | 创建/删除索引                                                |
| `EXECUTE`           | 执行存储过程/函数                                            |
| `ALL PRIVILEGES`    | 所有权限                                                     |
| `WITH GRANT OPTION` | 可以把自己拥有的权限授予别人                                 |
| `SYSTEM_USER`       | 具有系统用户级别的特殊管理能力，只能 `root` 用户拥有，超管也别分配 |



## 开发建议：超级管理员

1. 使用 `root` 用户，创建一个**太子**用户（超管）

    ```sql
    CREATE USER 'admin'@'localhost'
    IDENTIFIED BY 'admin123';
    ```

2. 给太子用户授权所有权限，包括 授权权限

    ```sql
    GRANT ALL PRIVILEGES
    ON *.*
    TO 'admin'@'localhost'
    WITH GRANT OPTION;
    ```

3. 这样**太子**用户就相当于 `root` 用户，使用太子用户连接 后端即可，万一服务器遭受攻击，直接干掉太子用户，断绝再次被攻击的可能

    ```sql
    SHOW GRANTS FOR 'admin'@'localhost';
    ```

    ```sql
    # 回收超管的所有权限
    REVOKE ALL PRIVILEGES
    ON *.*
    FROM 'admin'@'localhost';
    
    # 删除超管用户
    DROP USER 'admin'@'localhost';
    ```



# 用户访问控制

| 表                   | 作用                       |
| -------------------- | -------------------------- |
| `mysql.user`         | **用户账号、全局权限**     |
| `mysql.db`           | **数据库级权限**           |
| `mysql.tables_priv`  | **表级权限**               |
| `mysql.columns_priv` | **列级权限**               |
| `mysql.procs_priv`   | **存储过程、存储函数权限** |
| `mysql.proxies_priv` | **代理用户权限**           |

1. 用户向 MySQL 发出请求
2. MySQL 检查 `mysql.user` 权限表的权限信息
3. MySQL 检查 `mysql.db` 权限表的权限信息；遇到通配符就不往下检验了
4. MySQL 检查 `mysql.tables_priv` 权限表的权限信息；遇到通配符就不往下检验了
5. MySQL 检查 `mysql.columns_priv` 权限表的权限信息



# 角色管理

角色是一个**权限集合 / 权限载体**

1. 创建角色`CREATE ROLE`

    ```sql
    CREATE ROLE '角色名';
    
    CREATE ROLE 'admin_role';
    ```

2. 给角色授权`GRANT`

    ```sql
    GRANT SELECT, INSERT, UPDATE
    ON mydb.*
    TO 'developer';
    ```

3. 查看角色本身的权限`SHOW GRANTS`

    ```sql
    SHOW GRANTS
    FOR 'developer';
    ```

4. 把角色分配给用户`GRANT`

    ```sql
    GRANT '角色'
    TO '用户';
    
    GRANT 'developer'
    TO 'zhangsan'@'localhost';
    
    GRANT 'developer'
    TO 'lisi'@'localhost';
    ```

5. 激活用户角色

    ```sql
    SET DEFAULT ROLE 'developer'
    TO 'zhangsan'@'localhost';
    ```

6. 查看用户拥有的角色`SHOW GRANTS`

    ```sql
    SHOW GRANTS
    FOR 'zhangsan'@'localhost';
    ```

    ```SQL
    # 查看当前会话的角色
    SELECT CURRENT_ROLE();
    ```

7. 角色继承

    ```sql
    CREATE ROLE 'basic_role';
    CREATE ROLE 'developer_role';
    
    GRANT SELECT
    ON mydb.*
    TO 'basic_role';
    
    # GRANT 角色 TO 角色
    # developer_role 拥有了 basic_role 的权限
    GRANT 'basic_role'
    TO 'developer_role';
    ```

8. 撤销角色`REVOKE`

    ```sql
    REVOKE 'developer'
    FROM 'zhangsan'@'localhost';
    ```

9. 删除角色`DROP ROLE`

    ```sql
    DROP ROLE 'developer';
    ```



### 权限体系

| 角色              | 典型权限                         | 主要用途           |                                     |
| ----------------- | -------------------------------- | ------------------ | ----------------------------------- |
| `readonly`        | `SELECT`                         | 查询、报表、运营   | `SELECT`                            |
| `developer`       | `SELECT, INSERT, UPDATE, DELETE` | 开发测试           | `SELECT, INSERT, UPDATE, DELETE`    |
| `app_user`        | 应用实际需要的权限               | 后端程序连接数据库 | `SELECT, INSERT, UPDATE, DELETE`    |
| `dba`             | 数据库管理权限                   | DBA 运维           | `ALL PRIVILEGES`                    |
| `backup_operator` | 备份相关权限                     | 数据备份           | `SELECT, SHOW VIEW, TRIGGER, EVENT` |
| `monitor`         | 监控、状态查询                   | 监控系统           | `PROCESS`、监控相关查询权限         |
| `migration`       | `CREATE, ALTER, INDEX` 等        | 数据库迁移角色     | `CREATE, ALTER, INDEX, DROP`        |
| `admin`           | 较高管理权限                     | 数据库管理员       | `ALL PRIVILEGES`                    |

> 查看现有的角色
>
> ```sql
> SELECT *
> FROM mysql.user
> WHERE authentication_string = ''
>   AND account_locked = 'Y';
> ```



## 开发建议

1. 使用 `root` 用户，创建 `admin` 超管

    ```sql
    CREATE ROLE 'role_admin';
    ```

2. 给超管授权

    ```sql
    GRANT ALL PRIVILEGES
    ON *.*
    TO 'role_admin'
    WITH GRANT OPTION;
    ```

    ```sql
    SHOW GRANTS
    FOR 'role_admin';
    ```

3. 把超管分配给用户

    ```sql
    GRANT 'role_admin'
    TO 'admin'@'localhost';	
    ```

4. 激活超管

    ```sql
    SET DEFAULT ROLE 'role_admin'
    TO 'admin'@'localhost';
    ```

5. 验证是否分配成功

    ```sql
    SHOW GRANTS
    FOR 'admin'@'localhost';
    ```
