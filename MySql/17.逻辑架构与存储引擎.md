# 逻辑架构

## SQL 语句在 MySQL 中的执行流程

```mermaid
graph LR
    SQL[SQL语句] ---> 分析器[语法分析、语义检查]
    分析器 --语法分析树--> 优化器[逻辑优化、物理优化]
    优化器 --查询计划（查询树）--> 执行器[执行器]
    执行器 ---> 查询结果[查询结果]
```



- `MySQL 5.7` 查看是否记录SQL语句执行过程

    ```sql
    # 1 开启，0 关闭
    SELECT @@session.profiling;
    
    STE @@session.profiling = 1;
    ```

    查看 SQL 执行性能信息

    ```sql
    # 查看 SQL 执行性能信息
    SHOW PROFILES;
    
    # 查看某条 SQL 具体慢在哪里
    SHOW PROFILE FOR QUERY 130;
    ```

- `MySQL 8.0` 中，查看SQL语句性能信息，可以直接使用 `EXPLAIN ANALYZE` 解释分析

    它会直接告诉我们 **实际执行计划 + 实际耗时 + 实际处理的行数**

    ```sql
    EXPLAIN ANALYZE
    SELECT * FROM user_test;
    ```



# 存储引擎

```sql
# 查看 MySQL 提供的存储引擎，有支持，不支持和默认，默认一般是 InnoDB
SHOW ENGINES;

# 查看默认的存储引擎
SHOW VARIABLES LIKE '%storage_engine%';
# 或
SELECT @@default_storage_engine;
```

> `MySQL 8.0` 默认存储引擎是 `InnoDB` 支持事务
>
> `MySQL 5.0` 默认存储引擎是 `MyISAM`，`MyISAM` 不支持事务，所以使用 `MySQL 5.0 + MyISAM` 的要注意，可以就切换 `InnoDB`；`MySQL 5.5` 开始默认使用 `InnoDB`

1. 修改默认的存储引擎

    不会修改已经创建了的表

    ```sql
    # 修改全局变量
    SET GLOBAL default_storage_engine = InnoDB;
    ```

    最保险的还是直接修改配置文件

2. 创建表的时候指定存储引擎 `ENGINE = InnoDB`

    > 创建数据库不能指定存储引擎

    ```sql
    CREATE TABLE IF NOT EXISTS user (
        id BIGINT PRIMARY KEY,
        create_time DATETIME,
        update_time DATETIME
    )
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci
    ENGINE = InnoDB;      # 指定存储引擎
    ```



### 存储引擎对比

|          | InnoDB                  | MyISAM               |
| -------- | ----------------------- | -------------------- |
| 事务     | :white_check_mark: 支持 | :x: 不支持           |
| 外键     | 支持                    | 不支持               |
| 锁机制   | 行锁 + 表锁             | 表锁                 |
| 内存要求 | 相对较高                | 相对较低             |
| 存储空间 | 相对较大                | 相对较小             |
| 崩溃恢复 | :white_check_mark: 支持 | :x: 不支持           |
| 聚簇索引 | :white_check_mark: 支持 | :x: 不支持           |
| 适用场景 | 绝大多数业务系统        | 读多写少、历史系统等 |
