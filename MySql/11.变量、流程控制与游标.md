# 变量

## 系统变量

系统变量分为全局系统变量（需要添加 global 关键字）以及会话系统变量（需要添加 session 关键字）

1. 全局变量：全局系统变量针对于**所有会话（连接）有效**，但 **不能跨重启**
2. 会话变量：会话系统变量仅针对于**当前会话（连接）**有效。会话期间，当前会话对某个会话系统变量值的修改，不会影响其他会话同一个会话系统变量的值

### 全局变量

1. 查看所有全局变量

    ```sql
    SHOW GLOBAL VARIABLES;
    
    # 模糊查询
    SHOW GLOBAL VARIABLES LIKE '%标识符%';           # SHOW GLOBAL VARIABLES LIKE 'admin%';
    ```

2. 查看指定的系统变量的值；MySQL 中的系统变量以 两个`@` 开头，其中`@@global`仅用于标记全局系统变量

    ```sql
    SELECT @@global.变量名;
    
    SELECT @@global.admin_port;      # 33062
    ```

3. 修改系统变量

    - 修改 MySQL 配置文件，该修改将会永久保存

    - 运行时修改

        ```sql
        # 方式1
        SET GLOBAL 变量名 = 值;
        # 方式2
        SET @@global.变量名 = 值;
        
        SET GLOBAL max_connections = 200;
        ```



### 会话变量

1. 查看所有会话变量

    ```sql
    SHOW SESSION VARIABLES;
    
    # 或者
    SHOW VARIABLES;
    
    # 模糊查询
    SHOW SESSION VARIABLES LIKE '%标识符%';
    ```

2. 查看指定的会话变量的值

    `@@`首先标记会话系统变量，如果会话系统变量不存在，则标记全局系统变量。

    ```sql
    SELECT @@session.变量名;
    
    #或者
    SELECT @@变量名;       # 先查会话变量，没有就查全局变量
    ```

3. 修改会话变量

    ```sql
    # 方式1
    SET SESSION 变量名 = 值;
    # 方式2
    SET @@session.变量名 = 值;
    
    SET SESSION autocommit = 0;
    ```



## 用户变量

根据作用范围不同，又分为 **会话用户变量** 和 **局部变量**

1. 会话用户变量：作用域和会话变量一样，只对 **当前连接** 会话有效
2. 局部变量：只在 `BEGIN` 和 `END` 语句块中有效。局部变量只能在 **存储过程和存储函数** 中使用

### 会话用户变量

1. 变量的定义

    ```sql
    # 方式1：`=`或`:=``
    SET @用户变量 = 值;
    SET @用户变量 := 值;
    
    # 方式2：SELECT :=`` 或 `INTO` 关键字
    SELECT @用户变量 := 表达式 [FROM 等子句];
    SELECT 表达式 INTO @用户变量 [FROM 等子句];
    
    SELECT @num := COUNT(*) FROM employees;
    ```

2. 查看用户变量的值

    ```sql
    SELECT @用户变量
    ```



### 局部变量

1. 声明局部变量

    局部变量必须使用 `DECLARE` 声明

    ```sql
    #声明局部变量
    DECLARE 变量名1 变量数据类型 [DEFAULT 变量默认值];
    DECLARE 变量名2,变量名3,... 变量数据类型 [DEFAULT 变量默认值];
    ```

    ```sql
    CREATE PROCEDURE test()
    BEGIN
        DECLARE user_name VARCHAR(50);
        DECLARE user_age INT;
    
        SET user_name = '张三';
        SET user_age = 18;
    
        SELECT user_name, user_age;
    END;
    ```

2. 局部变量在存储过程的具体应用

    简化子查询的使用

    ```sql
    # 根据用户 ID 查询他的等级名称
    DELIMITER //
    
    CREATE PROCEDURE get_user_level(IN user_id INT)
    BEGIN
        DECLARE level_id INT;
        DECLARE level_name VARCHAR(50);
    
        SELECT level_id
        INTO level_id
        FROM user
        WHERE id = user_id;
    
        SELECT name
        INTO level_name
        FROM user_level
        WHERE id = level_id;
    
        SELECT level_name;
    END //
    
    DELIMITER ;
    ```



# 程序出错处理机制

错误示例：`ERROR 1305 (42000): PROCEDURE sql_study_db.get_email does not exist`

`MySQL_error_code` 和 `sqlstate_value` 都可以表示 `MySQL` 的错误。

- `MySQL_error_code` 是数值类型错误代码（1305 ）
- `sqlstate_value` 是长度为5的字符串类型错误代码（42000）
