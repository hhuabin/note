# 一、变量

## 系统变量 `@@`

系统变量分为全局系统变量（需要添加 global 关键字）以及会话系统变量（需要添加 session 关键字）

1. 全局变量：全局系统变量针对于**所有会话（连接）有效**，但 **不能跨重启**
2. 会话变量：会话系统变量仅针对于**当前会话（连接）**有效。会话期间，当前会话对某个会话系统变量值的修改，不会影响其他会话同一个会话系统变量的值

### 全局变量

1. 查看所有全局变量

    ```sql
    SHOW GLOBAL VARIABLES;
    
    # 模糊查询
    SHOW GLOBAL VARIABLES LIKE '%标识符%';           # SHOW GLOBAL VARIABLES LIKE 'admin%';
    ```

2. 查看指定的全局变量的值；`MySQL` 中的系统变量以 两个`@` 开头，其中`@@global`仅用于标记全局系统变量

    ```sql
    SELECT @@global.变量名;
    
    SELECT @@global.admin_port;      # 33062
    ```

3. 修改全局变量

    - 修改 `MySQL` 配置文件，该修改将会永久保存

    - `SET PERSIST` 持久化全局变量，该方式会把全局变量写入配置文件，慎用

        ```sql
        SET PERSIST max_connections = 200;
        ```
    
    - 运行时修改
    
        ```sql
        # 方式1
        SET GLOBAL 变量名 = 值;
        # 方式2
        SET @@global.变量名 = 值;
        
        SET GLOBAL max_connections = 200;
        ```



### 会话变量

1. 查看所有会话变量

    ```sql
    SHOW SESSION VARIABLES;
    
    # 或者
    SHOW VARIABLES;
    
    # 模糊查询
    SHOW SESSION VARIABLES LIKE '%标识符%';
    ```

2. 查看指定的会话变量的值

    `@@`首先标记会话系统变量，如果会话系统变量不存在，则标记全局系统变量。

    ```sql
    SELECT @@session.变量名;
    
    #或者
    SELECT @@变量名;       # 先查会话变量，没有就查全局变量
    ```

3. 修改会话变量

    ```sql
    # 方式1
    SET SESSION 变量名 = 值;
    # 方式2
    SET @@session.变量名 = 值;
    ```
    
    ```mysql
    SET SESSION autocommit = 0;
    
    SET autocommit = 0;   # 默认使用 SESSION，即等价于 SET SESSION autocommit = 0;
    ```



## 用户变量 `@`

根据作用范围不同，又分为 **会话用户变量** 和 **局部变量**

1. 会话用户变量：作用域和会话变量一样，只对 **当前连接** 会话有效
2. 局部变量：只在 `BEGIN` 和 `END` 语句块中有效。局部变量只能在 **存储过程和存储函数** 中使用

### 会话用户变量

1. 变量的定义

    ```sql
    # 方式1：`=`或`:=``
    SET @用户变量 = 值;
    SET @用户变量 := 值;
    
    # 方式2：SELECT :=`` 或 `INTO` 关键字
    SELECT @用户变量 := 表达式 [FROM 等子句];
    SELECT 表达式 INTO @用户变量 [FROM 等子句];
    
    SELECT @num := COUNT(*) FROM employees;
    ```

2. 查看用户变量的值

    ```sql
    SELECT @用户变量
    ```



### 局部变量(没有`@`)

1. 声明局部变量

    局部变量必须使用 `DECLARE` 声明

    ```sql
    #声明局部变量
    DECLARE 变量名1 变量数据类型 [DEFAULT 变量默认值];
    DECLARE 变量名2,变量名3,... 变量数据类型 [DEFAULT 变量默认值];
    ```

    ```sql
    CREATE PROCEDURE test()
    BEGIN
        DECLARE user_name VARCHAR(50);
        DECLARE user_age INT DEFAULT 0;
    
        SET user_name = '张三';
        SET user_age = 18;
    
        SELECT user_name, user_age;
    END;
    ```

2. 局部变量在存储过程的具体应用

    简化子查询的使用

    ```sql
    # 根据用户 ID 查询他的等级名称
    DELIMITER //
    
    CREATE PROCEDURE get_user_level(IN user_id INT)
    BEGIN
        DECLARE level_id INT;
        DECLARE level_name VARCHAR(50);
    
        SELECT level_id
        INTO level_id
        FROM user
        WHERE id = user_id;
    
        SELECT name
        INTO level_name
        FROM user_level
        WHERE id = level_id;
    
        SELECT level_name;
    END //
    
    DELIMITER ;
    ```



# 二、程序出错处理机制

> 错误处理一般在 **存储过程、储存函数、触发器、游标** 4个中使用；**普通 `SELECT/INSERT/UPDATE/DELETE` 不能直接声明 Handler**（那4个用的不多，所以大概率就是没啥用）

错误示例：`ERROR 1305 (42000): PROCEDURE sql_study_db.get_email does not exist`

`MySQL_error_code` 和 `sqlstate_value` 都可以表示 `MySQL` 的错误。

- `MySQL_error_code` 是数值类型错误代码（1305 ）
- `sqlstate_value` 是长度为5的字符串类型错误代码（42000）



### 定义错误名 `CONDITION`

```sql
# 方式1 根据 MySQL_error_code 数值类型的错误码 定义错误名
DECLARE 错误名称 CONDITION FOR 错误码;

DECLARE methods_not_exist CONDITION FOR 1305;
```

```sql
# 方式2 根据 sqlstate_value 字符串类型的错误码 定义错误名
DECLARE 错误名称 CONDITION FOR SQLSTATE 错误码;

DECLARE methods_not_exist CONDITION FOR SQLSTATE '42000';
```



## 定义处理程序 `HANDLER`

```sql
DECLARE 处理方式 HANDLER FOR 错误类型 处理语句

# 示例
DECLARE CONTINUE HANDLER FOR 1305 SET v_error = 1;
DECLARE CONTINUE HANDLER FOR SQLSTATE '23000' SET v_error = 1;
DECLARE CONTINUE HANDLER FOR user_not_found SET v_msg = '用户不存在';
```

处理方式有3个值

| 处理方式   | 出错后                                   |
| ---------- | ---------------------------------------- |
| `CONTINUE` | 处理错误后继续执行                       |
| `EXIT`     | 处理错误后退出当前代码块                 |
| `UNDO`     | 遇到错误撤回之前的操作，MySQL 中基本不用 |

错误类型

| 错误条件           | 含义             | 示例                                   |
| ------------------ | ---------------- | -------------------------------------- |
| `SQLSTATE`         | 字符串错误码     | `'23000'`：重复键                      |
| `MySQL` 错误码     | 数值类型错误码   | `1062`：重复键                         |
| 自定义 `CONDITION` | 自己定义的错误名 | `methods_not_exist`                    |
| `SQLWARNING`       | SQL 警告         | `01xxx`，`01` 开头的 `SQLSTATE` 错误码 |
| `NOT FOUND`        | 没有找到数据     | `02xxx`，`02` 开头的 `SQLSTATE` 错误码 |
| `SQLEXCEPTION`     | SQL 异常         | 非 `00xxx`、`01xxx`、`02xxx` 的错误    |

处理语句

| 处理语句        | 作用                   | 常见程度 | 示例                          |
| --------------- | ---------------------- | -------- | ----------------------------- |
| `SET`           | 修改变量、记录错误状态 | ⭐⭐⭐⭐⭐    | `SET v_error = 1;`            |
| `ROLLBACK`      | 回滚事务               | ⭐⭐⭐⭐⭐    | `ROLLBACK;`                   |
| `COMMIT`        | 提交事务               | ⭐        | `COMMIT;`                     |
| `SELECT`        | 查询/输出一些信息      | ⭐⭐       | `SELECT '发生错误';`          |
| `INSERT`        | 把错误信息记录到日志表 | ⭐⭐⭐⭐     | `INSERT INTO error_log ...`   |
| `UPDATE`        | 修改错误状态           | ⭐⭐⭐      | `UPDATE task SET status = 0;` |
| `SIGNAL`        | 主动抛出一个错误       | ⭐⭐⭐⭐     | `SIGNAL SQLSTATE '45000'...`  |
| `RESIGNAL`      | 重新抛出当前错误       | ⭐⭐⭐      | `RESIGNAL;`                   |
| `CALL`          | 调用其他存储过程       | ⭐⭐       | `CALL log_error();`           |
| `BEGIN ... END` | 执行多条处理语句       | ⭐⭐⭐⭐⭐    | 多条语句组合                  |

在存储过程中的具体应用

```sql
CREATE PROCEDURE transfer_money()
BEGIN

    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        ROLLBACK;       # 回滚
    END;

    START TRANSACTION;

    UPDATE account
    SET money = money - 100
    WHERE id = 1;

    UPDATE account
    SET money = money + 100
    WHERE id = 2;

    COMMIT;

END;
```



## `SIGNAL`

主动制造并抛出一个 SQL 异常，相当于 `javascript` 的 `throw new Error`

可以结合错误处理程序使用

```sql
SIGNAL SQLSTATE '错误状态码'       # 错误状态码 必须遵循 SQLSTATE 的格式和语义规则
SET MESSAGE_TEXT = '错误信息';

SIGNAL SQLSTATE '45000'
SET MESSAGE_TEXT = '薪资高于领导薪资错误';
```

| 属性              | 作用           | 常用程度 |
| ----------------- | -------------- | -------- |
| `SQLSTATE`        | SQL 状态码     | ⭐⭐⭐⭐⭐    |
| `MESSAGE_TEXT`    | 错误提示信息   | ⭐⭐⭐⭐⭐    |
| `MYSQL_ERRNO`     | MySQL 错误编号 | ⭐⭐⭐      |
| `CONSTRAINT_NAME` | 约束名称       | ⭐        |
| `TABLE_NAME`      | 表名           | ⭐        |
| `COLUMN_NAME`     | 列名           | ⭐        |
| `SCHEMA_NAME`     | 数据库名       | ⭐        |
| `CURSOR_NAME`     | 游标名称       | ⭐        |

```sql
SIGNAL SQLSTATE '45000'
SET
	MESSAGE_TEXT = '员工薪资校验失败',
    MYSQL_ERRNO = 10001,
    CONSTRAINT_NAME = 'uk_employee_salary',
    SCHEMA_NAME = 'company',
    TABLE_NAME = 'employee',
    COLUMN_NAME = 'salary';
```



# 三、流程控制

>**MySQL 流程控制主要用于存储过程、存储函数、触发器等程序对象中**
>
>普通的 `SELECT / INSERT / UPDATE / DELETE` 语句不能直接使用 `IF...ELSE`、`WHILE` 这种流程控制结构

1. **条件判断语句**：`IF`、`CASE`
2. **循环语句**：`WHILE`、`REPEAT`、`LOOP`
3. **跳转/退出语句**：`LEAVE`、`ITERATE`



## 1.`IF`

```sql
IF 条件 THEN
    SQL语句;
ELSEIF 条件 THEN
    SQL语句;
ELSE
    SQL语句;
END IF;           # 必须以 END IF; 结束
```

```sql
# 示例
DELIMITER //

CREATE PROCEDURE check_age(IN user_age INT)
BEGIN
    DECLARE result VARCHAR(20);

    IF user_age >= 18 THEN
        SET result = '成年人';
    ELSE
        SET result = '未成年人';
    END IF;

    SELECT result;
END //

DELIMITER ;
```



## 2.`CASE`

```sql
CASE 表达式
    WHEN 值1 THEN ...
    WHEN 值2 THEN ...
    WHEN 值3 THEN ...
END CASE;

CASE
    WHEN 条件1 THEN ...
    WHEN 条件2 THEN ...
    WHEN 条件3 THEN ...
END CASE;
```

```sql
# 举例
DECLARE result VARCHAR(10);

CASE level
    WHEN 1 THEN
        SET result = '普通用户';
    WHEN 2 THEN
        SET result = 'VIP用户';
    ELSE
        SET result = '未知';
END CASE;

CASE
    WHEN score >= 90 THEN
        SET level = '优秀';
    WHEN score >= 60 THEN
        SET level = '及格';
    ELSE
        SET level = '不及格';
END CASE;
```



## 3.`WHILE`

```sql
WHILE 条件 DO
    SQL语句;
END WHILE;
```

先判断条件，满足条件再执行

```sql
# 从 1 加到 5
DECLARE i INT DEFAULT 1;
DECLARE total INT DEFAULT 0;

WHILE i <= 5 DO
    SET total = total + i;
    SET i = i + 1;
END WHILE;
```



## 4.`REPEAT`

```sql
REPEAT
    SQL语句;
UNTIL 条件
END REPEAT;
```

`REPEAT` 和 `WHILE` 最大的区别：`REPEAT` 是先执行，再判断，至少会执行一次

```sql
DELIMITER //

CREATE PROCEDURE add_to_5()
BEGIN
	DECLARE i INT DEFAULT 10;

	REPEAT
		SET i = i + 1;       # 无论如何都会执行
	UNTIL i >= 5
	END REPEAT;
	
	SELECT i;     # 11
END //

DELIMITER ;

CALL add_to_5();
```



## 5.`LOOP`

```sql
# loop_label：标签名，可选
[loop_label:] LOOP
    SQL语句;
END LOOP [loop_label];
```

`LOOP` 是一个更加“原始”的循环，它**没有循环条件**，所以通常要配合 `LEAVE` 使用

```sql
DECLARE i INT DEFAULT 0;

my_loop: LOOP

    SET i = i + 1;

    IF i >= 5 THEN
        LEAVE my_loop;
    END IF;

END LOOP my_loop;
```





## 6.`LEAVE`(`break`)

```sql
LEAVE 标签名;
```

```sql
# 递增到 5
DECLARE i INT DEFAULT 0;

my_loop: LOOP

    SET i = i + 1;

    IF i >= 5 THEN
        LEAVE my_loop;
    END IF;

END LOOP my_loop;
```

嵌套循环，有需要可以直接退出外层的循环，内层的循环也会结束

```sql
outer_loop: LOOP

    inner_loop: LOOP

        SET i = i + 1;

        IF i = 3 THEN
            LEAVE outer_loop;     # 直接退出外层循环
        END IF;

    END LOOP inner_loop;

END LOOP outer_loop;
```



## 7.`ITERATE`(`continue`)

```sql
ITERATE 标签名;
```

```sql
# 递增到 5，3跳过
DECLARE i INT DEFAULT 0;

my_loop: LOOP

    SET i = i + 1;

    IF i = 3 THEN
        ITERATE my_loop;
    END IF;

    SET total = total + i;

    IF i >= 5 THEN
        LEAVE my_loop;
    END IF;

END LOOP my_loop;
```



# 四、游标 `Cursor`

游标，提供了一种灵活的操作方式，让我们能够对结果集中的每一条记录进行定位，并对指向的记录中的数据进行操作的数据结构。**游标让** **SQL** **这种面向集合的语言有了面向过程开发的能力**。

游标适合的场景：**游标主要用在存储过程、存储函数等存储程序中**，通常结合**循环**使用，尤其是需要**逐行处理查询结果**的场景



## 游标的使用方法

1. 声明游标`DECLARE CURSOR`

    ```sql
    DECLARE 游标名称 CURSOR FOR SELECT查询语句;
    ```

    ```sql
    DECLARE emp_cursor CURSOR FOR
        SELECT id, name, salary
        FROM employee;
    ```

2. 打开游标`OPEN`

    ```sql
    OPEN 游标名称;
    
    OPEN emp_cursor;
    ```

3. 使用游标`FETCH`

    ```sql
    FETCH emp_cursor
    INTO v_id, v_name, v_salary;
    ```

4. 关闭游标`CLOSE`

    ```sql
    CLOSE emp_cursor;
    ```



### 示例

```sql
# 功能：按照工资倒序排行后，取出前面累加工资超过 10w 元的员工人数
CREATE PROCEDURE count_salary()
BEGIN
    DECLARE done BOOLEAN DEFAULT FALSE;              # 声明结束标志
    DECLARE v_salary DECIMAL(10,2);                  # 工资
    DECLARE total_salary DECIMAL(10,2) DEFAULT 0;    # 总工资
    DECLARE total_count INT DEFAULT 0;               # 总人数

    -- ① 声明游标：工资倒序
    DECLARE cur CURSOR FOR
        SELECT salary
        FROM employee
        ORDER BY salary DESC;

    -- ② 读取完毕
    DECLARE CONTINUE HANDLER FOR NOT FOUND
        SET done = TRUE;

    -- ③ 打开游标
    OPEN cur;

    -- ④ 循环逐行读取
    read_loop: LOOP

		# 获取数据
        FETCH cur INTO v_salary;

        IF done THEN
            LEAVE read_loop;
        END IF;

        -- 累加工资和人数
        SET total_salary = total_salary + v_salary;
        SET total_count = total_count + 1;

        -- 超过10万就退出
        IF total_salary > 100000 THEN
            LEAVE read_loop;
        END IF;

    END LOOP;

    CLOSE cur;

    -- ⑤ 输出人数
    SELECT total_count AS 人数;

END;
```
