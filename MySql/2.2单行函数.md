# 单行函数

## 1.数值函数

### 基本函数

```sql
SELECT
ABS(-123),ABS(32),SIGN(-23),SIGN(43),PI(),CEIL(32.32),CEILING(-43.23),FLOOR(32.32),
FLOOR(-43.23),MOD(12,5)
FROM DUAL;
```

| 函数                    | 说明                                                         |
| ----------------------- | ------------------------------------------------------------ |
| `ABS(x)`                | 返回x的绝对值                                                |
| SIGN(x)                 | 返回X的符号。正数返回1，负数返回-1，0返回0                   |
| PI()                    | 返回圆周率的值                                               |
| `CEIL(x)`, `CEILING(x)` | 返回大于或等于某个值的最小整数                               |
| `FLOOR(x)`              | 返回小于或等于某个值的最大整数                               |
| `LEAST(e1,e2,e3…)`      | 返回列表中的最小值                                           |
| `GREATEST(e1,e2,e3…)`   | 返回列表中的最大值                                           |
| `MOD(x,y)`              | 返回X除以Y后的余数                                           |
| `RAND()`                | 返回0~1的随机值                                              |
| RAND(x)                 | 返回0~1的随机值，其中x的值用作种子值，相同的X值会产生相同的随机 |
| `ROUND(x)`              | 数返回一个对x的值进行四舍五入后，最接近于X的整数             |
| ROUND(x,y)              | 返回一个对x的值进行四舍五入后最接近X的值，并保留到小数点后面Y位 |
| `TRUNCATE(x,y)`         | 返回数字x截断为y位小数的结果                                 |
| `SQRT(x)`               | 返回x的平方根。当X的值为负数时，返回NULL                     |



### 角度与弧度呼唤函数

用再学

```sql
SELECT RADIANS(30), DEGREES(2*PI()), DEGREES(RADIANS(90))
FROM DUAL;
```

| 函数       | 说明                                  |
| ---------- | ------------------------------------- |
| RADIANS(x) | 将角度转化为弧度，其中，参数x为角度值 |
| DEGREES(x) | 将弧度转化为角度，其中，参数x为弧度值 |



### 三角函数

用再学

```sql
SELECT
SIN(RADIANS(30)), DEGREES(ASIN(1)), TAN(RADIANS(45)), DEGREES(ATAN(1)), DEGREES(ATAN2(1,1))
FROM DUAL;
```

| 函数       | 用法                                                         |
| ---------- | ------------------------------------------------------------ |
| SIN(x)     | 返回x的正弦值，其中，参数x为弧度值                           |
| ASIN(x)    | 返回x的反正弦值，即获取正弦为x的值。如果x的值不在-1到1之间，则返回NULL |
| COS(x)     | 返回x的余弦值，其中，参数x为弧度值                           |
| ACOS(x)    | 返回x的反余弦值，即获取余弦为x的值。如果x的值不在-1到1之间，则返回NULL |
| TAN(x)     | 返回x的正切值，其中，参数x为弧度值                           |
| ATAN(x)    | 返回x的反正切值，即返回正切值为x的值                         |
| ATAN2(m,n) | 返回两个参数的反正切值                                       |
| COT(x)     | 返回x的余切值，其中，X为弧度值                               |



### 指数与对数

```sql
SELECT POW(2,5), POWER(2,4), EXP(2), LN(10), LOG10(10), LOG2(4)

```

| 函数                     | 说明                                                 |
| ------------------------ | ---------------------------------------------------- |
| `POW(x,y,)` `POWER(X,Y)` | 返回x的y次方                                         |
| EXP(X)                   | 返回e的X次方，其中e是一个常数，2.718281828459045     |
| LN(X)，LOG(X)            | 返回以e为底的X的对数，当X <= 0 时，返回的结果为NULL  |
| LOG10(X)                 | 返回以10为底的X的对数，当X <= 0 时，返回的结果为NULL |
| LOG2(X)                  | 返回以2为底的X的对数，当X <= 0 时，返回NULL          |



### 进制转换

## 3.日期与时间函数

### 3.1获取日期、时间(`DATE`、`TIME`、`DATETIME`)

```sql
SELECT
CURDATE(), CURTIME(), NOW(), SYSDATE(), SYSDATE()+0, UTC_DATE(), UTC_DATE()+0, UTC_TIME(), UTC_TIME()+0
FROM DUAL;

# CURDATE(),  CURTIME(), NOW(),               SYSDATE()
# 2026-08-05  16:33:05   2026-08-05 16:33:05  2026-08-05 16:33:05
```

| 函数                                                         | 说明                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| **`CURDATE()`**,<br />`CURRENT_DATE()`                       | 返回当前日期，只包含**年、月、日**，返回类型是`DATE`         |
| **`CURTIME()`**,<br />`CURRENT_TIME()`                       | 返回当前时间，只包含**时、分、秒**，返回类型是`TIME`         |
| **`NOW()`**,<br />**`SYSDATE()`**,<br />`CURRENT_TIMESTAMP()`,<br />`LOCALTIME()`,<br />`LOCALTIMESTAMP()` | 返回当前系统日期和时间（包含日期和时间），返回类型是`DATETIME` |
| **`UTC_DATE()`**                                             | 返回 UTC（世界协调时间）日期                                 |
| **`UTC_TIME()`**                                             | 返回 UTC（世界协调时间）时间                                 |



### 3.2日期与时间戳的转换(`BIGINT`、`DATETIME`)

```sql
# 日期转秒数
SELECT UNIX_TIMESTAMP(now()) FROM DUAL;          # 1785918742

# 秒数转日期
SELECT FROM_UNIXTIME(1785913854) FROM DUAL;      # 2026-08-05 15:10:54
```

| 函数                                            | 说明                                                         |
| ----------------------------------------------- | ------------------------------------------------------------ |
| `UNIX_TIMESTAMP()`,<br />`UNIX_TIMESTAMP(date)` | 将日期或时间 `date` 转换为 UNIX 时间戳。<br />例如：`SELECT UNIX_TIMESTAMP();` → `1634348884`（返回秒数，不是毫秒）<br />返回值类型是**`BIGINT`** |
| `FROM_UNIXTIME(timestamp)`                      | 将 UNIX 时间戳转换为普通格式的日期时间<br />返回值类型是`DATETIME` |



### 3.3获取月份、星期、星期数、天数等函数

```sql
SELECT YEAR(CURDATE()), MONTH(CURDATE()), DAY(CURDATE()), HOUR(CURTIME()), MINUTE(NOW()), SECOND(SYSDATE())
FROM DUAL;          # 2026 8 5 16 22 50
```

| 函数                                                   | 说明                                             |
| ------------------------------------------------------ | ------------------------------------------------ |
| `YEAR(date)`,<br />`MONTH(date)`,<br />`DAY(date)`     | 返回日期的年份、月份（1-12）、日期               |
| `HOUR(time)`,<br />`MINUTE(time)`,<br />`SECOND(time)` | 返回时间的小时、分钟、秒                         |
| `MONTHNAME(date)`                                      | 返回月份名称，如 `January`、`February` 等        |
| `DAYNAME(date)`                                        | 返回星期名称，如 `Monday`、`Tuesday` …… `Sunday` |
| `WEEKDAY(date)`                                        | 返回星期索引，**周一=0，周二=1，…… 周日=6**      |
| `QUARTER(date)`                                        | 返回日期所在季度，取值范围 **1～4**              |
| `WEEK(date)`,<br />`WEEKOFYEAR(date)`                  | 返回日期是一年中的第几周                         |
| `DAYOFYEAR(date)`                                      | 返回日期是一年中的第几天                         |
| `DAYOFMONTH(date)`                                     | 返回日期是当月的第几天                           |
| `DAYOFWEEK(date)`                                      | 返回星期索引，**周日=1，周一=2，…… 周六=7**      |



### 3.4日期的操作函数

和 3.3 好像是差不多的，挑一个记应该就行

`EXTRACT(type FROM date)` 用于从日期或时间中提取指定部分，返回一个**整数值**。

```sql
SELECT
EXTRACT(YEAR FROM NOW()), EXTRACT(MONTH FROM NOW()), EXTRACT(DAY FROM NOW()),         # 2026 8 5
EXTRACT(HOUR FROM NOW()), EXTRACT(MINUTE FROM NOW()), EXTRACT(SECOND FROM NOW())      # 16 22 19
FROM DUAL;
```

| 函数                      | 说明                                       |
| ------------------------- | ------------------------------------------ |
| `EXTRACT(type FROM date)` | 返回指定日期中特定的部分，type指定返回的值 |

| type取值             | 说明                     | 示例                                                         |
| -------------------- | ------------------------ | ------------------------------------------------------------ |
| `YEAR`               | 年（最常用）             | `EXTRACT(YEAR FROM '2026-08-05')` → `2026`                   |
| `MONTH`              | 月（1~12）               | `EXTRACT(MONTH FROM '2026-08-05')` → `8`                     |
| `DAY`                | 日（1~31）               | `EXTRACT(DAY FROM '2026-08-05')` → `5`                       |
| `HOUR`               | 小时（0~23）             | `EXTRACT(HOUR FROM '2026-08-05 14:30:20')` → `14`            |
| `MINUTE`             | 分钟（0~59）             | `EXTRACT(MINUTE FROM '2026-08-05 14:30:20')` → `30`          |
| `SECOND`             | 秒（0~59）               | `EXTRACT(SECOND FROM '2026-08-05 14:30:20')` → `20`          |
| `QUARTER`            | 季度（1~4）              | `EXTRACT(QUARTER FROM '2026-08-05')` → `3`                   |
| `WEEK`               | 一年中的第几周           | `EXTRACT(WEEK FROM '2026-08-05')`                            |
| `DAY_HOUR`           | 日和小时                 | `EXTRACT(DAY_HOUR FROM '2026-08-05 14:30:20')` → `514`       |
| `DAY_MINUTE`         | 日、小时和分钟           | `EXTRACT(DAY_MINUTE FROM '2026-08-05 14:30:20')` → `51430`   |
| `DAY_SECOND`         | 日、小时、分钟和秒       | `EXTRACT(DAY_SECOND FROM '2026-08-05 14:30:20')` → `5143020` |
| `HOUR_MINUTE`        | 小时和分钟               | `EXTRACT(HOUR_MINUTE FROM '2026-08-05 14:30:20')` → `1430`   |
| `HOUR_SECOND`        | 小时、分钟和秒           | `EXTRACT(HOUR_SECOND FROM '2026-08-05 14:30:20')` → `143020` |
| `MINUTE_SECOND`      | 分钟和秒                 | `EXTRACT(MINUTE_SECOND FROM '2026-08-05 14:30:20')` → `3020` |
| `YEAR_MONTH`         | 年和月                   | `EXTRACT(YEAR_MONTH FROM '2026-08-05')` → `202608`           |
| `MICROSECOND`        | 微秒                     | `EXTRACT(MICROSECOND FROM '2026-08-05 14:30:20.123456')` → `123456` |
| `SECOND_MICROSECOND` | 秒和微秒                 | `EXTRACT(SECOND_MICROSECOND FROM '2026-08-05 14:30:20.123456')` |
| `MINUTE_MICROSECOND` | 分钟、秒和微秒           | `EXTRACT(MINUTE_MICROSECOND FROM '2026-08-05 14:30:20.123456')` |
| `HOUR_MICROSECOND`   | 小时、分钟、秒和微秒     | `EXTRACT(HOUR_MICROSECOND FROM '2026-08-05 14:30:20.123456')` |
| `DAY_MICROSECOND`    | 日、小时、分钟、秒和微秒 | `EXTRACT(DAY_MICROSECOND FROM '2026-08-05 14:30:20.123456')` |

### 3.6计算日期和时间的函数

```sql
SELECT
ADDDATE(NOW(),INTERVAL 1 DAY) AS col1,

DATE_ADD(NOW(), INTERVAL 1 DAY) AS col2,
DATE_ADD(NOW(),INTERVAL 1 SECOND) AS col3,
DATE_ADD(NOW(), INTERVAL -1 YEAR) AS col4,               #可以是负数
DATE_ADD(NOW(), INTERVAL '1_1' YEAR_MONTH) AS col6,      #需要单引号
DATE_ADD(NOW(),INTERVAL '1_1' MINUTE_SECOND) AS col5
FROM DUAL;

SELECT
ADDTIME(NOW(),20), SUBTIME(NOW(),30)
FROM DUAL;

SELECT
DATEDIFF(NOW(),'2026-08-01'),            # 4
TIMEDIFF(NOW(),'2026-08-05 0:0:0')       # 16:21:37
FROM DUAL;
```

| 函数                                                         | 说明                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| `DATE_ADD(date, INTERVAL expr type)`,<br />**`ADDDATE(date, INTERVAL expr type)`** | 返回在给定日期或时间基础上**增加** `INTERVAL` 时间间隔后的日期时间<br />date可以是`DATE`、`DATETIME`、`TIMESTAMP` |
| `DATE_SUB(date, INTERVAL expr type)`,<br />`SUBDATE(date, INTERVAL expr type)` | 返回在给定日期或时间基础上**减少** `INTERVAL` 时间间隔后的日期时间 |
| `ADDTIME(time1,time2)`                                       | 返回time1加上time2的时间。当time2为一个数字时，代表的是 **秒** ，可以为负数 |
| `SUBTIME(time1,time2)`                                       | 返回time1减去time2后的时间。当time2为一个数字时，代表的是 **秒** ，可以为负数 |
| **`DATEDIFF(date1,date2)`**                                  | 返回date1 - date2的日期间隔天数                              |
| `TIMEDIFF(time1, time2)`                                     | 返回time1 - time2的时间间隔；返回格式（24:00:00）            |
| `FROM_DAYS(N)`                                               | 返回从0000年1月1日起，N天以后的**日期**                      |



### 3.7日期的格式化与解析

```sql
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:%i:%s') FROM DUAL;     # 2026-08-05 16:20:32

SELECT DATE_FORMAT(CURTIME(), '%H:%i:%s') FROM DUAL;          # 16:20:32

SELECT STR_TO_DATE('2000-01-01 12:00:00','%Y-%m-%d %H:%i:%s') FROM DUAL;      # 2000-01-01 12:00:00
SELECT STR_TO_DATE('09/01/2008','%m/%d/%Y') FROM DUAL;                       # 2008-09-01

SELECT GET_FORMAT(DATETIME,'ISO') FROM DUAL;                  # %Y-%m-%d %H:%i:%s

# 应用
SELECT DATE_FORMAT(NOW(), GET_FORMAT(DATETIME,'ISO')) FROM DUAL;             # 2026-08-05 18:05:31
```

| 函数                                 | 说明                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| `DATE_FORMAT(date, fmt)`             | 按照字符串 `fmt` 格式化日期 `date` 值；返回值类型`VARCHAR`   |
| `TIME_FORMAT(time, fmt)`             | 按照字符串 `fmt` 格式化时间 `time` 值；返回值类型`VARCHAR`   |
| `GET_FORMAT(date_type, format_type)` | 返回值是一个**格式模板字符串**；返回值类型`VARCHAR`          |
| **`STR_TO_DATE(str, fmt)`**          | 按照字符串 `fmt` 对 `str` 进行解析，将其转换为日期类型；返回值类型`DATE` 或 `DATETIME` |

| `fmt`格式符 | 说明                                          | `fmt`格式符     | 说明                                          |
| ----------- | --------------------------------------------- | --------------- | --------------------------------------------- |
| **`%Y`**    | 4 位数字年份                                  | `%y`            | 2 位数字年份                                  |
| `%M`        | 月份名称（January、February……）               | **`%m`**        | 两位数字表示月份（01、02、03……）              |
| `%b`        | 缩写的月份名称（Jan、Feb……）                  | `%c`            | 数字表示月份（1、2、3……）                     |
| `%D`        | 英文后缀表示月份中的天数（1st、2nd、3rd……）   | **`%d`**        | 两位数字表示月份中的天数（01、02……）          |
| `%e`        | 数字形式表示月份中的天数（1、2、3……）         |                 |                                               |
| **`%H`**    | 两位数字表示小时，24 小时制（00、01、02……）   | `%h` / `%I`     | 两位数字表示小时，12 小时制（01、02……）       |
| `%k`        | 数字形式的小时，24小时制(1,2,3)               | `%l`            | 数字形式表示小时，12 小时制（1、2、3……）      |
| **`%i`**    | 两位数字表示分钟（00,01,02）                  | **`%S` / `%s`** | 两位数字表示秒（00、01、02……）                |
| `%W`        | 一周中的星期名称（Sunday...）                 | `%a`            | 星期缩写（Sun、Mon、Tues……）                  |
| `%w`        | 数字表示星期几（0=Sunday，1=Monday……）        |                 |                                               |
| `%j`        | 3 位数字表示一年中的第几天（001、002……）      | `%U`            | 数字表示一年中的第几周（Sunday 为一周第一天） |
| `%u`        | 数字表示一年中的第几周（Monday 为一周第一天） |                 |                                               |
| `%T`        | 24 小时制时间（HH:MM:SS）                     | `%r`            | 12 小时制时间（hh:mm:ss AM/PM）               |
| `%p`        | AM 或 PM                                      | `%%`            | 表示百分号 `%`                                |

`GET_FORMAT(date_type, format_type)` 返回指定日期类型和格式化类型对应的格式字符串。

| 日期类型`date_type` | 格式化类型`format_type` | 返回的格式化字符串  |
| ------------------- | ----------------------- | ------------------- |
| `DATE`              | `USA`                   | `%m.%d.%Y`          |
| `DATE`              | `JIS`                   | `%Y-%m-%d`          |
| `DATE`              | `ISO`                   | `%Y-%m-%d`          |
| `DATE`              | `EUR`                   | `%d.%m.%Y`          |
| `DATE`              | `INTERNAL`              | `%Y%m%d`            |
| `TIME`              | `USA`                   | `%h:%i:%s %p`       |
| `TIME`              | `JIS`                   | `%H:%i:%s`          |
| `TIME`              | `ISO`                   | `%H:%i:%s`          |
| `TIME`              | `EUR`                   | `%H.%i.%s`          |

## 4.流程控制函数

| 函数                                                         | 说明                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| `IF(value, value1, value2)`                                  | 如果 `value` 的值为 `TRUE`，返回 `value1`；否则返回 `value2` |
| `IFNULL(value1, value2)`                                     | 如果 `value1` 不为 `NULL`，返回 `value1`；否则返回 `value2`  |
| `CASE`<br />    WHEN 条件1 THEN 结果1<br />    WHEN 条件2 THEN 结果2<br />    ...<br />    [ELSE resultn]<br />    END | 类似 Java 中的 `if...else if...else`，根据不同条件返回对应结果 |
| `CASE expr WHEN 常量值1 THEN 值1 WHEN 常量值2 THEN 值2 ... [ELSE 值n] END` | 类似 Java 中的 `switch...case...`，根据表达式匹配不同值返回对应结果 |

```sql
SELECT IF(1 > 0,'正确','错误');        # 正确

SELECT IFNULL(null,'Hello Word');     # Hello Word

# 1 > 0
SELECT CASE
	WHEN 1 > 0
	THEN '1 > 0'
	WHEN 2 > 0
	THEN '2 > 0'
	ELSE '3 > 0'
	END "结果是"        # 结果是 -> 自定义列名
FROM DUAL;
```



## 5.加密与解密函数

```sql
SELECT MD5('mysql'), SHA('mysql'), SHA2('mysql', 256) FROM DUAL;
```

| 函数                           | 说明                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| `PASSWORD(str)`                | 返回字符串 `str` 的加密版本，生成 41 位字符串。**加密结果不可逆**，常用于密码加密<br />返回值类型`VARCHAR`<br />（MySQL 5.x 常用，MySQL 8.0 已废弃） |
| `MD5(str)`                     | 返回字符串 `str` 的 MD5 加密结果。如果参数为 `NULL`，返回 `NULL`<br />返回值类型`VARCHAR`（32 位十六进制字符串） |
| `SHA(str)`                     | 根据明文 `str` 计算并返回 SHA 加密后的字符串。如果参数为 `NULL`，返回 `NULL`。相比 MD5 安全性更高<br />返回值类型`VARCHAR`（40 位十六进制字符串，SHA-1） |
| `ENCODE(value, password_seed)` | 使用 `password_seed` 作为加密密码，对 `value` 进行加密<br />返回值类型`VARBINARY`（二进制数据）<br />（MySQL 8.0.3 已废弃） |
| `DECODE(value, password_seed)` | 使用 `password_seed` 作为解密密码，对 `value` 进行解密<br />返回值类型`VARBINARY` / 字符串（二进制解密结果）<br />（MySQL 8.0.3 已废弃） |

### 注意

- `PASSWORD()` **不推荐用于业务密码存储**，MySQL 8.0 已移除该函数。
- MD5、SHA-1 都属于**不可逆哈希算法**，不能解密。
- 现代应用密码存储建议使用：
    - `bcrypt`
    - `scrypt`
    - `Argon2`
    - `PBKDF2`

数据库中一般**不直接使用 MySQL 内置加密函数保存用户密码**



## MySQL信息函数

```sql
SELECT VERSION();                 # 8.0.46

SELECT CONNECTION_ID();           # 8

SELECT USER(), CURRENT_USER();    # root@localhost

SELECT CHARSET('Hello') AS charset, COLLATION('Hello') AS collation;     # utf8mb4 utf8mb4_0900_ai_ci
```

| 函数                                                         | 说明                                                |
| ------------------------------------------------------------ | --------------------------------------------------- |
| `VERSION()`                                                  | 返回当前 MySQL 服务器的版本号                       |
| `CONNECTION_ID()`                                            | 返回当前连接的连接 ID（Connection ID）              |
| `DATABASE()`,<br />`SCHEMA()`                                | 返回当前默认数据库名称                              |
| `USER()`,<br />`CURRENT_USER()`,<br />`SYSTEM_USER()`,<br />`SESSION_USER()` | 返回当前连接 MySQL 的用户名，格式为 `用户名@主机名` |
| `CHARSET(value)`                                             | 返回字符串 `value` 的字符集（Character Set）        |
| `COLLATION(value)`                                           | 返回字符串 `value` 的排序规则（Collation）          |



## 其他函数

```sql
SELECT FORMAT(1234567.89123, 2);        # 1,234,567.89

SELECT CONV(15, 10, 2);                 # 1111

SELECT INET_ATON('192.168.1.1');        # 3232235777

SELECT BENCHMARK(1000000, MD5('mysql'));

SELECT CONVERT('Hello' USING utf8mb4);  # Hello
```

| 函数                             | 说明                                                         |
| -------------------------------- | ------------------------------------------------------------ |
| `FORMAT(value, n)`               | 返回对数字 `value` 进行格式化后的结果，按**四舍五入**保留 `n` 位小数，并添加千位分隔符，和`ROUND(x, y)`函数相似<br />返回值类型`VARCHAR` |
| `CONV(value, from, to)`          | 将 `value` 在不同进制之间进行转换（`from` 为原进制，`to` 为目标进制）<br />返回值类型`VARCHAR` |
| `INET_ATON(ipvalue)`             | 将点分十进制 IP 地址转换为整数<br />返回值类型`INT UNSIGNED` |
| `INET_NTOA(value)`               | 将整数形式的 IP 地址转换为点分十进制 IP 地址<br />返回值类型`VARCHAR` |
| `BENCHMARK(n, expr)`             | 将表达式 `expr` 重复执行 `n` 次，用于测试 MySQL 执行表达式所耗费的时间，可以在navicat下面的 查询时间 处查看耗费时间<br />`BENCHMARK()` 的返回值始终为 `0`，主要用于测试表达式执行性能。<br />返回值类型`INT` |
| `CONVERT(value USING char_code)` | 将字符串 `value` 的字符集转换为 `char_code` 指定的字符集     |
