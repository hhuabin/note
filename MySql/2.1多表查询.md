# 多表查询

开发规范：考虑到性能问题，超过三个表禁止使用`JOIN`



## 内连接（两表的交集）

以后直接使用 `SQL99` 的语法就行

```sql
# SQL92 语法；隐式内连接
SELECT *
FROM TableA, TableB
WHERE TableA.id = TableB.id;

# SQL99 语法用 JOIN ... ON ...；显示内连接（INNER 可以省略）
SELECT *
FROM TableA
INNER JOIN TableB
ON TableA.id = TableB.id;
```

多表连接（TableA, TableB, TableC）

```sql
SELECT *
FROM TableA, TableB, TableC
WHERE TableA.id = TableB.id
AND TableB.name = TableC.name;

SELECT *
FROM TableA
INNER JOIN TableB
ON TableA.id = TableB.id
JOIN TableC
ON TableB.name = TableC.name;
```

自连接

```sql
SELECT A.id, B.name
FROM TableA A, TableB B
WHERE A.id = B.id;
```



## 左外连接（左表全保留，右表不匹配的字段返回`Null`）

```sql
# SQL99语法才有，OUTER可以省略
SELECT *
FROM TableA
LEFT OUTER JOIN TableB
ON TableA.id = TableB.id;
```



## 右外连接（右表全保留，左表不匹配的字段返回`Null`）

```sql
# # SQL99语法才有，OUTER可以省略
SELECT *
FROM TableA
RIGHT OUTER JOIN TableB ON TableA.id = TableB.id;
```



## 满外连接

`MySql` 用（`MySql` 不支持 `FULL OUTER JOIN`）

```sql
SELECT *
FROM TableA
LEFT JOIN TableB
ON TableA.id = TableB.id

# UNION ALL      # 不去重
UNION          # 去重，由于是在 UNION ALL 的基础上去重，所以效率会比较低

SELECT *
FROM TableA
RIGHT JOIN TableB
ON TableA.id = TableB.id;
```

```sql
# UNION ALL 效率高的写法
SELECT *
FROM TableA
LEFT JOIN TableB
ON TableA.id = TableB.id
UNION ALL      # 不去重
SELECT *
FROM TableA
RIGHT JOIN TableB
ON TableA.id = TableB.id
WHERE TableA.id IS NULL;
# WHERE 最好放第个JOIN，这样最终的表顺序与 UNION 才对的上
```

`Oracle` 用

```sql
SELECT *
FROM TableA
FULL OUTER JOIN TableB
ON TableA.id = TableB.a_id;
```

### 注意

1. 如果查询语句中出现了多个表中都存在的字段，则必须指明此字段所在的表

    ```sql
    SELECT TableA.a, TableB.a
    FROM TableA
    INNER JOIN TableB
    ON TableA.id = TableB.id;
    
    # 简化写法也可以使用表别名
    # 如果给表起了别名，一旦在SELECT或WHERE中使用表名的话，则必须使用表的别名，而不能再使用表的原名
    SELECT A.a, B.a
    FROM TableA A
    INNER JOIN TableB B
    ON A.id = B.id;
    ```




## 自然连接

一般不用，不好控制，我的开发中禁止使用

**自动查询两张连接表中所有相同的字段，然后进行 等值连接；**比如两个表都有`id`、`name`字段，它会自动按照这两个字段相等做连接

```sql
# 写法
SELECT *
FROM TableA
NATURAL JOIN TableB;
```

如果两表没有相同字段，相当于

```sql
SELECT *
FROM TableA
JOIN TableB
ON 1 = 1;
```



## USING

省略连接条件，简写而已

```SQL
# 按照 id 相等连接
SELECT *
FROM TableA
JOIN TableB
USING (id);
```
