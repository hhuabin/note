# 表的关联关系

1.   一对一关联
2.   一对多关联
3.   多对多关联
4.   自我引用



# INSERT 插入

```sql
# 按顺序插入所有列
INSERT INTO tableName VALUES ('', 1);

# 批量插入
INSERT INTO tableName (col1, col2)
VALUES 
    (v1, v2),
    (v3, v4);
```



# UPDATE 改

```sql
UPDATE tableName
SET col1 = value1, col2 = value2
WHERE condition;

```



# DELETE 删除

```sql
DELETE FROM tableName WHERE condition;
```
