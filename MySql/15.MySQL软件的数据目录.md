# `Windows`

数据库存储位置：在安装目录下的 `ProgramData` 中：`MySQL\ProgramData\MySQL Server 8.0\Data`

配置文件存储路径：在安装目录下的 `ProgramData` 中：`MySQL\ProgramData\MySQL Server 8.0\my.ini`

环境变量目录：在安装目录下的 `MySQL Server 8.0` 中：`MySQL\MySQL Server 8.0\bin`



# `Linux`

1. 查看 `MySQL` 相关的目录

    ```shell
    find / -name mysql
    ```

2. 数据库存储位置：`/data/mysql/`，安装时配置的

    ```shell
    # sql
    SHOW VARIABLES LIKE '%datadir%';
    
    ll /data/mysql/
    ```

3. 配置文件存储路径：`/etc/my.cnf`，安装时配置的

    ```shell
    vim /etc/my.cnf
    ```

4. 环境变量：`/etc/profile`，安装时配置的

    ```shell
    vim /etc/profile
    ```



# 数据库和文件系统的关系

## `MySQL` 的默认数据库

1. `mysql`：用户、权限、`MySQL` 系统管理信息；如 `user` 表

    ```sql
    # 查看用户
    SELECT * FROM mysql.user;
    ```

2. `information_schema`：`MySQL` 性能监控数据；如存储过程、触发器等

    ```sql
    # 查看所有数据库
    SELECT * 
    FROM information_schema.SCHEMATA;
    ```

3. `performance_schema`：`MySQL` 性能监控数据；如 `SQL` 执行情况

4. `sys`：对 `performance_schema` 的进一步封装，对性能数据进行更友好的展示

    ```sql
    # 查看正在执行的事务
    SELECT *
    FROM sys.innodb_trx;
    ```
