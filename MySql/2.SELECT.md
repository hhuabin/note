```sql
SELECT column1, column2, ...       # 查询字段 SELECT name, age

FROM tableName                     # 表名 FROM user u 列别名卸载列名后
[(LEFT / RIGHT) JOIN table2 ON condition]      # 连表 JOIN employee ON user.id = employee.id
[WHERE condition]                  # 连表条件 WHERE salary > 5000
[GROUP BY column]                  # 分组 GROUP BY user
[HAVING condition(聚合函数)]        # 分组后过滤 HAVING COUNT(*) > 3

[ORDER BY column ASC|DESC, ...]    # 排序 ORDER BY age DESC, name ASC;
[LIMIT offset, size];              # 分页 LIMIT 0, 10; 从第一条开始查10条
```

上表三部分的执行顺序

`FROM` -> `SELECT` -> `ORDER BY`

具体的顺序

`FROM` -> `ON` -> `(LEFT / RIGHT) JOIN` -> `WHERE` -> `GROUP BY` -> `HAVING` -> `SELECT` -> `DISTINCT` -> `ORDER BY` -> `LIMIT`

## `SELECT`语句中的关键字

#### 1.(字段)列别名

查出来的列表头会显示列别名

**列别名只能在`ORDER BY`中使用，不能在`WHERE`中使用**，因为 `FROM` 比 `SELECT` 先执行

1.   跟在列名后面

     ```sql
     SELECT name n FROM user;
     ```

2.   `AS`(alias)关键字

     ```sql

     ```

3.   `""`双引号，不要使用单引号（比第一种可以支持更多场景，比如可以支持空格了！）


```sql

SELECT DISTINCT name, age FROM user;
```

## `ORDER BY`排序

### 单列排序

```sql
# 默认升序
SELECT * FROM t_emp
ORDER BY emp_id;

# ASC 升序
SELECT * FROM t_emp
ORDER BY emp_id ASC;

# DESC 降序
SELECT * FROM t_emp
ORDER BY emp_id DESC;
```

### 多列排序

```sql
# , 分隔
# 先排 emp_id，emp_id有重复的再根据 emp_salary DESC 排列
SELECT * FROM t_emp
ORDER BY emp_id, emp_salary DESC;
```



## `LIMIT`分页

从 `PageNo` 开始取 `PageSize` 条数据（`PageNo` 从 0 开始）

**`PageNo` 写负数会报错；**`PageNo = 0` 时可以省略，当然不省最好，可读性好一些

```sql
LIMIT [位置偏移量,] 行数
```

```sql
SELECT * FROM table
LIMIT (PageNo - 1)*PageSize, PageSize;   # 前端一般是 (2, 10)，表示第二页，每页10条；写 sql 就是 (10, 20)
```

```sql
# 从第11条开始查10条（0是第一条）
SELECT * FROM 表名 LIMIT 10, 10;
```



### `OFFSET`

`MySql 8.0 `新特性，一般不用

```sql
# 从 21 条开始取 10 条 (就是顺序调换而已)
SELECT * FROM 表名 LIMIT 10 OFFSET 20;
```



### `Oracle`

`LIMIT` 不能在 `Oracle` 数据库中使用

1. `Oracle` 中可以使用 `ROWNUM` 和子查询配合做分页

    ```sql
    # 只取前面写法最简单
    SELECT *
    FROM emp
    WHERE ROWNUM <= 10;
    
    # 分页
    SELECT *
    FROM (
        SELECT t.*, ROWNUM rn
        FROM (
            SELECT *
            FROM emp
            ORDER BY id
        ) t
        WHERE ROWNUM <= 20
    )
    WHERE rn > 10;
    ```

2. `ROW_NUMBER()`

    ```sql
    SELECT *
    FROM (
        SELECT
            e.*,
            ROW_NUMBER() OVER (ORDER BY id) rn
        FROM emp e
    )
    WHERE rn BETWEEN 11 AND 20;
    ```

---

`Oracle 12c` 开始就有分页语法了

```sql
查询前10条
SELECT *
FROM emp
FETCH FIRST 10 ROWS ONLY;

# 查询第21~30条
SELECT *
FROM emp
ORDER BY id
OFFSET 20 ROWS
FETCH NEXT 10 ROWS ONLY;
```



## 聚合函数

### 常见聚合函数

（注意`NULL`值的问题，不做处理一般都是忽略统计的）

| 函数      | 说明                                                         |
| --------- | ------------------------------------------------------------ |
| `COUNT()` | 统计记录数（返回非 `NULL` 值或记录总数）；<br />返回值类型 `BIGINT` |
| `SUM()`   | 计算数值列的总和；<br />返回与参数类型相关（整数返回整数，小数返回 `DECIMAL`） |
| `AVG()`   | 计算数值列的平均值（返回非 `NULL` 值或记录的平均值）；<br />返回 `DECIMAL` / `DOUBLE`（根据参数类型决定） |
| `MAX()`   | 返回指定列的最大值；可以用于数值类型、字符串类型、日期时间类型<br />返回值与参数类型相同 |
| `MIN()`   | 返回指定列的最小值；<br />返回值与参数类型相同               |

```sql
SELECT MAX(emp_id) FROM t_emp;

SELECT COUNT(*) FROM t_emp;                     # 计算包含 NULL 值的记录总数，MyISAM、InnoDB引擎都是这个效率最高，以后用 COUNT(*) 统计总数即可
SELECT COUNT(1) FROM t_emp;                     # 计算包含 NULL 值的记录总数
SELECT COUNT(IFNULL(id, 0)) FROM t_emp;         # 计算包含 NULL 值的记录总数，或者使用必填的字段值也可以
```

聚合函数大都会不统计`NULL`值的列

```sql
# 如果有两行记录，分别为 1, NULL；最后的平均值是0.5，而不是1
SELECT AVG(IFNULL(num, 0)) FROM t_emp;          # 把 NULL 当作 0 一起统计进去，就可以统计所有的记录了
```



### `GROUP BY`分组

1. 单列分组

    ```sql
    SELECT department_id, AVG(salary)
    FROM employees
    GROUP BY department_id ;
    ```

2. 多列分组

    ```sql
    SELECT department_id, job_id, AVG(salary)
    FROM employees
    GROUP BY department_id, job_id;
    ```

==聚合函数需要配合 **聚合列** 使用，如果出现 非聚合列 的字段，报错（老版本的好像不会报错）==

`SELECT`中声明的非组函数字段，必须声明在`GROUP BY`中，`GROUP BY` 中只能多不能少

```sql
# 报错；username 不是聚合列
SELECT username, AVG(age) FROM ssm_user;
```

```sql
# 通过；username 是聚合列
SELECT username, AVG(age)
FROM ssm_user
GROUP BY username;
```



##### `WITH ROLLUP`

使用 `WITH ROLLUP` 关键字之后，在所有查询出的分组记录之后**增加一条记录**，该记录计算查询出的所有记录的总和，即统计记录数量

注意：当使用 `ROLLUP` 时，不能同时使用 `ORDER BY` 子句进行结果排序，即 **`ROLLUP` 和 `ORDER BY` 是互相排斥的**

```sql
SELECT dept, SUM(salary) AS total_salary
FROM emp
GROUP BY dept WITH ROLLUP;

# dept     total_salary
# 开发部    22000
# NULL     2200             # 这行是 WITH ROLLUP 增加的统计
```



注意事项

1. `WITH ROLLUP` **必须跟在 `GROUP BY` 后面**。

    ```sql
    GROUP BY dept WITH ROLLUP
    ```

2. **`ROLLUP` 和 `ORDER BY` 是互相排斥的**

3. 汇总行中的分组字段会显示为 `NULL`。

    这里需要注意 `GROUP BY dept`，`dept` 值为 `NULL` 的情况 

4. 汇总只对**聚合函数**（如 `COUNT()`、`SUM()`、`AVG()`、`MAX()`、`MIN()`）有意义。

5. 如果 `WITH ROLLUP` 统计了多列，那么会自右向左逐级统计，具体记不住

6. 在 **Oracle ** 中，更推荐使用标准 SQL 的 `ROLLUP()` 语法：

    ```sql
    GROUP BY ROLLUP(dept)
    ```

    它与下句作用相同，但属于 SQL 标准语法，兼容性更好。

    ```sql
    GROUP BY dept WITH ROLLUP
    ```



### `HAVING`

1. **`HAVING` 用于对分组后的结果进行过滤。**
2. `HAVING` 通常配合 `GROUP BY` 使用，`HAVING` 在 `GROUP BY` 之后执行。
3. `HAVING` 中可以使用聚合函数（如 `COUNT()`、`SUM()`、`AVG()` 等）。
4. 满足 `HAVING` 条件的分组才会被返回。

```sql
SELECT dept, SUM(salary)
FROM employees
GROUP BY dept
HAVING SUM(salary) > 1000000;
```

```sql
# 这种写法意义不大，有的时候也可以使用 WHERE 代替，WHERE的效率更高，HAVING 还是要配合 GROUP BY 使用
SELECT SUM(salary)
FROM employees
HAVING SUM(salary) > 1000000;
```

当过滤条件中有聚合函数，必须使用`HAVING`；没有聚合函数，统统使用`WHERE`，`WHERE` 效率更高

| `WHERE`           | `HAVING`          |
| ----------------- | ----------------- |
| 分组前过滤        | 分组后过滤        |
| 不能使用聚合函数  | 可以使用聚合函数  |
| 可单独使用        | 可单独使用        |
| `GROUP BY` 前执行 | `GROUP BY` 后执行 |
