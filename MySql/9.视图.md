# 视图

**视图（View）是一个虚拟表**：它不是一个真正独立存储数据的表，而是根据一个 `SELECT` 查询定义出来的，可以将视图理解为 **存储起来的查询语句**

1. **虚拟表**：视图使用起来像表
2. **查询定义**：视图本质上保存的是 `SELECT` 查询，所以**视图并不会提升查询性能，只是会简化使用而已**
3. **依赖底层表**：视图建立在已有表的基础上, 视图赖以建立的这些表称为**基表**
4. **封装查询**：把复杂 SQL 封装成简单的查询入口
5. **访问控制**：可以通过视图限制用户能看到的字段和数据
6. 针对视图的DML操作，会影响到对应基表中的数据，反之亦然
7. 视图本身的删除，不会导致基表数据的删除
8. 视图针对大型项目，特别是冗长的查询语句，可以使用视图表替代，小型项目不推荐使用视图
9. 视图的维护成本比较高

**视图的增、删、改操作与表一致**



### 视图的优点

1. **简化复杂查询**：把复杂 SQL 简化成简单查询
2. **提高安全性**：隐藏敏感列、限制数据行，控制访问
3. 提高数据访问的灵活性：不仅可以隐藏字段，还可以隐藏**数据行**



## `CREATE VIEW` 创建视图

1. 查看视图

    ```sql
    # 查看视图定义信息
    SHOW CREATE VIEW 视图名;
    ```

    ```sql
    DESCRIBE 视图名;
    
    DESC 视图名;
    ```

2. 查看视图属性信息（命令行命令）

    ```sql
    # navicate
    SHOW TABLE STATUS LIKE '视图名';
    
    # 命令行可以加上 \G 显示效果会好些
    SHOW TABLE STATUS LIKE '视图名'\G;
    ```

3. 查看数据库表、视图对象

    ```sql
    # # 不仅会展示表，也会展示视图，不容易区分表和视图
    SHOW TABLES;
    
    # 查看视图 Table_type = VIEW 的是视图
    SHOW FULL TABLES;
    
    # 这个也行，能区分
    SHOW TABLES STATUS;
    ```



1. 创建视图

    ```sql
    CREATE VIEW 视图名 AS
    SELECT 查询语句;
    ```

    ```sql
    CREATE VIEW employee_view AS
    SELECT id, name, salary
    FROM employees;
    ```

2. 自定义列名

    也可以把聚合列字段放进去，如平均值、`SUM()` 等

    ```sql
    # 方式1：在 SELECT 中使用 AS；推荐使用该方式
    CREATE VIEW employee_view AS
    SELECT
        id AS employee_id,
        name AS employee_name,
        salary AS employee_salary
    FROM employees;
    
    # 方式2：在视图名称后面统一指定列名
    CREATE VIEW employee_view (
        employee_id,
        employee_name,
        employee_salary
    ) AS
    SELECT
        id,
        name,
        salary
    FROM employees;
    ```

3. 也可以基于视图创建视图



## 视图更新

- 针对视图的DML操作，会影响到对应基表中的数据，反之亦然。但是要注意外键等原因出现的不可更新的情况
- 虽然视图可以更新数据，但视图的本质是 `select` 查询，是虚拟表，主要用于方便查询，不建议更新视图的数据
- **对视图数据的更改，都是通过对实际数据表里数据的操作来完成的**，即有需要就更新基表的数据



## `ALTER VIEW` 修改视图

常用于需要修改视图列的情况，修改视图不会修改基表，只是改变 `select` 语句而已

```sql
# 创建或替换视图
CREATE OR REPLACE VIEW 视图名 AS
SELECT 查询语句;

# 修改已有视图
ALTER VIEW 视图名 AS
SELECT 查询语句;
```

```sql
CREATE OR REPLACE VIEW employee_view AS
SELECT
    id,
    name,
    salary,
    department
FROM employees;

ALTER VIEW employee_view AS
SELECT
    id,
    name,
    salary,
    department
FROM employees;
```



## `DROP VIEW` 删除视图

删除视图

```sql
DROP VIEW IF EXISTS 视图名;
```

- 说明：如果基表删除，视图将会查询失败，所以删除基表需要手动删除或者修改视图，否则影响使用
