| MySQL 关键字 / 写法     | 含义说明                                                     | 示例                                |
| ----------------------- | ------------------------------------------------------------ | ----------------------------------- |
| `NULL`                  | 数据列可以包含 `NULL` 值，表示“没有值”或“未知值”，不是空字符串 `''` | `name VARCHAR(50) NULL`             |
| `NOT NULL`              | 数据列不允许包含 `NULL` 值                                   | `name VARCHAR(50) NOT NULL`         |
| `DEFAULT`               | 默认值；插入数据时未指定该字段，则使用默认值                 | `status INT DEFAULT 1`              |
| `PRIMARY KEY`           | 主键，唯一标识一条记录；一个表只能有一个主键，但主键可以由多个字段组成 | `id BIGINT PRIMARY KEY`             |
| `AUTO_INCREMENT`        | 自动递增，常用于整数类型的主键 ID                            | `id BIGINT AUTO_INCREMENT`          |
| `UNSIGNED`              | 无符号，只能存储非负数，可以扩大正数范围                     | `age TINYINT UNSIGNED`              |
| `UNIQUE` / `UNIQUE KEY` | 唯一约束，保证字段或字段组合的值不能重复                     | `email VARCHAR(100) UNIQUE`         |
| `KEY` / `INDEX`         | 创建普通索引，提高查询效率                                   | `INDEX idx_name(name)`              |
| `CHECK`                 | 检查约束，限制字段必须满足指定条件                           | `CHECK (age >= 0)`                  |
| `COMMENT`               | 添加注释，可以给表或字段添加说明                             | `name VARCHAR(50) COMMENT '用户名'` |
| `ENGINE`                | 指定表使用的存储引擎                                         | `ENGINE=InnoDB`                     |
| `CHARACTER SET`         | 指定字符集                                                   | `CHARACTER SET utf8mb4`             |
| `COLLATE`               | 指定排序规则/校对规则，影响字符串比较和排序                  | `COLLATE utf8mb4_0900_ai_ci`        |



# 表管理

## 1.创建表

### 表结构

1. 显示表结构

    列出表字段的相关信息，如字段的类型

    ```sql
    DESCRIBE table1;
    
    DESC table1;
    ```

2. 显示**创建这张表的完整 `SQL`**

    ```sql
    SHOW CREATE TABLE employees;
    ```

3. 修改表的字符集

    表的字符集一般不动，怕乱码，创建的时候就要考虑好

    ```sql
    # 查看表的字符集，在 Create Table 中
    SHOW CREATE TABLE table1;
    
    # 修改的是表的默认字符集，主要影响以后新增的字段
    ALTER TABLE table1
    CHARACTER SET utf8mb4;
    
    # 修改表的字符集，并且自动转换现有字段的字符集
    ALTER TABLE table1
    CONVERT TO CHARACTER SET utf8mb4;
    ```



### 创建表的方式

- 创建表需要注意数据库/表的字符集，不指定则**默认使用数据库的字符集**
- 不同表的相同字段尽量保持数据类型是一致的，多表连接等操作才方便
- 表必备的三个字段`id`、`create_time`、`update_time`

```sql
CREATE TABLE [IF NOT EXISTS] 表名(
    字段1, 数据类型 [约束条件] [默认值] [COMMENT '注释'],
    字段2, 数据类型 [约束条件] [默认值] [COMMENT '注释'],
    字段3, 数据类型 [约束条件] [默认值] [COMMENT '注释'],
    ……
    [表约束条件]
)[ COMMENT = '注释'];
```



1. 简单创建

    创建表需要权限，具体看权限管理，`root` 用户肯定有！

    ```sql
    CREATE TABLE IF NOT EXISTS `sys_user` (
        id BIGINT,
        create_time DATETIME,
        update_time DATETIME,
        is_deleted TINYINT
    )
    ```

    ```sql
    # 建表一般要注明注释
    CREATE TABLE IF NOT EXISTS `sys_user` (
        id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
        create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
        update_time DATETIME COMMENT '更新时间',
        is_deleted TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '是否删除：0-正常，1-已删除'
    )
    COMMENT = '用户表';
    ```

    `navicat` 点击表，右边的 `DDL` 可以查看建表信息，包括 `COMMENT`

2. **联合主键**：当主键是多个字段，可以把主键写在最后

    ```sql
    CREATE TABLE IF NOT EXISTS user_role (
        user_id BIGINT,
        role_id BIGINT,
        create_time DATETIME,
        PRIMARY KEY (user_id, role_id)
    );
    ```

3. 基于现有的表创建（表备份），**字段数据类型以及数据**也会复制过去

    ```sql
    CREATE TABLE table2
    AS
    SELECT * FROM table1
    ```

4. 指定表和字段的**字符集**

    ```sql
    # 指定表的存储引擎、字符集
    CREATE TABLE IF NOT EXISTS user (
        id BIGINT PRIMARY KEY,
        create_time DATETIME,
        update_time DATETIME
    )
    ENGINE = InnoDB                  # 指定存储引擎
    CHARACTER SET 'utf8mb4'          # 简写 CHARSET = utf8;
    COLLATE 'utf8mb4_0900_ai_ci';    # 指定排序规则
    
    # 指定字段的字符集（不常用，一般统一按照数据库的字符集）
    CREATE TABLE IF NOT EXISTS user (
        id BIGINT PRIMARY KEY,
        create_time DATETIME CHARACTER SET 'utf8',
        update_time DATETIME
    );
    ```

5. 指定自增的初始值

    ```sql
    CREATE TABLE IF NOT EXISTS `sys_user` (
        id BIGINT PRIMARY KEY AUTO_INCREMENT,
        create_time DATETIME,
        update_time DATETIME,
        is_deleted TINYINT
    ) AUTO_INCREMENT = 1000;
    ```




## 2.修改表

`alter`：改变

1. 修改表名 `RENAME TO`

    ```sql
    ALTER TABLE old_table_name RENAME TO new_table_name;
    ```

    ```sql
    ALTER TABLE `user`
    RENAME TO sys_user;
    ```

2. **新增字段 `ADD`**

    ```sql
    ALTER TABLE 表名 ADD [COLUMN] 字段名 数据类型;
    ```

    ```sql
    # 字段默认放在表的最后
    ALTER TABLE `user`
    ADD COLUMN age INT;
    
    # 字段放在表的最前
    ALTER TABLE `user`
    ADD COLUMN age INT FIRST;
    
    # 指定字段在 id 的后面
    ALTER TABLE `user`
    ADD COLUMN age INT AFTER id;
    ```

    默认值的问题

    ```sql
    ALTER TABLE t ADD COLUMN flag CHAR(1) DEFAULT '0';
    
    # 手动给已经存在的数据添加默认值
    UPDATE t SET flag = '0' WHERE flag IS NULL;
    ```

3. **重命名字段名 `CHANGE`**

    ```sql
    ALTER TABLE 表名 CHANGE [COLUMN] 旧字段名 新字段名 数据类型;
    ```

    ```sql
    ALTER TABLE user
    CHANGE COLUMN username user_name VARCHAR(50);
    ```

4. **删除字段 `DROP`**

    ```sql
    ALTER TABLE 表名 DROP [COLUMN] 字段名;
    ```

    ```sql
    ALTER TABLE user
    DROP COLUMN age;
    ```

5. 修改字段类型/约束 `MODIFY`

    ```sql
    ALTER TABLE 表名 MODIFY [COLUMN] 字段名 新类型;
    ```

    ```sql
    ALTER TABLE user
    MODIFY COLUMN name VARCHAR(100);
    
    ALTER TABLE user
    MODIFY COLUMN name VARCHAR(100) NOT NULL;
    ```

6. 增加唯一性约束

    > 指定唯一性约束的名称，可以用删除唯一性索引的方式删除唯一性约束（不指定，默认唯一性约束名称是字段名）

    ```sql
    # 默认唯一性约束名称是字段名
    ALTER TABLE sys_user ADD UNIQUE (name);
    
    # 指定唯一性约束的名称
    ALTER TABLE sys_user
    ADD CONSTRAINT uk_sys_user_name UNIQUE (name);
    ```

    ```sql
    # 联合唯一性约束
    ALTER TABLE sys_user
    ADD CONSTRAINT uk_sys_user_name_phone
    UNIQUE (name, phone);
    ```

7. 添加默认值 `MODIFY`

    已经存在的数据不会自动加上默认值，只能手动更新

    ```sql
    ALTER TABLE `user`
    MODIFY COLUMN `status` INT DEFAULT 1;
    
    # 更新已经存在的数据
    UPDATE user
    SET `status` = 1
    WHERE `status` IS NULL;
    ```

8. 添加主键 `ADD PRIMARY KEY`

    ```sql
    ALTER TABLE user
    ADD PRIMARY KEY(id);
    ```

9. 删除主键 `DROP PRIMARY KEY`

    ```sql
    ALTER TABLE user
    DROP PRIMARY KEY;
    ```

10. 添加索引 `ADD INDEX`

    普通索引：

    ```sql
    ALTER TABLE user ADD INDEX idx_name(name);
    ```

    唯一索引：

    ```sql
    ALTER TABLE user ADD UNIQUE INDEX uk_email(email);
    ```

11. 删除索引 `DROP INDEX`

       ```sql
       ALTER TABLE user DROP INDEX idx_name;
       ```

12. 添加外键 `FOREIGN KEY`

    ```sql
    ALTER TABLE order_table
    ADD CONSTRAINT fk_user_id
    FOREIGN KEY(user_id)
    REFERENCES user(id);
    ```

13. 修改表注释

     ```sql
     ALTER TABLE employees
     COMMENT = '公司员工信息表';
     ```

14. 修改字段注释

    ```sql
    ALTER TABLE employees
    MODIFY name VARCHAR(50) COMMENT '员工姓名';
    ```




## 3.删除表

1. 删除表 `DROP`（不可撤销，需要备份）

    ```sql
    DROP TABLE tableName;
    
    DROP TABLE IF EXISTS tableName;
    ```

2. 清空表数据 `DELETE`

    ```sql
    TRUNCATE TABLE tableName;      # 快，重置自增 ID，但是不可回滚
    ```

    ```sql
    DELETE FROM tableName;         # 逐行删除，不重置自增 ID，可回滚
    
    # 类似于
    DELETE FROM tableName
    WHERE 1 = 1;
    ```
