| MySQL关键字          | 含义                     | 说明 / 示例                                      |
| -------------------- | ------------------------ | ------------------------------------------------ |
| `NULL`               | 数据列可以包含 NULL 值   | 表示“没有值”或“未知值”，不是空字符串 `''`        |
| `NOT NULL`           | 数据列不允许包含 NULL 值 | 插入数据时必须提供该字段的值                     |
| `DEFAULT`            | 默认值                   | 当插入数据未指定该字段时，使用默认值             |
| `PRIMARY KEY`        | 主键                     | 唯一标识一条记录，不能为空，一个表只能有一个主键 |
| `AUTO_INCREMENT`     | 自动递增                 | 用于整数类型字段，常用于主键 ID                  |
| `UNSIGNED`           | 无符号                   | 只能存储非负数，扩大正数范围                     |
| `CHARACTER SET name` | 指定字符集               | 设置字段、表或数据库使用的字符编码               |



# 表管理

## 1.创建表

### 表结构

1. 显示表结构

    列出表字段的相关信息，如字段的类型

    ```sql
    DESCRIBE table1;
    
    DESC table1;
    ```

2. 显示**创建这张表的完整 SQL**

    ```sql
    SHOW CREATE TABLE employees;
    ```

3. 修改表的字符集

    ```sql
    # 查看表的字符集，在 Create Table 中
    SHOW CREATE TABLE table1;
    
    ALTER TABLE table1 charset utf8
    ```



### 创建表的方式

- 创建表需要注意数据库/表的字符集，不指定则**默认使用数据库的字符集**
- 不同表的相同字段尽量保持数据类型是一致的，多表连接等操作才方便
- 表必备的三个字段`id`、`create_time`、`update_time`

```sql
CREATE TABLE [IF NOT EXISTS] 表名(
    字段1, 数据类型 [约束条件] [默认值],
    字段2, 数据类型 [约束条件] [默认值],
    字段3, 数据类型 [约束条件] [默认值],
    ……
    [表约束条件]
);
```



1. 简单创建

    ```sql
    # 创建表需要权限，root 用户肯定有！
    CREATE TABLE IF NOT EXISTS user (
        id BIGINT PRIMARY KEY,
        create_time DATETIME,
        update_time DATETIME
    );
    ```

2. 当主键是多个字段，可以把主键写在最后

    ```sql
    CREATE TABLE IF NOT EXISTS user_role (
        user_id BIGINT,
        role_id BIGINT,
        create_time DATETIME,
        PRIMARY KEY (user_id, role_id)
    );
    ```

3. 基于现有的表创建，**字段数据类型以及数据**也会复制过去

    ```sql
    CREATE TABLE table2
    AS
    SELECT * FROM table1
    ```

4. 指定表和字段的字符集（不常用，一般统一按照数据库的字符集）

    ```sql
    # 指定表的字符集
    CREATE TABLE IF NOT EXISTS user (
        id BIGINT PRIMARY KEY,
        create_time DATETIME,
        update_time DATETIME
    )
    CHARACTER SET 'utf8mb4'          # 简写 CHARSET = utf8;
    COLLATE 'utf8_general_ci';       # 指定排序规则
    
    # 指定字段的字符集
    CREATE TABLE IF NOT EXISTS user (
        id BIGINT PRIMARY KEY,
        create_time DATETIME CHARACTER SET 'utf8',
        update_time DATETIME
    );
    ```

    



## 2.修改表

`alter`：改变

1. 修改表名 `RENAME TO`

    ```sql
    ALTER TABLE old_table_name RENAME TO new_table_name;
    ```

    ```sql
    ALTER TABLE `user`
    RENAME TO sys_user;
    ```

2. **新增字段 `ADD`**

    ```sql
    ALTER TABLE 表名 ADD [COLUMN] 字段名 数据类型;
    ```

    ```sql
    ALTER TABLE `user`
    ADD COLUMN age INT;
    
    # 增加限制
    ALTER TABLE user
    ADD COLUMN create_time DATETIME DEFAULT CURRENT_TIMESTAMP;
    ```

3. **重命名字段名 `CHANGE`**

    ```sql
    ALTER TABLE 表名 CHANGE [COLUMN] 旧字段名 新字段名 数据类型;
    ```

    ```sql
    ALTER TABLE user
    CHANGE COLUMN username user_name VARCHAR(50);
    ```

4. **删除字段 `DROP`**

    ```sql
    ALTER TABLE 表名 DROP [COLUMN] 字段名;
    ```

    ```sql
    ALTER TABLE user
    DROP COLUMN age;
    ```

5. 修改字段类型/约束 `MODIFY`

    ```sql
    ALTER TABLE 表名 MODIFY [COLUMN] 字段名 新类型;
    ```

    ```sql
    ALTER TABLE user
    MODIFY COLUMN name VARCHAR(100);
    
    ALTER TABLE user
    MODIFY COLUMN name VARCHAR(100) NOT NULL;
    ```

6. 添加默认值 `MODIFY status`

    ```sql
    ALTER TABLE user 
    MODIFY COLUMN status INT DEFAULT 1;
    ```

7. 添加主键 `ADD PRIMARY KEY`

    ```sql
    ALTER TABLE user
    ADD PRIMARY KEY(id);
    ```

8. 删除主键 `DROP PRIMARY KEY`

    ```sql
    ALTER TABLE user
    DROP PRIMARY KEY;
    ```

9. 添加索引 `ADD INDEX`

    普通索引：

    ```sql
    ALTER TABLE user ADD INDEX idx_name(name);
    ```

    唯一索引：

    ```sql
    ALTER TABLE user ADD UNIQUE INDEX uk_email(email);
    ```

10. 删除索引 `DROP INDEX`

    ```sql
    ALTER TABLE user DROP INDEX idx_name;
    ```

11. 添加外键 `FOREIGN KEY`

    ```sql
    ALTER TABLE order_table
    ADD CONSTRAINT fk_user_id
    FOREIGN KEY(user_id)
    REFERENCES user(id);
    ```



## 3.删除表

1. 删除表 `DROP`（不可撤销，需要备份）

    ```sql
    DROP TABLE tableName;
    
    DROP TABLE IF EXISTS tableName;
    ```

2. 清空表数据 `DELETE`

    ```sql
    TRUNCATE TABLE tableName;      # 快，重置自增 ID，但是不可回滚
    ```

    ```sql
    DELETE FROM tableName;         # 逐行删除，不重置自增 ID，可回滚
    
    # 类似于
    DELETE FROM tableName
    WHERE 1 = 1;
    ```
