# 窗口函数

在不把多行数据合并成一行的情况下，对**与当前行相关的一组数据**进行计算；这是它和 `GROUP BY` 最大的区别

- `GROUP BY`：把多行变成一行
- 窗口函数：分组计算，但保留原来的每一行；不会因为分组而减少行数

```sql
函数(...) OVER (
    PARTITION BY ...
    ORDER BY ...
    ROWS/RANGE ...
)
```

- `PARTITION BY`：划分窗口，指定窗口函数按照哪些字段进行分组。
- `ORDER BY`：窗口内部排序，指定窗口函数按照哪些字段进行排序。

例如：

```sql
AVG(salary) OVER (
    PARTITION BY dept
)

# 可以拆成：
AVG(salary)               # → 计算什么
OVER (...)                # → 关键字指定函数窗口的范围
PARTITION BY dept         # → 窗口按照什么分组
```

## 公用表表达式`CTE`

`CTE`：给一条临时查询结果起一个名字，作用范围是当前语句。

```sql
WITH cte_name AS (
    SELECT ...
)
SELECT ...
FROM cte_name;
```

例如：

```sql
WITH tech_employees AS (
    SELECT *
    FROM employees
    WHERE department = '技术部'
)
SELECT *
FROM tech_employees;
```





1. 一个 `SQL` 可以有多个 `CTE`

    ```sql
    WITH
    high_salary AS (
        SELECT *
        FROM employees
        WHERE salary >= 10000
    ),
    tech_employees AS (
        SELECT *
        FROM employees
        WHERE department = '技术部'
    )
    SELECT *
    FROM high_salary
    WHERE employee_id IN (
        SELECT employee_id
        FROM tech_employees
    );
    ```

2. `CTE` 的递归调用

    ```sql
    # 按层级查询
    总经理
    ├── 技术总监
    │   ├── 张三
    │   └── 李四
    └── 财务总监
        ├── 王五
        └── 赵六
    ```

    ```sql
    WITH RECURSIVE employee_tree AS (
        -- 第一层：找到总经理
        SELECT
            employee_id,
            name,
            manager_id
        FROM employees
        WHERE manager_id IS NULL
    
        UNION ALL
    
        -- 下一层：找到他的下属
        SELECT
            e.employee_id,
            e.name,
            e.manager_id
        FROM employees e
        JOIN employee_tree t
            ON e.manager_id = t.employee_id
    )
    SELECT *
    FROM employee_tree;
    ```
