# 事务

1. 查看当前 autocommit 状态

    ```sql
    SELECT @@autocommit;         # 返回 1 开启，返回 0 关闭
    ```

2. 设置自动提交

    ```sql
    # 设置自动提交（默认值）
    SET autocommit = TRUE;
    
    # 关闭自动提交
    SET autocommit = FALSE;
    ```

3. 提交

    ```sql
    COMMIT;
    ```

4. 回滚，回到上一次 `COMMIT` 之前

    ```sql
    ROLLBACK;
    ```



## 原子化

```sql
# 关闭自动提交，直到手动 COMMIT; 之前都不会提交
SET autocommit = FALSE;

UPDATE user SET name='Tom';

UPDATE user SET age=18;

# ROLLBACK;

COMMIT;

SET autocommit = TRUE;
```
