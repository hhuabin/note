# 比较运算符

| 运算符 | 名称                                                         | 示例                              |
| ------ | ------------------------------------------------------------ | --------------------------------- |
| =      | 等于<br />相等返回1，不相等返回0<br/>（有隐式转换的问题，如 1 = '1'）<br />`1 = NULL` 结果是 `NULL`<br />`NULL = NULL` 结果是 `NULL`<br />`NULL`参与的结果都是 `NULL` | SELECT C FROM TABLE WHERE A = B   |
| <=>    | 安全等于<br />（有隐式转换的问题，如 1 = '1'）<br />主要是解决 `NULL`的问题<br />`1 = NULL` 结果是 `0`<br />`NULL <=> NULL` 结果是 `1` | SELECT C FROM TABLE WHERE A <=> B |
| <>(!=) | 不等于                                                       | SELECT C FROM TABLE WHERE A <> B  |
| <      | 小于                                                         | SELECT C FROM TABLE WHERE A < B   |
| <=     | 小于等于                                                     | SELECT C FROM TABLE WHERE A <= B  |
| >      | 大于                                                         | SELECT C FROM TABLE WHERE A > B   |
| >=     | 大于等于                                                     | SELECT C FROM TABLE WHERE A >= B  |

| 运算符                | 名称             | 示例                                                         | 作用                                                         |
| --------------------- | ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `IS NULL` \| `ISNULL` | 为空运算符       | SELECT B FROM TABLE WHERE A IS NULL<br />SELECT ISNULL(NULL) FROM DUAL; |                                                              |
| `IS NOT NULL`         | 不为空运算符     | SELECT B FROM TABLE WHERE A IS NOT NULL                      |                                                              |
| `LEAST`               | 最小值运算符     | SELECT D FROM TABLE WHERE C LEAST(A, B)                      | 函数                                                         |
| `REATEST`             | 最大值运算符     | SELECT D FROM TABLE WHERE C GREATEST(A, B)                   | 函数                                                         |
| `BETWEEN AND`         | 两值之间的运算符 | SELECT D FROM TABLE WHERE C BETWEEN A AND B                  | BETWEEN **下限** AND **上限**                                |
| `NOT BETWEEN AND`     | 不在两值之间     | SELECT D FROM TABLE WHERE C NOT BETWEEN A AND B              |                                                              |
| `IN`                  | 属于运算符       | SELECT D FROM TABLE WHERE E IN(A, B, C)                      | `,`号分隔                                                    |
| `NOT IN`              | 不属于运算符     | SELECT D FROM TABLE WHERE C NOT IN(A, B)                     |                                                              |
| `LIKE`                | 模糊匹配运算符   | SELECT C FROM TABLE WHERE A LIKE '%B%'                       | `%`表示0或多个字符<br />`_`代表一个任意字符<br />`\`是转义字符 |
| `REGEXP`              | 正则表达式运算符 | SELECT C FROM TABLE WHERE A REGEXP B                         |                                                              |
| `RLIKE`               | 正则表达式运算符 | SELECT C FROM TABLE WHERE A RLIKE B                          |                                                              |

```sql
# 示例
SELECT employee_id, last_name, job_id, salary
FROM employees
WHERE salary >= 10000
OR job_id LIKE '%MAN%';
```

```sql
# 示例
WHERE age > 18 AND status = 1
WHERE id IN (1, 2, 3)
WHERE age BETWEEN 18 AND 30
WHERE name LIKE '%黄%'
```



# 逻辑运算符

| 运算符         | 作用     | 示例                               |
| -------------- | -------- | ---------------------------------- |
| `NOT` \| `!`   | 逻辑非   | SELECT NOT A                       |
| `AND` \| &&    | 逻辑与   | SELECT A AND B<br />SELECT A && B  |
| `OR` \| `\|\|` | 逻辑或   | SELECT A OR B<br />SELECT A \|\| B |
| XOR            | 逻辑异或 | SELECT A XOR B                     |

```sql
# 示例
select last_name,department_id,salary
from employees
where department_id in (10,20) XOR salary > 8000;
```



# 位运算符

| 运算符 | 作用              | 示例          |
| ------ | ----------------- | ------------- |
| &      | 按位与（位AND）   | SELECT A & B  |
| \|     | 按位或（位OR）    | SELECT A \| B |
| ^      | 按位异或（位XOR） | SELECT A ^ B  |
| ~      | 按位取反          | SELECT ~A     |
| >>     | 按位右移          | SELECT A >> 2 |
| <<     | 按位左移          | SELECT A << 2 |

```sql
SELECT 12 & 5, 12 | 5,12 ^ 5 FROM DUAL;

# 1100    0101
# 12 & 5        12 | 5        12 ^ 5
# 4             13            9 
```
