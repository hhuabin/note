# 索引

## 1.1索引分类

| 索引类型               | 作用                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 主键索引 `PRIMARY KEY` | 唯一标识一条数据（给表建立**主键**的时候会自动给主键添加主键索引） |
| 唯一索引 `UNIQUE`      | 数据不能重复（给字段建立**唯一性约束**的时候会自动给字段添加唯一索引） |
| 普通索引 `INDEX`       | 提高查询速度                                                 |
| 联合索引 `INDEX`       | 多个字段一起建立索引                                         |
| 全文索引 `FULLTEXT`    | 用于文本搜索                                                 |

适合建立索引的位置：`WHERE`、`JOIN`、`ORDER BY`、`GROUP BY`



## 1.2创建索引

```sql
CREATE TABLE sys_user (
    id BIGINT,
    username VARCHAR(50),
    email VARCHAR(100),
    age INT,
    city VARCHAR(50),
    content TEXT
);
```

> 创建索引时，不指定索引名就采用字段名，索引名一般以 `idx_` 开头，如 `idx_id`、`uk_idx_id`（唯一索引）、`mul_idx_id_name`（联合索引）

1. 创建主键索引

    建表时添加

    ```sql
    # 添加主键
    CREATE TABLE sys_user (
        id BIGINT PRIMARY KEY,
        username VARCHAR(50)
    );
    
    CREATE TABLE sys_user (
        id BIGINT,
        username VARCHAR(50),
        PRIMARY KEY (id)
    );
    ```

    已有表添加主键

    ```sql
    ALTER TABLE sys_user
    ADD PRIMARY KEY (id);
    ```

2. 创建唯一索引

    建表时添加

    ```sql
    # 添加唯一性约束
    CREATE TABLE sys_user (
        id BIGINT,
        username VARCHAR(50) UNIQUE
    );
    
    CREATE TABLE sys_user (
        id BIGINT,
        username VARCHAR(50),
        UNIQUE INDEX uk_username (username)
    );
    ```

    已有表添加主键

    ```sql
    CREATE UNIQUE INDEX uk_username
    ON sys_user (username);
    
    # 或
    ALTER TABLE sys_user
    ADD UNIQUE INDEX uk_username (username);
    ```

3. 创建普通索引

    建表时添加

    ```sql
    CREATE TABLE sys_user (
        id BIGINT,
        username VARCHAR(50),
        INDEX uk_username (username)
    );
    ```

    已有表添加主键

    ```sql
    CREATE INDEX idx_age
    ON sys_user (age);
    
    ALTER TABLE sys_user
    ADD INDEX idx_age (age);
    ```

4. 创建联合索引

     联合索引需要注意 **最左前缀原则**，需要严格按照表中，左边的字段排在前面

     建表时添加

     ```sql
     CREATE TABLE sys_user (
         id BIGINT,
         username VARCHAR(50),
         age INT,
         INDEX idx_username_age(username, age)       # username 在 age 左侧
     );
     ```

     已有表添加主键

     ```sql
     CREATE INDEX idx_age_city
     ON sys_user (age, city);
     
     # 或
     ALTER TABLE sys_user
     ADD INDEX idx_age_city (age, city);
     ```

5. 创建全文索引

    `FULLTEXT` 全文索引可以用于全文搜索，并且只为 `CHAR`、`VARCHAR` 和 `TEXT` 列创建索引。索引总是对整个列进行，不支持局部(前缀)索引

    建表时添加

    ```sql
    CREATE TABLE sys_user (
        id BIGINT,
        username VARCHAR(50),
        age INT,
        FULLTEXT futxt_idx_username(username)
    );
    ```

    已有表添加主键

    ```sql
    CREATE FULLTEXT INDEX idx_content
    ON sys_user (content);
    ```



## 1.3查看索引

1. 查看一张表的所有索引

    ```sql
    SHOW INDEX FROM sys_user;
    
    # 或
    SHOW KEYS FROM sys_user;
    ```

    

## 1.4删除索引

> 删除表中的列时，如果要删除的列为索引的组成部分（联合索引），则该**列也会从索引中删除**
>
> 如果组成索引的所有列都被删除，则**整个索引将被删除**

1. 删除主键索引

    ```sql
    ALTER TABLE sys_user
    DROP PRIMARY KEY;
    ```

2. 删除唯一索引、普通索引、联合索引

    > 删除唯一索引也会删除掉唯一性约束

    ```sql
    DROP INDEX 索引名
    ON 表明;
    
    DROP INDEX uk_username
    ON sys_user;
    
    # 或
    ALTER TABLE sys_user
    DROP INDEX idx_username;
    ```

    > 联合索引的问题：如果联合索引关联有三个字段名，如 `idx_name_age_sex`，删除掉一个列，联合索引会重置关联为剩下的两个字段，索引名不变

5. 删除全文索引

    ```sql
    DROP INDEX idx_content ON sys_user;
    ```




# `MySQL 8.0` 新特性

## 2.1支持降序索引（仅限 InnoDB 存储引擎）

> 以前的 `MySQL` 版本中，索引主要按照**升序**存储。
>
> `MySQL 8.0` 支持在创建索引时为索引列指定 `ASC` / `DESC`，主要用于优化 `ORDER BY`，尤其适合联合索引中不同字段具有不同排序方向的场景

1. 创建降序索引

    ```sql
    CREATE INDEX idx_age_desc
    ON user (age DESC);
    ```

2. 创建联合降序索引

    降序索引真正比较有价值的地方，是**联合索引**

    ```sql
    CREATE INDEX idx_age_id
    ON user (age DESC, id ASC);
    ```

    ```sql
    # 年龄从大到小。同年龄时 id 从小到大
    SELECT *
    FROM user
    ORDER BY age DESC, id ASC;
    ```



## 2.2 查看降序索引

```sql
# 其中 Collation 列，展示 D 的表示降序（Descending），A 表示升序（Ascending）
SHOW INDEX FROM sys_user;
```
