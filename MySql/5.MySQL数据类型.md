# MySQL中的数据类型

| 分类                              | 数据类型                                                     |
| --------------------------------- | ------------------------------------------------------------ |
| 整数类型（Integer）               | TINYINT、SMALLINT、MEDIUMINT、**`INT(INTEGER)`**、BIGINT     |
| 浮点数类型（Floating-Point）      | FLOAT、DOUBLE                                                |
| 定点数类型（Fixed-Point）         | **`DECIMAL`**、NUMERIC（DECIMAL 的同义词）                   |
| 位类型（Bit）                     | BIT                                                          |
| 日期时间类型（Date & Time）       | YEAR、TIME、**`DATE`**、DATETIME、TIMESTAMP                  |
| 文本字符串类型（String）          | CHAR、**VARCHAR**、TINYTEXT、TEXT、MEDIUMTEXT、LONGTEXT      |
| 二进制字符串类型（Binary String） | BINARY、VARBINARY、TINYBLOB、BLOB、MEDIUMBLOB、LONGBLOB      |
| 枚举类型（Enumeration）           | ENUM                                                         |
| 集合类型（Set）                   | SET                                                          |
| JSON 类型                         | JSON对象、JSON数组                                           |
| 空间数据类型（Spatial）           | 单值：GEOMETRY、POINT、LINESTRING、POLYGON；<br />集合：MULTIPOINT、MULTILINESTRING、MULTIPOLYGON、GEOMETRYCOLLECTION |



## 常用的几类类型介绍

| 数据类型       | 描述                                                         |
| -------------- | ------------------------------------------------------------ |
| `INT(INTEGER)` | 4 字节整数，有符号范围：-2³¹ ~ 2³¹-1，无符号范围：0 ~ 2³²-1（UNSIGNED）。<br />（有符号最大值 2147483647，21亿）（无符号最大值 4294967295，42亿） |
| `BIGINT`       | 8 字节整数类型，有符号范围：-2^63 ~ 2^63-1，无符号范围：0 ~ 2^64-1（UNSIGNED）。<br />（有符号最大值 9223372036854775807，922亿亿，19个整数）（无符号最大值 18446744073709551615，1844亿亿，20个整数） |
| `CHAR(n)`      | 定长字符串，长度固定为 `n`（1~255），不足会自动补空格，适合存储固定长度数据。 |
| `VARCHAR(n)`   | 可变长度字符串，长度为 1~65535 字节（受行大小限制），**必须指定长度**，实际占用与存储内容有关，是开发中最常用的字符串类型。 |
| `FLOAT(M,D)`   | 单精度浮点数，占 4 字节，适用于近似值计算，不建议用于金额。MySQL 8.0 中 `M,D` 已不推荐使用。 |
| `DOUBLE(M,D)`  | 双精度浮点数，占 8 字节，精度高于 FLOAT，适用于近似值计算，不建议用于金额。MySQL 8.0 中 `M,D` 已不推荐使用。 |
| `DECIMAL(M,D)` | 高精度定点数，适用于金额、价格等需要精确计算的场景。存储空间根据精度动态计算，并非固定 `M+2` 字节。 |
| `DATE`         | 日期类型，格式：`YYYY-MM-DD`，范围：`1000-01-01` ~ `9999-12-31`。 |
| `TIME`         | 时间类型，格式：`HH:MM:SS`，表示时间或时间间隔。             |
| `DATETIME`     | 日期时间类型，格式：`YYYY-MM-DD HH:MM:SS`，范围较大，不受时区影响。 |
| `TIMESTAMP`    | 时间戳类型，格式：`YYYY-MM-DD HH:MM:SS`，受时区影响，常用于记录创建时间、更新时间。 |
| `YEAR`         | 年份类型，存储四位年份，如 `2026`。                          |
| `BLOB`         | 二进制大对象，用于存储图片、音频、文件等二进制数据。按大小分为 `TINYBLOB`、`BLOB`、`MEDIUMBLOB`、`LONGBLOB`，其中 **LONGBLOB 最大约 4GB**。 |
| `TEXT`         | 文本类型，用于存储长文本。按大小分为 `TINYTEXT`、`TEXT`、`MEDIUMTEXT`、`LONGTEXT`，其中 **LONGTEXT 最大约 4GB**，普通 **TEXT 最大约 64KB**。 |
