# 子查询

子查询（Subquery）就是**在一条 SQL 语句中再嵌套一条 SQL 查询**。子查询要用 `()` 包住。

简单来说，就是**先查一个结果，再把这个结果作为另一条 SQL 的条件或数据来源**。

子查询可以出现在 `SELECT`、`FROM`、**`WHERE`**、`HAVING` 等位置，也可以用于 `INSERT`、`UPDATE`、`DELETE`。

```sql
# 查询工资最高的员工，不用子查询
SELECT MAX(salary)
FROM t_emp;

# 得到 9000

SELECT *
FROM t_emp
WHERE salary = 9000;
```

```sql
# 查询工资最高的员工
SELECT *
FROM t_emp
WHERE salary = (
    SELECT MAX(salary)
    FROM t_emp
);
```



### 子查询分类

1. 根据**返回的条目数量**可以分为

    - 单行子查询
    - 多行子查询

    |                  | 单行子查询       | 多行子查询        |
    | ---------------- | ---------------- | ----------------- |
    | 返回结果         | 一行一列         | 多行一列          |
    | 示例结果         | `8000`           | `8000,9000,10000` |
    | 常用操作符       | `= > < >= <= <>` | `IN ANY ALL`      |
    | 是否允许多个结果 | ❌                | ✅                 |
    | 使用场景         | 一个确定值       | 一组值            |

2. 根据**外层查询和内层查询的引用关系**分为

    - 独立子查询
    - 关联子查询



## 单行子查询

单行只返回一个值，所以外层可以使用普通比较运算符

```sql
=
>
<
>=
<=
<>
```

```sql
# 部门 = 李四的部门
# 工资 = 李四的工资
SELECT *
FROM t_emp
WHERE dept_id = (
    SELECT dept_id
    FROM t_emp
    WHERE emp_name = '李四'
)
AND salary = (
    SELECT salary
    FROM t_emp
    WHERE emp_name = '李四'
);

# 也可以使用这种写法
SELECT *
FROM t_emp
WHERE (dept_id, salary) = (
    SELECT dept_id, salary     # (10, 9000)
    FROM t_emp
    WHERE emp_name = '李四'
);
```

单行查询的问题：当 `emp_name` **不唯一**，查出多条数据，会报错



## 多行子查询

多行子查询返回多行数据；常用的多行比较操作符

| 操作符 | 含义                                                         |
| ------ | ------------------------------------------------------------ |
| `IN`   | 等于列表中的**任意一个**                                     |
| `ANY`  | 需要和单行比较操作符一起使用，和子查询返回的**某一个**值比较 |
| `ALL`  | 需要和单行比较操作符一起使用，和子查询返回的**所有**值比较   |
| `SOME` | 实际上是 `ANY` 的别名，作用相同，一般常使用 `ANY`            |

```sql
# IN
SELECT *
FROM t_emp
WHERE salary IN (
    SELECT salary
    FROM t_emp
    WHERE dept_id = 10
);
```

```sql
# ANY
SELECT *
FROM t_emp
WHERE salary > ANY (       # 这里相当找大于（dept_id = 10 的 salary 最小值）
    SELECT salary
    FROM t_emp
    WHERE dept_id = 10
);
```

```sql
# ALL
SELECT *
FROM t_emp
WHERE salary > ALL (
    SELECT salary
    FROM t_emp
    WHERE dept_id = 10
);
```



### `FROM` 中的子查询

```sql
# 语法
SELECT 查询字段
FROM (
    子查询
) 别名;
```

```sql
# 查询平均工资超过7000的部门
SELECT dept_id, avg_salary
FROM (
    SELECT dept_id, AVG(salary) avg_salary      # avg_salary 自定义聚合函数列的列名
    FROM t_emp
    GROUP BY dept_id
) t
WHERE avg_salary > 7000;
```



### 空值问题`NULL`(`NOT IN`)

`NOT IN` 的空值问题

```sql
# 查询不属于这些部门的员工
SELECT *
FROM t_emp
WHERE dept_id NOT IN (
    SELECT dept_id
    FROM t_dept
);
```

如果dept_id中存在空值NULL，该查询等价于 `dept_id != 10 AND dept_id != 20 AND dept_id != NULL`

关键在于 `dept_id != NULL` 返回 `UNKNOWN`，等式不可能成立，一条数据的都查不到

1. 在子查询中过滤 `NULL`

    ```sql
    SELECT *
    FROM t_emp
    WHERE dept_id NOT IN (
        SELECT dept_id
        FROM t_dept
        WHERE dept_id IS NOT NULL
    );
    ```

2. 使用 NOT EXISTS（更推荐）

    不受 `NULL 影响`，大数据量通常性能更稳定

    ```sql
    SELECT *
    FROM t_emp e
    WHERE NOT EXISTS (
        SELECT 1
        FROM t_dept d
        WHERE d.dept_id = e.dept_id
    );
    ```
