# 安装

1. 下载`tar.xz`文件

    `Linux-Generic` -> `Linux Generic glibc 2.28 x86_64` -> `mysql-8.0.46-linux-glibc2.28-x86_64.tar.xz`

2. 安装 MySQL Generic Binary 需要的依赖：

    ```shell
    dnf install -y libaio
    ```

3. 把压缩包传至 `/usr/local`，解压

    ```shell
    tar -xJf /root/mysql-8.0.46-linux-glibc2.28-x86_64.tar.xz
    ```

4. 建立 `mysql` 软连接

    ```shell
    ln -s /usr/local/mysql-8.0.46-linux-glibc2.28-x86_64 /usr/local/mysql
    ```

5. 创建目录设置权限

    ```shell
    # 数据库存放目录
    mkdir -p /data/mysql
    chown -R mysql:mysql /data/mysql
    
    mkdir -p /usr/local/mysql/mysql-files
    chown mysql:mysql /usr/local/mysql/mysql-files
    chmod 750 /usr/local/mysql/mysql-files
    ```

6. 初始化 `MySQL`

    ```shell
    /usr/local/mysql/bin/mysqld --initialize --user=root --basedir=/usr/local/mysql --datadir=/data/mysql
    ```

    生成了

    ```shell
    A temporary password is generated for root@localhost: Abc123!xyz
    ```

    记下`root@localhost`后面的临时密码

7. 创建 MySQL 配置文件

    ```shell
    vim /etc/my.cnf
    ```

    写入

    ```shell
    [client]
    port=3306
    socket=/tmp/mysql.sock
    
    [mysqld]
    user=root
    
    basedir=/usr/local/mysql
    datadir=/data/mysql
    
    port=3306
    socket=/tmp/mysql.sock
    
    character-set-server=utf8mb4
    collation-server=utf8mb4_0900_ai_ci
    
    pid-file=/data/mysql/mysql.pid
    log-error=/data/mysql/mysql.err
    
    secure-file-priv=/usr/local/mysql/mysql-files
    
    symbolic-links=0
    ```

8. 设置环境变量

    ```shell
    vim /etc/profile
    ```

    在文件最后添加

    ```shell
    export MYSQL_HOME=/usr/local/mysql
    export PATH=$MYSQL_HOME/bin:$PATH
    ```

    ```shell
    source /etc/profile
    ```

    然后就可以使用 `mysql` 检查版本了

    ```shell
    mysql --version
    ```

9. 第一次启动

    ```shell
    /usr/local/mysql/bin/mysqld_safe --defaults-file=/etc/my.cnf --user=root &
    ```

    ```shell
    mysql -uroot -p
    ```

    输入刚才生成的临时密码

    然后修改密码

    ```mysql
    ALTER USER 'root'@'localhost' IDENTIFIED BY 'root';
    ```



### 配置 `systemd`

1. 创建 `systemd` 服务

    ```shell
    vim /etc/systemd/system/mysqld.service
    ```

    写入

    ```shell
    [Unit]
    Description=MySQL Community Server 8.0.46
    After=network.target
    
    [Service]
    Type=forking
    
    User=root
    Group=root
    
    ExecStart=/usr/local/mysql/bin/mysqld_safe --defaults-file=/etc/my.cnf --user=root
    ExecStop=/bin/kill -s TERM $MAINPID
    
    PIDFile=/data/mysql/mysql.pid
    
    LimitNOFILE=65535
    
    TimeoutSec=0
    Restart=on-failure
    
    [Install]
    WantedBy=multi-user.target
    ```

2. 重新加载 `systemd`

    ```shell
    systemctl daemon-reload
    ```

3. 关闭 `MySQL`

    ```shell
    /usr/local/mysql/bin/mysqladmin -uroot -p shutdown
    
    # 检查
    ps -ef | grep '[m]ysqld'    # 没有输出即正确关闭，否则关闭失败
    ```

4. 使用 `systemd` 启动

    ```shell
    systemctl start mysqld
    ```

    查看状态

    ```shell
    systemctl status mysqld
    ```

5. 设置开机自启动

    ```shell
    systemctl enable mysqld
    
    # 检查
    systemctl is-enabled mysqld
    ```





# `Navicat` 连接 `Linux` 数据库



1. 关闭 `linux` 防火墙，并且禁止防火墙开机启动

    ```shell
    # 检查防火墙运行状态
    systemctl status firewalld
    
    systemctl stop firewalld.service        // 关闭防火墙
    
    systemctl disable firewalld.service     // 禁止防火墙开机启动
    
    firewalld-cmd --reload                  // 重启防火墙
    ```

2. `MySQL` 默认情况下是不允许 `root` 用户使用其他 `IP` 地址连接的，`root` 默认只能使用 `localhost` 本地连接

    ```mysql
    # 修改 mysql 数据库的 user 表；允许任何 ip 使用 root 连接，生产不可配
    use mysql;
    update user set host = '%' where user = 'root';
    
    # 刷新权限
    flush privileges;
    ```




# 卸载



1. 停止 `MySQL` 服务

    ```shell
    sudo systemctl stop mysqld
    ```

2. 卸载 `MySQL` 软件包

    ```shell
    # 先查看安装了哪些 MySQL 包
    rpm -qa | grep -i mysql
    
    # 依次执行卸载
    sudo dnf remove mysql-community-server mysql-community-client mysql-community-common mysql-community-libs
    ```

3.  删除 MySQL 官方 Yum 源

    ```shell
    sudo dnf remove mysql84-community-release
    
    # 检查，没有输出就可以了
    dnf repolist | grep -i mysql
    ```

4. 删除 MySQL 相关文件

    ```shell
    find / -name mysql
    
    # 确实是自己创建的目录，直接 rm 删除即可
    rm -rf /var/lib/mysql
    ```
    



# 数据库大小写的问题

```sql
# 值为 0，大小写敏感，值为 1 大小写不敏感
SHOW VARIABLES LIKE '%lower_case_table_names%';     # 不要修改该值，系统默认即可；用的话，不要用大写
```

`MySQL` 在 `Linux` 下数据库名、表名、列名、别名大小写规则是这样的

1. 数据库名、表名、表的别名、变量名是严格区分大小写的
2. 关键字、函数名称在SQL中不区分大小写
3. 列名(或字段名)与列的别名(或字段别名)在所有的情况下均是忽略大小写的



# 数据库的严格模式 `sql_mode`

- 宽松模式：迁移数据库时，可以考虑使用
- 严格模式：日常使用

```sql
# 查看当前模式
SELECT @@sql_mode;
SELECT @@session.sql_mode;
SELECT @@global.sql_mode;


SHOW VARIABLES LIKE 'sql_mode';
```

```sql
ONLY_FULL_GROUP_BY,
STRICT_TRANS_TABLES,          # 开启了严格模式
NO_ZERO_IN_DATE,
NO_ZERO_DATE,
ERROR_FOR_DIVISION_BY_ZERO,
NO_ENGINE_SUBSTITUTION
```

| --                    | --                                         |
| --------------------- | ------------------------------------------ |
| `STRICT_TRANS_TABLES` | 对**支持事务**的存储引擎进行严格的数据检查 |
| `STRICT_TRANS_TABLES` | 对**所有**存储引擎都进行严格检查           |



### 宽松模式

- 自动转换数据
- 截断数据
- 使用默认值
- 使用隐式值

```sql
# 开启宽松模式
SET SESSION sql_mode = '';
```



### 严格模式

数据必须符合字段定义，否则直接报错

```sql
CREATE TABLE users (
    name VARCHAR(5)
);

# 严格模式下直接报错；宽松模式下会自动截断，使用 12345 存进去，然后报 Warning
INSERT INTO users VALUES ('123456');
```



```sql
# 开启会话严格模式（默认是严格模式）
SET SESSION sql_mode = 'STRICT_TRANS_TABLES';

# 修改全局，新建会话生效，sql_mode 并不仅仅包含 STRICT_TRANS_TABLES 记得配置全
SET GLOBAL sql_mode = 'STRICT_TRANS_TABLES';
```

```sql
# 修改 MySQL 配置文件，重启 MySQL 生效
sql_mode=ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION
```
