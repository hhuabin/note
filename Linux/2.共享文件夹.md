# 开启共享文件夹

1. 虚拟机中需要配置开启共享文件夹

   `centOS` 关机
   
   ```
   VM -> 设置(Settings) -> 选项(Options) -> 共享文件夹(Shared Folders) -> 添加共享文件夹
   ```
   



## CentOS

1. 安装 `open-vm-tools` 和 `fuse` 工具

   ```bash
   sudo dnf install -y open-vm-tools open-vm-tools-desktop fuse3
   ```

   说明：

   - `open-vm-tools`：VMware 官方开源工具
   - `open-vm-tools-desktop`：桌面环境支持（建议装）
   - `fuse3`：新版本系统通常是 fuse3，不一定叫 fuse

2. 启动 `Open VMware Tools` 服务并设置服务**开机自启**

   ```bash
   sudo systemctl enable --now vmtoolsd
   ```

   ```shell
   systemctl status vmtoolsd      # 检查状态
   ```

3. 使用 `vmhgfs-fuse` 挂载共享文件夹（临时挂载）

   ```bash
   sudo vmhgfs-fuse .host:/ /mnt/hgfs
   ```

   ```shell
   sudo vmhgfs-fuse .host:/ /mnt/hgfs -o allow_other       # 允许虚拟机上的非 root 用户也能访问共享文件夹
   ```

4. 验证共享文件夹

   ```bash
   ls /mnt/hgfs/
   ```



## 开机自动挂载共享文件夹

1. 方式1（确保 `vmtoolsd` 是开机自启状态）

   ```shell
   sudo vim /etc/fstab
   ```

   在文件中追加

   ```shell
   .host:/    /mnt/hgfs    fuse.vmhgfs-fuse    defaults,allow_other,_netdev    0 0
   ```

   重新加载

   ```shell
   sudo systemctl daemon-reload
   ```

   验证

   ```shell
   sudo mount -a
   # 正常是没有输出，有输出即报错，需要重新配置
   ```

2. 方式2

   1. 先卸载当前手动挂载

       ```shell
       fusermount3 -u /mnt/hgfs
       ```

       如果提示找不到 `fusermount3`：

       ```shell
       fusermount -u /mnt/hgfs
       ```

   2. 创建 systemd 服务

       ```shell
       sudo vi /etc/systemd/system/vmware-share.service
       ```

       写入：

       ```shell
       [Unit]
       Description=VMware Shared Folder
       After=vmtoolsd.service
       Requires=vmtoolsd.service
       
       [Service]
       Type=oneshot
       ExecStart=/usr/bin/vmhgfs-fuse .host:/ /mnt/hgfs -o allow_other,uid=1000,gid=1000
       ExecStop=/usr/bin/fusermount3 -u /mnt/hgfs
       RemainAfterExit=yes
       
       [Install]
       WantedBy=multi-user.target
       ```

   3. 重新加载 systemd

       ```shell
       sudo systemctl daemon-reload
       ```

       然后启用：

       ```shell
       sudo systemctl enable vmware-share.service
       ```

       启动：

       ```shell
       sudo systemctl start vmware-share.service
       ```

       检查：

       ```shell
       systemctl status vmware-share.service
       ```

       然后：

       ```shell
       ls -la /mnt/hgfs
       ```
