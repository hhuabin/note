# 二、搜索与跳转

`Windows` 风格

| 功能                                         | 快捷键                              | `idea` 位置                                                  |
| -------------------------------------------- | ----------------------------------- | ------------------------------------------------------------ |
| 全局搜索                                     | `Shift` + `Shift`（`Double Shift`） |                                                              |
| 跳转到声明                                   | `Ctrl + B`                          | 右键 -> `Go To` -> `Declaration or Usages`                   |
| 选择下一个相同内容（`VScode` 的 `Ctrl + D`） | `Alt + J`                           | `Select Next Occurrence`<br />可以配多一个快捷键`Ctrl + D`，然后把原来移除掉<br />`idea` 的 `Ctrl + D` 默认是复制一行 `Duplicate Line or Selection`<br />可以将 `Duplicate Line or Selection` 改为 `Ctrl + Alt + 下箭头` |
|                                              |                                     |                                                              |
|                                              |                                     |                                                              |
|                                              |                                     |                                                              |
|                                              |                                     |                                                              |
|                                              |                                     |                                                              |
|                                              |                                     |                                                              |
