# 一、动态 `SQL`

[Mybatis 动态 sql](https://mybatis.org/mybatis-3/zh_CN/dynamic-sql.html "dynamic-sql")

动态 `SQL` 是 `MyBatis` 的强大特性之一

```xml
<!--
    动态SQL 多条件查询
    if: 通过 test 属性中的表达式判断标签中的内容是否生效
    where:
        若标签中的内容成立会自动添加 where 关键字
        去掉标签中 内容前的 and 关键字
    trim:
        prefix, suffix: 在标签中前面后后面添加指定内容
        prefixOverrides, suffixOverrides: 在标签中前面后后面删除指定内容
    choose, when, otherwise
        相当于 if ... else ...
        when设置至少一个 otherwise最多一个。最终只有一条语句生效
    foreach
        collection: 循环的集合
        item: 集合个体
        separator: 循环间的分隔符
        open: 循环内容的开头
        close: 循环内容的结尾
    sql: 可以记录一段 sql
        id: 唯一标识
        <include refid="empColumns"> 使用
 -->
```



## 1.1 `<if>` 和 `<where>` 标签

1.  `<if>`：可以有选择的加入 `SQL` 语句的片段

    -   `test` 属性：内部做比较运算，结果为 `true` 拼接标签内的 `sql`

    ```xml
    <!-- List<Employee> getEmployeeByCondition(Employee employee); -->
    <select id="getEmployeeByCondition" resultType="com.mybatis.bean.Employee">
        SELECT * FROM t_emp
        WHERE
        <if test="empId > 0">
            emp_id = #{empId}
        </if>
        <if test="empName != null and empName != ''">
            AND emp_name = #{empName}
        </if>
    </select>
    ```

    >   问题：如果第一个条件满足，第二个条件不满足，`sql` 语句会出现 `WHERE AND` 的情况，这时候可以使用 `<where>` 标签

2.  `<where>`：自动添加 `WHERE` 关键字

    -   `where` 标签会自动去掉标签体内前面多余的 `AND/ OR`
    -   如果 `<where>` 标签里没有满足的条件，则不会添加 `WHERE` 关键字

    ```xml
    <!-- List<Employee> getEmployeeByCondition(Employee employee); -->
    <select id="getEmployeeByCondition" resultType="com.mybatis.bean.Employee">
        SELECT * FROM t_emp
        <where>
            <if test="empId > 0">
                emp_id = #{empId}
            </if>
            <if test="empName != null and empName != ''">
                AND emp_name = #{empName}
            </if>
        </where>
    </select>
    ```

    ```java
    public void selectEmployeeByCondition() {
        SqlSession sqlSession = SqlSessionUtil.getSqlSession();
        DynamicSQLMapper mapper = sqlSession.getMapper(DynamicSQLMapper.class);
    
        Employee employee = new Employee();
        // 如果 empId 小于0，mybatis 会自动删除多余的 AND
        employee.setEmpId(3);
        employee.setEmpName("bin");
    
        List<Employee> employeeList = mapper.getEmployeeByCondition(employee);
    
        sqlSession.close();
        employeeList.forEach(System.out::println);
    }
    ```



## 1.2 `UPDATE` 的 `<set>` 标签

`<set>`：自动添加 `SET` 关键字

-   动态去掉两端多余的逗号

```xml
<!-- void updateEmployee(Employee employee); -->
<update id="updateEmployee">
    UPDATE t_emp
    <set>
        <if test="empName != null">
            emp_name = #{empName},
        </if>
        <if test="empSalary &lt; 3000">
            emp_salary = #{empSalary},
        </if>
    </set>
    WHERE emp_id = #{empId}
</update>
```

>   只是使用 `<if>` 两边可能会出现多余的 `,`，所以需要 `<set>`



## 1.3 `<trim>` 控制 `sql` 两端字符

`<trim>`：控制条件部分两端是否包含哪些字符（有需要可以使用它代替 `<WHERE>` 和 `<SET>`）

-   `prefix`、` suffix`：在标签中前面、后面添加指定内容
-   `prefixOverrides`，`suffixOverrides`：在标签中前面、后面删除指定内容

```xml
<!-- List<Employee> getEmployeeByCondition(Employee employee); -->
<select id="getEmployeeByCondition" resultType="com.mybatis.bean.Employee">
    SELECT * FROM t_emp
    <!-- 给条件语句添加 WHERE 前缀，删除 AND | OR 前缀 -->
    <trim prefix="WHERE" prefixOverrides="AND | OR">
        <if test="empId > 0">
            emp_id = #{empId}
        </if>
        <if test="empName != null and empName != ''">
            AND emp_name = #{empName}
        </if>
    </trim>
</select>
```



## 1.4 `<choose>`、`<when>`、`<otherwise>` 组合

在多个条件分支中，仅执行一个。相当于 `if ... else ...`

`<choose>`：从上到下匹配，取第一个满足条件的

-   `<when>`：`when` 设置至少一个
-   `<otherwise>`：`otherwise` 最多一个

```xml
<!-- 如果姓名不为 null 使用姓名查询，如果姓名为 null，薪水不为空就使用薪水查询，都为 null 查询全部 -->
<!-- List<Employee> getEmployeeByCondition(Employee employee); -->
<select id="getEmployeeByCondition" resultType="com.mybatis.bean.Employee">
    SELECT * FROM t_emp
    WHERE
    <choose>
        <!-- 如果 empId != null，使用 emp_id = #{empId} -->
        <when test="empId != null">
            emp_id = #{empId}
        </when>
        <!-- 上一个条件判断失败，才会进行下一个 <when> 的判断 -->
        <when test="empName != null and empName != ''">
            emp_name = #{empName}
        </when>
        <!-- <when> 标签都失败，使用 <otherwise> -->
        <otherwise>
            1 = 1
        </otherwise>
    </choose>
</select>
```



## 1.5 `<foreach>` 遍历标签

`<foreach>` 标签核心作用是**遍历集合或数组，动态拼接 `SQL` 片段**，最典型的场景是构建 `IN` 条件或批量插入的 `VALUES` 列表。它能自动处理分隔符，避免产生多余的逗号

- `collection`：遍历的数组
- `item`：数组里的个体
- `separator`：循环间的分隔符
- `open`：循环内容的开头
- `close`：循环内容的结尾

---

1.   举例1

     ```xml
     <!-- int insertEmployees(@Param("employees") List<Employee> employees); -->
     <insert id="insertEmployees">
         INSERT INTO t_emp (emp_name, emp_salary)
         VALUES
         <foreach collection="employees" item="employee" separator=",">
             (#{employee.empName}, #{employee.empSalary})
         </foreach>
     </insert>
     ```

     ```java
     @Test
     public void insertEmployeeList() {
         SqlSession sqlSession = SqlSessionUtil.getSqlSession();
         DynamicSQLMapper mapper = sqlSession.getMapper(DynamicSQLMapper.class);
     
         ArrayList<Employee> employees = new ArrayList<>();
     
         Employee employee1 = new Employee("bin1", 10.0);
         Employee employee2 = new Employee("bin2", 20.0);
         employees.add(employee1);
         employees.add(employee2);
     
         int i = mapper.insertEmployees(employees);
         sqlSession.close();
         
         System.out.println("result = " + i);
     
     }
     ```

2.   举例2

     ```xml
     <select id="selectUsersByIds" resultType="User">
         SELECT * FROM users
         WHERE id IN
         <foreach collection="ids" item="id" open="(" close=")" separator=",">
             #{id}
         </foreach>
     </select>
     ```

3.   举例3

     ```xml
     <!-- UPDATE users SET status=1, update_time=NOW() WHERE id IN (1,2,3) -->
     <update id="updateStatusByIds">
         UPDATE users
         SET status = #{status}, update_time = NOW()
         WHERE id IN
         <foreach collection="ids" item="id" open="(" separator="," close=")">
             #{id}
         </foreach>
     </update>
     ```

4.   极端条件下可以遍历执行多条 `sql` 语句

     执行多条 `sql` 需开启 `allowMultiQueries`

     ```yaml
     # 在配置文件的 数据库 url 中添加 ?allowMultiQueries=true
     spring:
       datasource:
         url: jdbc:mysql://localhost:3306/ssm?allowMultiQueries=true
     ```

     ```xml
     <update id="batchUpdateUsers2">
         <foreach collection="list" item="user" separator=";">
             UPDATE users
             SET name = #{user.name}, age = #{user.age}
             WHERE id = #{user.id}
         </foreach>
     </update>
     ```

     生成多条 `UPDATE` 语句

     ```sql
     UPDATE users SET name='张三', age=20 WHERE id=1;
     UPDATE users SET name='李四', age=22 WHERE id=2;
     ```

     



## 1.6 `sql` 片段

可以记录一段 `sql`

`<sql>`：定义 `SQL` 片段

-   `id`：片段的唯一标识，供 `<include refid>` 引用。同一个命名空间内不能重复

` <include>`：引用片段

-   `refid`：指定要引用的 `<sql>` 片段的 `id`。如果片段定义在**其他 `Mapper` 命名空间**中，需要写全限定名，如 `refid="com.example.UserMapper.userColumns"`
-   `<property>` 子标签：可选，用于向片段内传参。配合片段中的 `${}` 占位符使用，可以实现片段的动态化

```xml
<!-- 定义 SQL 片段-->
<sql id="selectt_emp">
    SELECT * FROM t_emp
</sql>

<!-- SELECT * FROM t_emp WHERE emp_id = #{empId} -->
<select id="getEmployeeByCondition" resultType="com.mybatis.bean.Employee">
    <include refid="selectt_emp"></include>
    WHERE emp_id = #{empId}
</select>
```

带参数的片段：

```xml
<sql id="orderByClause">
    <!-- `${}` 是直接拼接，`column`/`direction` 若来自外部输入会有 SQL 注入风险，务必用白名单校验 -->
    ORDER BY ${column} ${direction}
</sql>

<!-- SELECT * FROM users ORDER BY create_time DESC -->
<select id="selectUsers" resultType="User">
    SELECT * FROM users
    <include refid="orderByClause">
        <property name="column" value="create_time"/>
        <property name="direction" value="DESC"/>
    </include>
</select>
```
