# 一、`Mybatis` 多表映射

`MyBatis` 多表映射主要解决的是"一个实体里包含另一个实体或实体集合"的映射问题，核心是 `<resultMap>` 里的 `<association>`（一对一/多对一） 和 `<collection>`（一对多）

- `<association>`：处理多对一映射；如一个订单只对应一个用户
- `<collection>`：处理一对多映射；如一个用户有多个订单

| 用户 |      | 订单 |
| :--: | :--: | :--: |
|  1   | -->  |  多  |
|  1   | <--  |  1   |



## 1.1 `association`（关联） 对一映射

将 `Customer` 赋值给 `Order.customer`

1.   准备实体类

     ```java
     public class Customer {
         private Integer customerId;
         private String customerName;
         private List<Order> orderList;       // 体现的是对多的关系；一个用户有多个订单
     }
     
     public class Order {
         private Integer orderId;
         private String orderName;
         private Integer customerId;
         private Customer customer;           // 体现的是对一的关系；一个订单只对应一个用户
     }
     ```

2.   创建 `Mapper`，需要使用 `resultMap`

     ```xml
     <mapper namespace="com.mybatis.mapper.OrderMapper">
         <resultMap id="orderMap" type="com.mybatis.bean.Order">
             <id column="order_id" property="orderId"/>
             <result column="order_name" property="orderName"/>
             <result column="customer_id" property="customerId"/>
     
             <!--
                 association 关联：对一的关系
                  - property：Order类 的属性名
                  - javaType：类的全限定符
              -->
             <association property="customer" javaType="com.mybatis.bean.Customer">
                 <id column="customer_id" property="customerId"/>
                 <result column="customer_name" property="customerName"/>
             </association>
         </resultMap>
     
         <!-- Order queryOrderById(Integer orderId); -->
         <select id="queryOrderById" resultMap="orderMap">
             SELECT * FROM t_order
             JOIN t_customer ON t_order.customer_id = t_customer.customer_id
             WHERE t_order.order_id = #{orderId};
         </select>
     </mapper>
     ```

3.   调用 `Mapper`

     ```java
     Order order = orderMapper.queryOrderById(1);
     
     System.out.println("order = " + order);
     
     // order = Order{orderId=1, orderName='o1', customerId=1, customer=Customer{customerId=1, customerName='c01', orderList=null}}
     ```



## 1.2 `collection`（集合） 对多映射

赋值给 `Customer.orderList`

1.   准备实体类（看上面）

2.   创建 `Mapper`，需要使用 `resultMap`

     ```xml
     <mapper namespace="com.mybatis.mapper.CustomerMapper">
         <resultMap id="customerMap" type="com.mybatis.bean.Customer">
             <id column="customer_id" property="customerId"/>
             <result column="customer_name" property="customerName"/>
             <!--
                 collection 集合：对多的关系
                  - property: Customer类 的属性名
                  - ofType: 类的全限定符
              -->
             <collection property="orderList" ofType="com.mybatis.bean.Order">
                 <id column="order_id" property="orderId"/>
                 <result column="order_name" property="orderName"/>
                 <result column="customer_id" property="customerId"/>
             </collection>
         </resultMap>
     
         <!-- Customer queryList(); -->
         <select id="queryList" resultMap="customerMap">
             SELECT * FROM t_order
             JOIN t_customer
             ON t_order.customer_id = t_customer.customer_id
         </select>
     </mapper>
     ```

3.   调用 `Mapper`

     ```java
     Customer customer = customerMapper.queryList();
     
     System.out.println("customer = " + customer);
     
     // customer = Customer{customerId=1, customerName='c01', orderList=[Order{orderId=1, orderName='o1', customerId=1, customer=null}, Order{orderId=2, orderName='o2', customerId=1, customer=null}, Order{orderId=3, orderName='o3', customerId=1, customer=null}]}
     ```



## 1.3 `autoMappingBehavior` 自动映射列到字段或属性

[settings 官方文档](https://mybatis.org/mybatis-3/zh_CN/configuration.html#settings "settings")

```xml
<settings>
    <!-- 开启驼峰映射 -->
    <setting name="mapUnderscoreToCamelCase" value="true"/>
    <!-- 自动映射列到字段或属性 -->
    <setting name="autoMappingBehavior" value="PARTIAL"/>
</settings>
```

`autoMappingBehavior`：指定 `MyBatis` 应如何自动映射列到字段或属性。可以省略 `<resultMap>` 标签中与 数据库列名 同名的 `<result>`

1.   `NONE`：表示关闭自动映射

2.   `PARTIAL`：默认值；只会自动映射没有定义嵌套结果映射的字段。（带有（`association`、`collection`）的 `<resultMap>` 映射不了）

     ```xml
     <resultMap id="orderMap" type="com.mybatis.bean.Order">
         <id column="order_id" property="orderId"/>
         <result column="order_name" property="orderName"/>
         <result column="customer_id" property="customerId"/>
     </resultMap>
     
     <!--
     	<setting name="mapUnderscoreToCamelCase" value="true"/>
     	<setting name="autoMappingBehavior" value="PARTIAL"/>
      -->
     <!-- value="PARTIAL"：省略只有一层 resultMap 的 result -->
     <resultMap id="orderMap" type="com.mybatis.bean.Order">
         <id column="order_id" property="orderId"/>
     </resultMap>
     ```

3.   `FULL`：会自动映射任何复杂的结果集（无论是否嵌套）

     ```xml
     <resultMap id="orderMap" type="com.mybatis.bean.Order">
         <id column="order_id" property="orderId"/>
         <result column="order_name" property="orderName"/>
         <result column="customer_id" property="customerId"/>
     
         <association property="customer" javaType="com.mybatis.bean.Customer">
             <id column="customer_id" property="customerId"/>
             <result column="customer_name" property="customerName"/>
         </association>
     </resultMap>
     
     <!--
     	<setting name="mapUnderscoreToCamelCase" value="true"/>
     	<setting name="autoMappingBehavior" value="FULL"/>
      -->
     <!-- value="FULL"：省略 resultMap 带有 association、collection 的 result -->
     <resultMap id="orderMap" type="com.mybatis.bean.Order">
         <id column="order_id" property="orderId"/>
     
         <association property="customer" javaType="com.mybatis.bean.Customer">
             <id column="customer_id" property="customerId"/>
         </association>
     </resultMap>
     ```



## 1.4 分布查询 可以配合延迟加载进行 `sql` 性能提升

使用 `<association/>` 标签

-   `property`：实体类的属性名
-   `fetchType`：`eager` | `lazy` 立即加载 | 延迟加载
-   `select`：设置分布查询的 `sql` 唯一标识
-   `column`：将查询出的某个字段作为分布查询的 `sql` 条件

```xml
<resultMap id="deptAndEmpResultMap" type="Dept">
    <id column="dept_id" property="deptId"></id>
    <result column="dept_name" property="deptName"></result>
    <collection property="emps" ofType="Emp">
        <id column="emp_id" property="empId"></id>
        <result column="emp_name" property="empName"></result>
        <result column="age" property="age"></result>
        <result column="gender" property="gender"></result>
    </collection>
    <!--<association property="emps" fetchType="lazy"
                 select="com.mybatis.mapper.EmpMapper.getEmpByDeptId"
                 column="dept_id"></association>-->
</resultMap>

<!--Dept getDeptAndEmpByDeptId(@Param("deptId") Integer deptId);-->
<select id="getDeptAndEmpByDeptId" resultMap="deptAndEmpResultMap">
    SELECT * FROM t_dept
    LEFT JOIN t_emp ON t_dept.dept_id = t_emp.dept_id
    WHERE t_dept.dept_id = #{deptId}
</select>
<!--分布查询-->
<!--<select id="getDeptAndEmpByDeptId" resultMap="deptAndEmpResultMap">
    SELECT * FROM t_dept WHERE t_dept.dept_id = #{deptId}
</select>-->
```
