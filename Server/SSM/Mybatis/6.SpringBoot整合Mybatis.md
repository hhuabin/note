# `SpringBoot` 整合 `MyBatis`

### 1. 添加 `Maven` 依赖

```xml
<!-- MyBatis Spring Boot Starter -->
<dependency>
    <groupId>org.mybatis.spring.boot</groupId>
    <artifactId>mybatis-spring-boot-starter</artifactId>
    <version>2.3.2</version>
</dependency>

<!-- MySQL 驱动 -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>${mysql.version}</version>
</dependency>
```

| `Starter` 版本 | `Spring Boot` | `Java`     |
| -------------- | ------------- | ---------- |
| 2.3.x          | 2.7.x         | `Java 8+`  |
| 3.0.x          | 3.2～3.5      | `Java 17+` |
| 4.0.x          | 4.0.x         | `Java 17+` |



### 2. 在 `application.yml` 配置文件指定 `xml` 文件位置等

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/springboot2?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: 123456

mybatis:
  # Mapper XML 文件位置
  mapper-locations: classpath:mapper/**/*.xml

  # 实体类包路径（配置后 XML 中可以直接使用类名）
  type-aliases-package: com.springboot2.entity
  # 多个实体类包使用 ',' 分隔，如下
  # type-aliases-package: com.springboot2.entity,com.springboot2.module.user.entity,com.springboot2.module.order.entity

  configuration:
    # 数据库字段下划线自动映射 Java 驼峰属性
    map-underscore-to-camel-case: true

    # 开启 SQL 日志
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```

>   如果项目实体包都统一放在 `entity` 目录下，也可以使用通配符指定实体包
>
>   ```yaml
>   mybatis:
>     type-aliases-package: com.springboot2.**.entity
>   ```

```tex
src/main/resources
│
├── application.yml
│
└── mapper
    └── UserMapper.xml     # Mapper.xml 文件的位置由 mapper-locations 指定
```

| 配置                           | 作用                       |
| ------------------------------ | -------------------------- |
| `mapper-locations`             | 指定 `Mapper XML` 文件位置 |
| `type-aliases-package`         | 指定实体类包路径           |
| `map-underscore-to-camel-case` | 开启下划线转驼峰           |
| `log-impl`                     | 指定 `SQL` 日志实现        |



### 3. 配置 `Mapper` 扫描

1.   使用 `@Mapper`

     ```java
     @Mapper
     public interface UserMapper {
     
         User selectUserById(Long userId);
     
     }
     ```

2.   在 `Spring Boot` 启动类上添加 `@MapperScan`

     >   其实比较多还是使用 `@Mapper` 单独指定

     ```java
     package com.springboot2;
     
     import org.mybatis.spring.annotation.MapperScan;
     import org.springframework.boot.SpringApplication;
     import org.springframework.boot.autoconfigure.SpringBootApplication;
     
     @SpringBootApplication
     @MapperScan("com.springboot2.mapper")
     public class SpringBoot2Application {
     
         public static void main(String[] args) {
             SpringApplication.run(SpringBoot2Application.class, args);
         }
     
     }
     ```

     `@MapperScan` 的作用：

     -   指定 `Mapper` 接口所在的包
     -   自动扫描该包下的 `Mapper` 接口
     -   将 `Mapper` 接口注册为 `Spring Bean`

     这样就不需要在每个 `Mapper` 接口上单独添加 `@Mapper` 注解

3.   针对项目中有多个 `mapper` 包

     ```java
     // @MapperScan 指定多个包
     @MapperScan(basePackages = {
         "com.springboot2.mapper",
         "com.springboot2.module.user.mapper",
         "com.springboot2.module.order.mapper"
     })
     
     // 使用通配符指定多个包（使用这个方式更好）
     @MapperScan("com.springboot2.**.mapper")
     ```



### 4. 分页查询

1.   引入分页插件

     ```xml
     <dependency>
         <groupId>com.github.pagehelper</groupId>
         <artifactId>pagehelper-spring-boot-starter</artifactId>
         <version>1.4.7</version>
     </dependency>
     ```

2.   在 `application.yml` 中配置

     ```yaml
     pagehelper:
       helper-dialect: mysql
       reasonable: true
       support-methods-arguments: true
     ```

     | 配置项                      | 作用                                              |
     | --------------------------- | ------------------------------------------------- |
     | `helper-dialect`            | 指定数据库方言                                    |
     | `reasonable`                | 页码小于 1 时查询第一页，大于总页数时查询最后一页 |
     | `support-methods-arguments` | 支持从 `Mapper` 方法参数中读取分页参数            |

3.   `Service` 层调用

     ```java
     @Service
     public class UserInfoService {
     
         @Autowired
         private UserInfoMapper userInfoMapper;
     
         public PageInfo<UserInfo> getUserList(Integer pageNum, Integer pageSize) {
     
             // 开始分页
             PageHelper.startPage(pageNum, pageSize);
     
             // 执行查询（PageHelper 会拦截紧接着的查询）
             List<UserInfo> list = userInfoMapper.selectUserList();
     
             // 封装分页结果
             return new PageInfo<>(list);
         }
     }
     ```

     >   `xml` 的 `sql` 语句不要以 `;` 结尾，原理就是在 `sql` 语句后面追加 `limit`
