# 一、`Spring IoC` / `DI` 实践步骤

>   组件交给 `Spring IoC`容器管理，并且获取和使用的基本步骤

1. 导入相关依赖

   ```xml
   <!-- Spring-context -->
   <dependency>
       <groupId>org.springframework</groupId>
       <artifactId>spring-context</artifactId>
       <version>6.0.6</version>
   </dependency>
   
   <!-- junit测试 -->
   <dependency>
       <groupId>org.junit.jupiter</groupId>
       <artifactId>junit-jupiter-api</artifactId>
       <version>5.3.1</version>
   </dependency>
   ```

2. 通过 `xml` 配置组件

   ```xml
   // springioc.xml / ***.xml
   <?xml version="1.0" encoding="UTF-8"?>
   <beans xmlns="http://www.springframework.org/schema/beans"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
   
       <!-- 一个 bean 一个组件（默认是单例） -->
       <bean id="helloBean" class="com.springioc.bean.HelloBean"></bean>
   
   </beans>
   ```

   `<bean />` 标签 == 组件信息声明

   -   `id`：属性是标识单个 `Bean` 定义的字符串
   -   `class`：属性定义 `Bean` 的类型并使用完全限定的类名

3. 通过 `XML` 格式的配置文件实例化 `IoC` 容器

   我们应该选择一个合适的容器实现类，进行 `IoC` 容器的实例化工作

   ```java
   // 实例化 IoC 容器
   ApplicationContext ioc = new ClassPathXmlApplicationContext("springioc.xml");
   ```

4. 从容器中获取 `Bean`（组件）

   `ApplicationContext` 是一个高级工厂的接口，能够维护不同 `bean` 及其依赖项的注册表。通过使用方法 `T getBean(String name, Class<T> requiredType)` ，您可以检索 `bean` 的实例

   ```java
   // 实例化 IoC 容器
   ApplicationContext applicationContext = new ClassPathXmlApplicationContext("springioc.xml");
   
   // 获取 IOC 容器中的 bean
   HelloBean helloBean = (HelloBean) applicationContext.getBean("helloBean");
   
   // 使用组件对象
   helloBean.sayHello();
   ```



# 二、基于 `XML` 配置方式组件管理

## 2.1 `Bean` 的三种实例化方式

| 实例化方式               | 核心属性                         | 方法类型    | 是否需要工厂对象 |
| ------------------------ | -------------------------------- | ----------- | ---------------- |
| 构造函数实例化（最常见） | `class`                          | 构造方法    | 不需要           |
| 静态工厂方法             | `class`、`factory-method`        | `static`    | 不需要           |
| 实例工厂方法             | `factory-bean`、`factory-method` | 非 `static` | 需要             |

1.   无参构造函数实例化组件（最常见）

     通过反射调用 `Bean` 类的无参构造方法创建对象

     ```java
     public class UserDao {
     
         // 无参构造方法
         public UserDao() {
             System.out.println("通过无参构造方法创建 UserDao");
         }
     
         public void getUser() {
             System.out.println("查询用户");
         }
     }
     ```

     ```xml
     <!--
         方式 1: 无参构造函数实例化组件
           - id: 唯一标识，方便以后获取 Bean
           - class: 类的全限定符
           - scope: singleton | prototype
             - singleton: 单例模式 （默认）
             - prototype: 多例模式
      -->
     <bean id="userDao1" class="com.springioc.dao.UserDao" scope="singleton"></bean>
     ```

2.   静态工厂方法实例化

     通过调用工厂类中的静态方法创建 `Bean`

     ```java
     // 创建工厂类，提供静态方法
     public class UserDaoFactory {
     
         public static UserDao createInstance() {
             return new UserDao();
         }
     }
     ```

     ```xml
     <!--
         方式 2: 静态工厂方法实例化
           - id：组件标识
           - class：工厂类的全限定符
           - factory-method：静态工厂方法
      -->
     <bean id="userDao2" class="com.springioc.factory.UserDaoFactory" factory-method="createInstance"></bean>
     ```

3.   实例工厂方法实例化

     通过普通工厂对象调用非静态方法创建 `Bean`

     ```java
     public class UserDaoFactory {
     
         public UserDao createInstance() {
             return new UserDao();
         }
     }
     ```

     ```xml
     <!--
         方式 3：实例工厂方法实例化
           - id：Bean 的唯一标识
           - factory-bean：工厂 Bean 的 id
           - factory-method：工厂对象中的实例方法名
      -->
     <!-- 创建工厂对象 -->
     <bean id="userDaoFactory" class="com.springioc.factory.UserDaoFactory"></bean>
     
     <bean id="userDao3" factory-bean="userDaoFactory" factory-method="createInstance"></bean>
     ```



## 2.2 `Bean` 的依赖注入(`DI`)方式

>   `Spring` 创建对象之后，如何给对象的属性赋值，以及如何注入其他 `Bean` ？

```java
// 准备类 UserDao
public class UserDao {

    public UserDao() {}

    public void getUser() {
        System.out.println("查询用户");
    }
}
```

1. `Setter` 注入 :star:

    需要提供 无参构造函数（实例化要用） 和 `Setter` 方法（注入）

    ```java
    public class UserService {
    
        private String username;
        private UserDao userDao;
        
        // 需要提供无参构造函数
        public UserService() {}
    
        public void setUsername(String username) {
            this.username = username;
        }
    
        public void setUserDao(UserDao userDao) {
            this.userDao = userDao;
        }
    }
    ```

    ```xml
    <bean id="userDao" class="com.springioc.dao.UserDao"/>
    
    <bean id="userService" class="com.springioc.service.UserService">
    
        <!-- 注入普通属性 -->
        <property name="username" value="bin"/>
    
        <!-- 注入引用类型 -->
        <property name="userDao" ref="userDao"/>
    
    </bean>
    ```

    `value` 和 `ref` 的区别：

    | 属性    | 作用            | 示例                   |
    | ------- | --------------- | ---------------------- |
    | `value` | 注入普通值      | 字符串、数字、布尔值等 |
    | `ref`   | 引用其他 `Bean` | 注入 `UserDao` 对象    |

2.  构造器注入

    通过 构造方法 为对象属性赋值

    ```java
    public class UserService {
    
        private String username;
        private UserDao userDao;
    
        public UserService() {}
    
        public UserService(String username, UserDao userDao) {
            this.username = username;
            this.userDao = userDao;
        }
    }
    ```

    ```xml
    <bean id="userDao" class="com.springioc.dao.UserDao"/>
    
    <bean id="userService" class="com.springioc.service.UserService">
    
        <!--
            constructor-arg：构造参数传值
         -->
        <constructor-arg name="username" value="bin"/>
        <constructor-arg name="userDao" ref="userDao"/>
    
    </bean>
    ```

3. 集合类型注入

    ```java
    public class UserService {
    
        private List<String> names;
        private Set<String> roles;
        private Map<String, String> config;
        private Properties properties;
    
        public void setNames(List<String> names) {
            this.names = names;
        }
    
        public void setRoles(Set<String> roles) {
            this.roles = roles;
        }
    
        public void setConfig(Map<String, String> config) {
            this.config = config;
        }
    
        public void setProperties(Properties properties) {
            this.properties = properties;
        }
    }
    ```

    ```xml
    <bean id="userService" class="com.springioc.service.UserService">
    
        <!-- List 集合 -->
        <property name="names">
            <list>
                <value>张三</value>
                <value>李四</value>
            </list>
        </property>
    
        <!-- Set 集合 -->
        <property name="roles">
            <set>
                <value>admin</value>
                <value>user</value>
            </set>
        </property>
    
        <!-- Map 集合 -->
        <property name="config">
            <map>
                <entry key="username" value="bin"/>
                <entry key="password" value="123456"/>
            </map>
        </property>
    
        <!-- Properties 集合 -->
        <property name="properties">
            <props>
                <prop key="driver">com.mysql.cj.jdbc.Driver</prop>
                <prop key="url">jdbc:mysql://localhost:3306/test</prop>
            </props>
        </property>
    
    </bean>



## 2.3 `IoC` 容器的创建和使用

`XML` 中声明的 `Bean`，只是告诉 `Spring` 如何创建和管理 `Bean`，还需要创建 `IoC` 容器，让 `Spring` 加载这些配置



### 2.3.1 创建 `IoC` 容器

| 容器实现类                        | 配置文件位置 | 使用场景         |
| --------------------------------- | ------------ | ---------------- |
| `ClassPathXmlApplicationContext`  | `classpath`  | 项目内部配置文件 |
| `FileSystemXmlApplicationContext` | 文件系统路径 | 外部配置文件     |

1.   `ClassPathXmlApplicationContext`

     从项目的类路径（`classpath`）中加载 `XML` 配置文件

     ```java
     // 从 classpath 加载 spring.xml
     ApplicationContext context = new ClassPathXmlApplicationContext("springioc.xml");
     
     // 获取 IoC 容器中的 bean
     UserService userService = context.getBean("userService1", UserService.class);
     // 使用 userService
     System.out.println(userService.getUsername());
     ```

     ```java
     // 先创建 IoC 容器对象，再指定配置文件，然后刷新
     ClassPathXmlApplicationContext context = new ClassPathXmlApplicationContext();
     // 指定配置文件
     context.setConfigLocations("springioc.xml");
     // 刷新
     context.refresh();
     ```

2.   `FileSystemXmlApplicationContext`

     ```java
     // 从文件系统加载 XML 配置文件
     ApplicationContext context = new FileSystemXmlApplicationContext("D:/spring/config/spring.xml");
     ```



### 2.3.2 获取 `Bean`

创建 `IoC` 容器之后，可以通过 `getBean()` 获取容器中的 `Bean`

```xml
<bean id="userDao" class="com.springioc.dao.UserDao"/>
```

1.   根据 `id` 获取

     ```java
     UserDao userDao = (UserDao) context.getBean("userDao");
     ```

     需要手动进行类型转换

2.   根据 `id` 和类型获取（推荐）

     ```java
     UserDao userDao = context.getBean("userDao", UserDao.class);
     
     // 使用 userService
     System.out.println(userService.getUsername());
     ```

     不需要手动类型转换，类型更加明确

3.   根据类型获取（`@Autowired`）

     ```java
     UserDao userDao = context.getBean(UserDao.class);
     ```

     >   注意：如果容器中存在多个 `UserDao` 类型的 `Bean`，就可能出现 `NoUniqueBeanDefinitionException` 异常

---

>   判断 `Bean` 是否存在
>
>   ```java
>   // 判断 Bean 是否存在
>   boolean exists = context.containsBean("userDao");
>   
>   // 判断 Bean 是否为单例
>   boolean singleton = context.isSingleton("userDao");
>   
>   // 判断 Bean 是否为多例
>   boolean prototype = context.isPrototype("userDao");
>   ```



## 2.4 组件生命周期方法

我们可以在组件类中定义方法，然后当 **`IoC` 容器实例化**和**销毁组件对象**的时候进行调用！这两个方法我们成为**生命周期方法**！类似于 `Servlet` 的 `init / destroy` 方法,我们可以在周期方法完成初始化和释放资源等工作

1.   创建 `init / destory` 方法

     周期方法要求： 方法命名随意，但是要求方法必须是 `public void` 无形参列表

     ```java
     public class UserDao {
     
         public UserDao() {}
     
         // 周期方法要求： 方法命名随意，但是要求方法必须是 public void 无形参列表
         public void init() {
             System.out.println("UserDao init");
         }
     
         public void destory() {
             System.out.println("UserDao destory");
         }
     }
     
     ```

2.   在 `xml` 文件中声明 `init-method` 和 `destroy-method`

     ```xml
     <bean id="userDao" class="com.springioc.dao.UserDao" init-method="init" destroy-method="destory"></bean>
     ```

     ```java
     @Test
     public void testLifeCycle() {
         // 获取 IOC 容器
         ClassPathXmlApplicationContext applicationContext = new ClassPathXmlApplicationContext("springioc2.xml");
     
         // 销毁
         applicationContext.close();
     }
     ```



## 2.5 作用域 `Scope`（单例 | 多例）

>   我们一般都使用单例的

`<bean/>` 标签声明 `Bean`，只是将 `Bean` 的信息配置给 `SpringIoC` 容器！在 `IoC` 容器中，这些`<bean/>`标签对应的信息转成 `Spring` 内部 `BeanDefinition` 对象（感觉类似于虚拟 `DOM` 对象），`BeanDefinition` 对象内，包含定义的信息（ `id`、`class` 属性等等）！

这意味着，`BeanDefinition`与 `类` 概念一样，`Spring IoC` 容器可以可以根据 `BeanDefinition` 对象反射创建多个 `Bean` 对象实例。具体创建多少个 `Bean` 的实例对象，由 `Bean` 的作用域 `Scope` 属性指定！

```xml
<!--
    scope: singleton | prototype
        singleton: 单例模式 （默认）
        prototype: 多例模式
-->
<bean id="userDao" class="com.springioc.dao.UserDao" scope="prototype"></bean>
```

```java
@Test
public void testScope() {
    // 获取 IOC 容器
    ApplicationContext applicationContext = new ClassPathXmlApplicationContext("springioc2.xml");
    // 获取 IOC 容器中的 bean
    UserDao userDao1 = (UserDao) applicationContext.getBean(UserDao.class);
    UserDao userDao2 = (UserDao) applicationContext.getBean(UserDao.class);
    System.out.println(userDao1 == userDao2);     // false
}
```



## 2.6 `FactoryBean<T>` 工厂接口

`FactoryBean` 的核心作用是通过工厂 `Bean` 创建并向 `Spring` 容器提供另一个对象

`FactoryBean<T>` 是 `Spring` 提供的一个工厂接口，位于 `org.springframework.beans.factory.FactoryBean`

`FactoryBean` 接口提供三种方法：

| 方法              | 作用                         |
| ----------------- | ---------------------------- |
| `getObject()`     | 创建并返回实际 `Bean` 对象   |
| `getObjectType()` | 返回实际 `Bean` 对象的类型   |
| `isSingleton()`   | 指定工厂创建的对象是否为单例 |



### 2.6.1 `FactoryBean` 使用示例

1. 定义 `UserDao`

   ```java
   public class UserDao {
   
       public void getUser() {
           System.out.println("查询用户");
       }
   }
   ```

2. 创建 `UserDaoFactory`

   ```java
   package com.springioc.factory;
   
   public class UserDaoFactory implements FactoryBean<UserDao> {
   
       @Override
       public UserDao getObject() {
           System.out.println("FactoryBean 创建 UserDao");
   
           return new UserDao();
       }
   
       @Override
       public Class<?> getObjectType() {
           return UserDao.class;
       }
   
       @Override
       public boolean isSingleton() {
           return true;
       }
   }
   ```

3. `xml` 配置

   ```xml
   <bean id="userDao" class="com.springioc.factory.UserDaoFactory"/>
   ```

   注意：这里配置的 `class` 是 `UserDaoFactory`，不是 `UserDao`

4. 测试读取 `FactoryBean` 和 `FactoryBean.getObject` 对象

   ```java
   @Test
   public void testFactoryBean() {
       ApplicationContext applicationContext = new ClassPathXmlApplicationContext("springioc2.xml");
   
       // 获取 UserDao Bean (FactoryBean.getObject)
       UserDao userDao = applicationContext.getBean("userDao", UserDao.class);
       System.out.println(userDao);
       userDao.getUser();
   
       // 如果想要获取 FactoryBean对象, 直接在 id 前添加&符号即可!  &helloBean 这是一种固定的约束
       Object userDaoFactoryBean = applicationContext.getBean("&userDaoFactory");
       System.out.println(userDaoFactoryBean);
   }
   ```

   

### 2.6.2 `FactoryBean` 和 `BeanFactory` 区别

-   [`BeanFactory`](./1.Spring与SpringFramework.md#3.2.2 `SpringIoc` 容器具体接口和实现类 "BeanFactory") 是 `IoC` 容器本身（管理 `Bean` 的工厂）
-   `FactoryBean` 是一种特殊的 `Bean`（用于创建其他 `Bean` 的工厂）

| 对比项       | `BeanFactory`                                      | `FactoryBean`                                                |
| :----------- | :------------------------------------------------- | :----------------------------------------------------------- |
| **本质**     | `Spring IoC` 容器的顶层接口                        | 一个普通 `Bean`，但实现了 `FactoryBean` 接口                 |
| **职责**     | 管理、创建、获取所有 Bean                          | 封装复杂对象的创建逻辑                                       |
| **获取对象** | `getBean("xxx")` 直接返回 Bean 实例                | `getBean("&xxx")` 返回 `FactoryBean` 本身；`getBean("xxx")` 返回其 `getObject()` 产物 |
| **典型实现** | `DefaultListableBeanFactory`、`ApplicationContext` | `SqlSessionFactoryBean`、`MapperFactoryBean`                 |



## 2.7 基于 `XML` 的方式整合三层架构组件

>   了解三层架构即可，其他的用不到

基于 `XML` 整合三层架构的核心思路是：将所有层（`Dao`、`Service`、`Controller`）的实例创建和依赖关系，都交给 `Spring` 的 `applicationContext.xml` 来管理。各层代码本身不负责查找或创建依赖，而是通过 `setter` 方法等待容器注入

1. 增加依赖

   ```xml
   <!-- 数据库驱动 -->
   <dependency>
       <groupId>mysql</groupId>
       <artifactId>mysql-connector-java</artifactId>
       <version>8.0.31</version>
   </dependency>
   
   <!-- druid 连接池 -->
   <dependency>
       <groupId>com.alibaba</groupId>
       <artifactId>druid</artifactId>
       <version>1.2.8</version>
   </dependency>
   
   <!-- spring-jdbc -->
   <dependency>
       <groupId>org.springframework</groupId>
       <artifactId>spring-jdbc</artifactId>
       <version>6.0.6</version>
   </dependency>
   ```

2. 分别注入 `jdbcTemplate`、`userDao`、`userService` 即可

   ```xml
   <!--
       引入 jdbc.properties
       然后就可以通过 ${key} 的方式获得 value
   -->
   <context:property-placeholder location="classpath:jdbc.properties"></context:property-placeholder>
   
   <!--druid 数据库连接池-->
   <bean id="dataSource" class="com.alibaba.druid.pool.DruidDataSource">
       <property name="driverClassName" value="${jdbc.driver}"></property>
       <property name="url" value="${jdbc.url}"></property>
       <property name="username" value="${jdbc.user}"></property>
       <property name="password" value="${jdbc.password}"></property>
   </bean>
   
   <bean id="jdbcTemplate" class="org.springframework.jdbc.core.JdbcTemplate">
       <property name="dataSource" ref="dataSource"></property>
   </bean>
   
   <bean id="userDao" class="com.springioc.dao.impl.UserDaoImpl">
       <property name="jdbcTemplate" ref="jdbcTemplate" />
   </bean>
   
   <bean id="userService" class="com.springioc.service.impl.UserServiceImpl">
       <property name="userDao" ref="userDao" />
   </bean>
   
   <bean id="userController" class="com.springioc.controller.UserController">
       <property name="userService" ref="userService" />
   </bean>
   ```

3. 查询语句

   ```java
   public void testGetAllUser(){
   
       ApplicationContext applicationContext = new ClassPathXmlApplicationContext("spring-jdbc.xml");
   
       JdbcTemplate jdbcTemplate = applicationContext.getBean(JdbcTemplate.class);
   
       String sql = "SELECT * FROM ssm_user";
   
       List<User> userList = jdbcTemplate.query(sql, new BeanPropertyRowMapper<>(User.class));
   
       System.out.println("userList = " + userList);
   
       // 插入操作
       String insertSql = "insert into ssm_user values(null, ?, ?, ?, ?, ?)";
       jdbcTemplate.update(insertSql, "root", "123", 24, "男", "77777@qq.com");
   }
   ```
