# 一、注解使用

| 注解          | 说明                                                         |
| ------------- | ------------------------------------------------------------ |
| `@Component`  | 该注解用于描述 `Spring` 中的 `Bean`，它是一个泛化的概念，仅仅表示容器中的一个组件（`Bean`），并且可以作用在应用的任何层次，例如 `Service` 层、`Dao` 层等。 使用时只需将该注解标注在相应类上即可 |
| `@Repository` | 该注解用于将数据访问层（`Dao` 层）的类标识为 `Spring` 中的 `Bean`，其功能与 `@Component` 相同 |
| `@Service`    | 该注解通常作用在业务层（`Service` 层），用于将业务层的类标识为 `Spring` 中的 `Bean`，其功能与 `@Component` 相同 |
| `@Controller` | 该注解通常作用在控制层（如 `SpringMVC` 的 `Controller`），用于将控制层的类标识为 `Spring` 中的 `Bean`，其功能与 `@Component` 相同 |
|               |                                                              |
| `@Autowired`  | 按**类型**自动装配 `Spring` 容器中的 `Bean`，用于对象依赖注入 |
| `@Value`      | 为字段或方法参数注入外部配置值                               |

> `@Controller`、`@Service`、`@Repository` 这三个注解只是在`@Component`注解的基础上起了三个新的名字，所以 `@Controller`、`@Service`、`@Repository` 这三个注解只是给开发人员看的，让我们能够便于分辨组件的作用。



## 1.1 `@Component` 组件注解

1.   给类加上 `@Component` 组件注解

     ```java
     @Component
     public class User {
     
         private Integer id;
         private String username;
     
         public User() {
         }
     
         public Integer getId() {
             return id;
         }
     
         public void setId(Integer id) {
             this.id = id;
         }
     
         public String getUsername() {
             return username;
         }
     
         public void setUsername(String username) {
             this.username = username;
         }
     }
     ```

2.   在 `xml` 配置扫描范围

     >   扫描还是需要用到 `xml` 配置文件

     ```xml
     <!--
         component-scan 扫描组件
           - exclude-filter 排除扫描
               - type：annotation | assignable
                   - annotation: 根据 注解类型 过滤
                   - assignable: 根据 类的类型 过滤
           - include-filter 指定包含扫描, 需要设置 use-default-filters="false"
      -->
     <context:component-scan base-package="com.springioc">
         <!-- 排除所有 @Controller 注解的类 -->
         <!-- <context:exclude-filter type="annotation" expression="org.springframework.stereotype.Controller"/> -->
     
         <!-- 排除 UserController 这个类 -->
         <!-- <context:exclude-filter type="assignable" expression="com.spring.controller.UserController"/> -->
     
         <!-- 指定包含扫描：指定包含扫描；必须配合 use-default-filters="false" 使用，否则不生效 -->
         <!-- 只扫描 @Controller 注解的类 -->
         <!-- <context:include-filter type="annotation" expression="org.springframework.stereotype.Controller"/> -->
     </context:component-scan>
     ```

3.   使用 `Bean` 组件

     ```java
     @Test
     public  void testAnnotationBean(){
         ApplicationContext context = new ClassPathXmlApplicationContext("spring-ioc-annotation.xml");
         User user = context.getBean("user", User.class);
     
         System.out.println(user);
         System.out.println(user.getUsername());
     }
     ```



## 1.2 `Bean` 的 `id`

1.   默认 `id`：类名首字母小写就是 `Bean` 的 `id`

     例如：`UserController` 类对应的 `Bean` 的 `id` 就是 `userController`

     ```java
     @Component    // id = userController
     public class UserController {
     }
     ```

2.   自定义组件 `id`

     使用 `value` 属性自定义

     ```java
     @Component(value = "userController")
     // @Component("userController")    // 只有一个 value 的时候可以省略
     public class UserController {
     }
     ```



# 二、组件的生命周期方法

| 注解             | 作用                       | 标注位置 |
| :--------------- | :------------------------- | :------- |
| `@PostConstruct` | 注解方式指定**初始化方法** | 方法上   |
| `@PreDestroy`    | 注解方式指定**销毁方法**   | 方法上   |

```java
@Component
public class UserService {

    // 周期方法要求： 方法命名随意，但是要求方法必须是 public void 无形参列表
    @PostConstruct
    public void init() {
        System.out.println("初始化：@PostConstruct");
    }

    @PreDestroy
    public void destroy() {
        System.out.println("销毁：@PreDestroy");
    }
}
```

```java
@Test
public void testLifeCycle() {
    // 获取 IOC 容器
    ClassPathXmlApplicationContext applicationContext = new ClassPathXmlApplicationContext("spring-ioc-annotation.xml");

    // 销毁
    applicationContext.close();
}
```



# 三、作用域 `Scope`

| 对比项   | `singleton`   | `prototype`         |
| :------- | :------------ | :------------------ |
| 实例数量 | 容器内仅 1 个 | 每次 getBean 都新建 |

-   `@Scope(ConfigurableBeanFactory.SCOPE_SINGLETON) / @Scope("singleton")`：单例，默认值
-   `@Scope(ConfigurableBeanFactory.SCOPE_PROTOTYPE) / @Scope("prototype")`：多例

```java
@Component
@Scope(ConfigurableBeanFactory.SCOPE_SINGLETON)
public class UserService {
}
```

```java
@Test
public void testScope() {
    ApplicationContext context = new ClassPathXmlApplicationContext("spring-ioc-annotation.xml");

    UserService userService1 = context.getBean(UserService.class);
    UserService userService2 = context.getBean(UserService.class);

    System.out.println(userService1 == userService2);
}
```



# 四、`Bean` 属性赋值 :star:

## 4.1 `@Autowired` 赋值引用类型

```java
import org.springframework.beans.factory.annotation.Autowired;
```

1. 属性注入（字段注入）

   直接在成员变量上使用 `@Autowired`（最常用）

   ```java
   @Service
   public class UserService {
   
       @Autowired
       private UserDao userDao;
   
       public void getUser() {
           userDao.findUser();
       }
   }
   ```

2. `Setter` 方法注入

   在 `Setter` 方法上使用 `@Autowired`

   ```java
   @Service
   public class UserService {
   
       private UserDao userDao;
   
       @Autowired
       public void setUserDao(UserDao userDao) {
           this.userDao = userDao;
       }
   
       public void getUser() {
           userDao.findUser();
       }
   }
   ```

3. 构造器注入 ⭐推荐

   在构造方法上使用 `@Autowired`

   ```java
   @Service
   public class UserService {
   
       private final UserDao userDao;
   
       @Autowired
       public UserService(UserDao userDao) {
           this.userDao = userDao;
       }
   
       public void getUser() {
           userDao.findUser();
       }
   }
   ```



## 4.2 赋值基本类型

### 4.2.1 直接赋值

1.   `Java` 直接声明并赋值

     ```java
     @Component
     public class UserService {
     
         private String username = "bin";
         
         private Integer age = 18;
     
     }
     ```

2.   构造器直接声明

     在 `Spring` 中使用构造器注入时，通常推荐将必需依赖声明为 `final`；这样可以保证 `UserDao` 在对象创建时就完成注入，之后不能被重新赋值

     ```java
     @Component
     public class UserService {
     
         private final String username;
     
         public UserService() {
             this.username = "bin";
         }
     }
     ```



### 4.2.2 `@Value` 注解赋值

1.   直接赋值

     >   这个没必要用，用上面那个就行

     ```java
     @Component
     public class UserService {
     
         @Value("bin")
         private String username;
     
         @Value("18")
         private Integer age;
     }
     ```

2.   `Setter` 方法赋值

     ```java
     @Component
     public class UserService {
     
         private String username;
     
         @Value("bin")
         public void setUsername(String username) {
             this.username = username;
         }
     }
     ```

3.   构造器赋值

     ```java
     @Component
     public class UserService {
     
         private final String username;
     
         public UserService(@Value("bin") String username) {
             this.username = username;
         }
     }
     ```

4.   读取配置文件赋值

     创建 `properties` 配置文件

     ```properties
     # jdbc.properties
     jdbc.user = root
     jdbc.password = hhuabin
     jdbc.url = jdbc:mysql://localhost:3306/ssm
     jdbc.driver=com.mysql.cj.jdbc.Driver
     ```

     加载配置文件

     ```xml
     <context:property-placeholder location="classpath:jdbc.properties"/>
     ```

     使用 `@Value` 读取配置

     ```java
     @Component
     public class UserService {
     
         @Value("${jdbc.username}")
         private String username;
     
         @Value("${jdbc.password}")
         private String password;
     
         @Value("${jdbc.url}")
         private String url;
     }
     ```

     这里的 `${}` 表示从 `Spring` 的属性配置中读取对应的配置项

5.   `@Value("${配置项:默认值}")`

     如果配置文件中不存在对应属性，可以设置默认值

     ```java
     @Value("${jdbc.username:root}")
     private String username;
     ```
