# 一、`SpringBoot` 整合 `AOP`

`Spring Boot` 通过 `spring-boot-starter-aop` 整合 `Spring AOP`，主要用于日志记录、权限校验、操作审计、性能监控等场景

1.   添加 `Maven` 依赖

     ```xml
     <!-- Spring Boot AOP -->
     <dependency>
         <groupId>org.springframework.boot</groupId>
         <artifactId>spring-boot-starter-aop</artifactId>
     </dependency>
     ```

     >   `Spring Boot` 会自动管理 `AOP` 相关依赖版本，无须单独指定版本

2.   配置 `AOP`

     一般情况下不需要额外配置，`Spring Boot` 会自动启用 `AOP` 自动配置。

     如果需要手动指定，可以使用：

     ```yaml
     spring:
       aop:
         auto: true
         proxy-target-class: true
     ```

     | 配置                            | 作用                                   |
     | ------------------------------- | -------------------------------------- |
     | `spring.aop.auto`               | 是否启用 `AOP` 自动代理，默认 `true`   |
     | `spring.aop.proxy-target-class` | 是否优先使用 `CGLIB` 代理，默认 `true` |

3.   创建切面类

     ```java
     package com.springboot2.common.aspect;
     
     import org.aspectj.lang.annotation.Aspect;
     import org.aspectj.lang.annotation.Before;
     import org.springframework.stereotype.Component;
     
     @Aspect
     @Component
     public class LogAspect {
     
         /**
          * 前置通知
          */
         @Before("execution(* com.springboot2.controller.*.*(..))")
         public void before() {
             System.out.println("请求开始执行");
         }
     
     }
     ```

     | 注解              | 名称     | 执行时机       |
     | ----------------- | -------- | -------------- |
     | `@Aspect`         | 切面     | 声明切面类     |
     | `@Before`         | 前置通知 | 方法执行前     |
     | `@After`          | 后置通知 | 方法执行后     |
     | `@AfterReturning` | 返回通知 | 方法正常返回后 |
     | `@AfterThrowing`  | 异常通知 | 方法抛出异常后 |
     | `@Around`         | 环绕通知 | 方法执行前后   |



# 二、`SpringBoot` 整合 `Tx`

`Spring Boot` 通过 `Spring JDBC` 事务管理机制整合事务功能

对于 `MyBatis` 项目，`Spring Boot` 会自动配置事务管理器，无须额外引入事务依赖

如果没有数据库访问依赖，可以整合添加

1.   添加 `Maven` 依赖

     ```xml
     <!-- Spring JDBC -->
     <dependency>
         <groupId>org.springframework.boot</groupId>
         <artifactId>spring-boot-starter-jdbc</artifactId>
     </dependency>
     ```

2.   配置事务管理

     `Spring Boot` 默认会根据数据源自动配置事务管理器。

     一般不需要手动配置。

     如果需要显式开启事务管理，可以使用：

     ```java
     package com.springboot2.config;
     
     import org.springframework.context.annotation.Configuration;
     import org.springframework.transaction.annotation.EnableTransactionManagement;
     
     @Configuration
     @EnableTransactionManagement
     public class TransactionConfig {
     }
     ```

     >   实际上，`Spring Boot` 默认已经启用了基于注解的事务管理，因此通常不需要再添加 `@EnableTransactionManagement`

3.   使用 `@Transactional`

     在 `Service` 方法上添加 `@Transactional` 注解即可开启事务

     ```java
     @Service
     public class UserServiceImpl implements UserService {
     
         @Resource
         private UserMapper userMapper;
     
         @Transactional(rollbackFor = Exception.class)
         public void createUser(User user) {
     
             // 新增用户
             userMapper.insertUser(user);
     
             // 模拟异常
             int result = 1 / 0;
     
         }
     
     }
     ```

     当方法执行过程中发生异常时，事务会回滚，新增用户操作不会提交

4.   `@Transactional` 常用属性

     | 属性            | 作用                     |
     | --------------- | ------------------------ |
     | `propagation`   | 事务传播行为             |
     | `isolation`     | 事务隔离级别             |
     | `timeout`       | 事务超时时间             |
     | `readOnly`      | 是否为只读事务           |
     | `rollbackFor`   | 指定发生哪些异常时回滚   |
     | `noRollbackFor` | 指定发生哪些异常时不回滚 |

     ```java
     @Transactional(
         propagation = Propagation.REQUIRED,
         isolation = Isolation.DEFAULT,
         timeout = 30,
         readOnly = false,
         rollbackFor = Exception.class
     )
     ```

5.   注意事项

     `@Transactional` 通常用于 `Service` 层，不建议直接放在 `Controller` 层

     默认情况下，只有 `RuntimeException` 和 `Error` 会触发回滚，受检异常默认不回滚

     同一个类内部通过 `this` 调用另一个事务方法，通常不会触发该方法的事务代理

     方法需要通过 `Spring` 管理的代理对象调用，事务才会生效

     `MySQL` 使用事务时，数据表应采用支持事务的存储引擎，例如 `InnoD`
