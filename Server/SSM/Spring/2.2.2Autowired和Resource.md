# 一、`@Autowired`

>   `Spring` 提供，默认按照类型注入

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Qualifier;
```

```java
// @Autowired 源码
@Target({ElementType.CONSTRUCTOR, ElementType.METHOD, ElementType.PARAMETER, ElementType.FIELD, ElementType.ANNOTATION_TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface Autowired {
    boolean required() default true;
}
```



## 1.1 `@Autowired` 依赖查找方式

1.   `@Autowired` 默认按类型（`byType`）注入

     ```java
     @RestController
     public class UserController {
     
         @Autowired
         // 按照 UserService 类型查找
         private UserService userService;
     
     }
     ```

     默认要有一个 `bean`，一个都没有就报错，可以通过设置 `required = false` 允许空注入，但是后续调用直接空指针，错误更危险

     ```java
     // 不推荐使用，会报空指针错误
     @Autowired(required = false)
     ```

2.   如果有多个同类型的 `Bean`（比如有两个 `impl` 实现了同一个 `service`），此时也会报错

     ```java
     @Service
     public class UserServiceImpl implements UserService {
     }
     ```

     ```java
     @Service
     public class UserServiceImpl2 implements UserService {
     }
     ```

     ```java
     @RestController
     public class UserController {
     
         @Autowired
         private UserService userService;
     
     }
     ```

     解决办法：

     1.   按照名称查找

          `Spring` 会先按照 `UserService` 类型寻找，发现有 `userServiceImpl`、`userServiceImpl2`，如果字段名是 `userServiceImpl`，则自动注入 `userServiceImpl`。该方法严重依赖字段名，不建议使用

          ```java
          @Autowired
          // 修改字段名为 userServiceImpl
          private UserService userServiceImpl;
          ```

     2.   :star: ​通过 `@Qualifier` 指定获取 `Bean` 的 `id`；该注解不能单独使用，必须配合 `@Autowired`；使用这个方式 

          ```java
          @Autowired
          @Qualifier(value = "userServiceImpl")
          private UserService userService;
          ```



# 二、`@Resource`

>   `Java` 提供，默认按照名称注入

`@Resource` 需要引入依赖（`SpringBoot 2.7.18` 不需要引入该依赖，`SpringBoot 3` 要）

```xml
<!-- SpringBoot 2.7.18 继承了该依赖的版本，在 SpringBoot 中可以不写版本 -->
<dependency>
    <groupId>jakarta.annotation</groupId>
    <artifactId>jakarta.annotation-api</artifactId>
    <version>1.3.5</version>
</dependency>
```

```java
import jakarta.annotation.Resource;
```

```java
// @Resource 源码
@Target({ElementType.TYPE, ElementType.FIELD, ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
@Repeatable(Resources.class)
public @interface Resource {
    String name() default "";

    String lookup() default "";

    Class<?> type() default Object.class;

    AuthenticationType authenticationType() default Resource.AuthenticationType.CONTAINER;

    boolean shareable() default true;

    String mappedName() default "";

    String description() default "";

    public static enum AuthenticationType {
        CONTAINER,
        APPLICATION;
    }
}
```



##  2.1 `@Resource` 依赖查找方式

1.   `@Resource` 默认按名称（`byName`）注入

     ```java
     @RestController
     public class UserController {
     
         @Resource // 不指定名称就以 字段名(userService) 为名称去查找
         private UserService userService;
     
     }
     ```

     等同于

     ```java
     @RestController
     public class UserController {
     
         @Resource(name = "userService")
         private UserService userService;
     
     }
     ```

2.   指定 `Bean` 类型

     ```java
     @Resource(type = UserService.class)
     private UserService service;
     ```

3.   同时指定 `name + type`（强约束）

     ```java
     @Resource(name = "userServiceImpl", type = UserService.class)
     private UserService userService;
     ```



## 2.2 依赖包

| 对比项              | `javax.annotation.Resource` | `jakarta.annotation.Resource` |
| ------------------- | --------------------------- | ----------------------------- |
| 所属规范            | `Java EE`                   | `Jakarta EE`                  |
| 所属包              | `javax.annotation`          | `jakarta.annotation`          |
| 引入版本            | `Java EE`                   | `Jakarta EE 9`                |
| `Spring Boot 2.7.x` | :star: 推荐                 | 不推荐                        |
| `Spring Boot 3.x`   | 不推荐                      | :star: 推荐                   |
| 注解功能            | 依赖注入                    | 依赖注入                      |



# 三、`@Autowired`、`@Resource` 对比

| 对比项           | `@Autowired`                                   | `@Resource`                           |
| ---------------- | ---------------------------------------------- | ------------------------------------- |
| 所属             | `Spring`                                       | `JDK`（`Java`）                       |
| 所属包           | `org.springframework.beans.factory.annotation` | `javax.annotation`                    |
| 默认注入方式     | 按类型（`byType`）                             | 按名称（`byName`）                    |
| 查找顺序         | 类型 → 字段名/参数名 → `@Qualifier`            | 名称（字段名）→ 类型                  |
| 核心属性         | 只有 `required`（默认 `true`）                 | `name`、`type` 两个属性               |
| 指定名称方式     | 需配合 `@Qualifier("beanName")`                | 直接用 `@Resource(name = "beanName")` |
| 可标注位置       | 构造器、方法、参数、字段、注解                 | 类、字段、方法（通常 `setter`）       |
| 字段注入         | 支持                                           | 支持                                  |
| `Setter` 注入    | 支持                                           | 支持                                  |
| 构造器注入       | 支持                                           | 不支持                                |
| 是否支持可选注入 | `required = false`                             | 不支持                                |
| 默认是否必须注入 | 是                                             | 是                                    |

1.   `@Autowired` 构造器注入（参考）

     ```java
     @Service
     public class UserService {
     
         private final UserMapper userMapper;
     
         // 
         @Autowired
         public UserService(UserMapper userMapper) {
             this.userMapper = userMapper;
         }
     
     }
     ```

2.   `@Resource` 写在类上（较少见）

     ```java
     @Resource(name = "someBean")
     @RestController
     public class UserController { ... }
     ```

     >   标在类上时，`@Resource` 作用于该类**所有需要注入的成员**的默认解析（实际使用很少，了解即可）
