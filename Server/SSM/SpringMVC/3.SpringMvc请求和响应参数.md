# 一、`Spring MVC` 接收请求参数

## 1.1 `Param` 参数接收（`GET`）

### 1.1.1 直接传值

```java
// http://localhost:8080/param/data?name=bin&age=18
@GetMapping("data")
@ResponseBody
public String data(String name, Integer age) {
    if (name == null) name = "";
    if (age == null) age = 0;
    System.out.println("name=" + name + " " + "age=" + age);
    return ("name=" + name + " " + "age=" + age);
}
```

>   缺点：`name` 和 `age` 都可以不传，不会报错，所以要自己判空
>
>   这里最好不要用基本数据类型去接，比如 `public String data(String name, int age)`，万一前端不传 `age` 直接报错（基本数据类型的坑）

用 `@PostMapping` 时，`name`、`age` 这类简单类型参数，`Spring` 会从**请求参数**里找（`URL` 查询串或 `application/x-www-form-urlencoded` 表单体）。如果前端发的是 `application/json`，这两个参数**收不到**，得改用 `@RequestBody` 接收对象或 `Map`

```java
// 前端：Content-Type: application/x-www-form-urlencoded，body: name=bin&age=18
@PostMapping("data")
@ResponseBody
public String data(String name, Integer age) { ... }
```



### 1.1.2 `@RequestParam` 获取 `query` 参数

[`@RequestParam` 获取 `query` 参数](./2.SpringMVC提供的注解.md#6. `@RequestParam` 获取 `query` 参数)

适合 `GET` 请求

```java
@GetMapping("requestParam")
@ResponseBody
public String requestParam(@RequestParam("name") String name,
                           @RequestParam(required = false, defaultValue = "18") Integer age
) {
    System.out.println("name=" + name + " " + "age=" + age);
    return ("name=" + name + " " + "age=" + age);
}
```



### 1.1.3 一名多值（`@RequestParam List<?>` 参数）

```java
// http://localhost:5000/param/mulForm?list=bin&list=18
@GetMapping("mulForm")
@ResponseBody
public String mulForm(@RequestParam List<String> list) {
    System.out.println(list.toString());  // [bin, 18]
    return list.toString();
}
```



### 1.1.4 实体接收 `DTO p`

实体接收，实体类一定要加上 `Setter` 方法，否则赋值不生效

```java
// DTO
@Getter
@Setter
@NoArgsConstructor
@ToString
public class User {
    private String name;

    // 记得使用 Integer 包装数据类型，不然报错报死你
    // name=bin&age= -> 使用 int 就报错
    private Integer age = 18;
}
```

```java
// http://localhost:5000/param/addUser?name=bin&age=18
@GetMapping("addUser")
@ResponseBody
public String addUser(User user) {
    System.out.println("user=" + user);
    return user.toString();
}
```



### 1.1.5 动态路径参数 `@PathVariable`

[`@PathVariable` 获取路径参数](./2.SpringMVC提供的注解.md#5. `@PathVariable` 获取路径参数)

```java
@ResponseBody
@GetMapping("/user/{userid}")
public String testPathVariable(@PathVariable("userid") String userId) {
    System.out.println("userId: " + userId);
    return userId;
}
```



## 1.2 `@RequestBody` `json` 参数接收（`POST`）

1. 加入 `jackson`依赖，`json` 类型处理的工具（在 `Spring Boot` 中无需显示导入）

    `Java` 本身不支持 `json` 格式，只支持 路径参数 和 `param` 参数，`json` 是前端的格式，所以需要导 `jackson` 三方依赖

    ```xml
    <dependency>
        <groupId>com.fasterxml.jackson.core</groupId>
        <artifactId>jackson-databind</artifactId>
        <version>2.15.0</version>
    </dependency>
    ```

2. 配置使用 `@EnableWebMvc` 注解，此注解可代替 `MvcConfig` 下的 `handlerMapping` 和 `handlerAdapter` 方法（`Spring Boot` 中不用再配置）

    ```java
    @EnableWebMvc  // json 数据处理，必须使用此注解，因为他会加入 json 处理器
    @Configuration
    @ComponentScan("com.springmvc")
    public class MvcConfig {
    }
    ```

3. `@RequestBody` 接收 `json` 实体

    ```java
    // 加入 Setter 方法
    @Data
    public class Person {
        private String name;
        private int age;
        private String gender;
    }
    ```

    ```java
    @Controller
    @RequestMapping("json")
    @ResponseBody
    public class JsonController {
    
        @PostMapping("data")
        public String addPerson(@RequestBody Person person) {
            System.out.println("person=" + person.toString());
            return person.toString();
        }
    }
    ```



### `Spring Boot`

`spring-boot-starter-web`，它内部依赖的 `spring-boot-starter-json` 就已经自动包含了 `Jackson`。`Spring Boot` 会自动配置好 `ObjectMapper` 和相关的 `JSON` 消息转换器，让你能直接使用 `@RequestBody` 接收 `JSON` 数据



## 1.3 `@CookieValue` 接收指定 `Cookie`

[`@CookieValue` 获取指定 `Cookie`](./2.SpringMVC提供的注解.md#9. `@CookieValue` 获取指定 `Cookie`)

```java
@Controller
@RequestMapping("cookie")
@ResponseBody
public class CookieController {

    // 取 Cookie
    @GetMapping("data")
    public String data(@CookieValue("username") String username) {
        System.out.println("username=" + username);
        return username;
    }

    // 存 Cookie
    @GetMapping("save")
    public String saveCookie(HttpServletResponse response) {
        Cookie cookie = new Cookie("username", "bin");
        response.addCookie(cookie);
        return "success";
    }
}
```



## 1.4 `@RequestHeader` 接收请求头数据

[`@RequestHeader` 获取请求头](./2.SpringMVC提供的注解.md#8. `@RequestHeader` 获取请求头)

```java
@GetMapping("header")
public String header(@RequestHeader("Host") String host) {
    System.out.println("host=" + host);
    return host;
}
```



## 1.5 `Servlet` 原生 `Api` 获取（`Java Web`）

[Servlet 笔记](../../JavaWeb/Servlet/Servlet.md)

[Method Arguments 方法参数](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann-methods/arguments.html "Spring 官网")

| `API`                 | 作用                                                   |
| --------------------- | ------------------------------------------------------ |
| `HttpServletRequest`  | 获取 `HTTP` 请求信息，例如请求参数、请求头、请求路径等 |
| `HttpServletResponse` | 操作 `HTTP` 响应，例如设置响应头、状态码、输出响应内容 |
| `HttpSession`         | 管理 `HTTP` 会话，例如保存和获取用户会话数据           |
| `ServletContext`      | 应用域对象；获取 `Web` 应用程序的全局上下文信息        |
| `ServletConfig`       | 获取 `Servlet` 的初始化配置信息                        |

这些 `API` 并不是 `Spring MVC` 定义的，而是来自 `Java Servlet API`

```java
@Controller
@RequestMapping("api")
@ResponseBody
public class ApiController {

    // 注入全局 ServletContext（应用域对象）
    @Autowired
    private ServletContext servletContext;

    @GetMapping("http")
    public void api(HttpServletRequest request,       // 请求对象（承载请求域）
                    HttpServletResponse response,     // 响应对象
                    HttpSession session               // 会话对象（承载会话域）
    ) {
        // 通过请求对象获取应用域对象
        ServletContext servletContext1 = request.getServletContext();
        // 通过会话对象获取应用域对象
        ServletContext servletContext2 = session.getServletContext();

        System.out.println(servletContext1 == servletContext2);     // 输出 true
        System.out.println(servletContext == servletContext1);      // 输出 true
    }
}
```



### 1.5.1 三大共享域对象

| 域对象     | 作用范围                           | 对应类型             |
| :--------- | :--------------------------------- | :------------------- |
| **请求域** | 一次请求内                         | `HttpServletRequest` |
| **会话域** | 浏览器的一次会话内（跨多个请求）   | `HttpSession`        |
| **应用域** | 整个项目（所有用户、所有请求共享） | `ServletContext`     |



### 1.5.2 请求域对象操作（往 `request` 域放数据）

>   这几种方式主要用于 `Spring MVC` 的服务端页面渲染（前后端不分离），例如 `JSP`、`Thymeleaf` 等模板引擎
>
>   前后端分离的项目，对于下面的东西理解即可

1.   `Servlet` 提供的操作方式

     ```java
     @Controller
     @RequestMapping("share")
     @ResponseBody
     public class ShareController {
     
         // 应用域对象
         @Autowired
         private ServletContext servletContext;
     
         @GetMapping("request")
         public void request(HttpServletRequest request, HttpSession session) {
             // request 就是请求域啦
         }
     }
     ```

2.   `Spring Mvc` 提供的请求域操作方式：

     -   `Model`
     -   `ModelMap`
     -   `Map`
     -   `ModelAndView`

---

1. `Model`

    ```java
    // Model 往请求域放数据
    public void request(Model model) {
        model.addAttribute("key", "value");
    }
    ```

2. `ModelMap`

    ```java
    // ModelMap 往请求域放数据
    public void request(ModelMap modelMap) {
        modelMap.addAttribute("key", "value");
    }
    ```

3. `Map`

    ```java
    // Map 往请求域放数据
    public void request(Map map) {
        map.put("key", "value");
    }
    ```

4. `ModelAndView`

    ```java
    // ModelAndView 往请求域放数据
    public ModelAndView request() {
        ModelAndView modelAndView = new ModelAndView();
        modelAndView.addObject("key", "value");
        modelAndView.setViewName("视图 / 页面名称");
        return modelAndView;
    }
    ```





# 二、`Spring MVC` 响应参数

## 2.1 `@ResponseBody` 返回 `json` 数据

1. 加入 `jackson` 依赖，`json` 类型处理的工具

    ```xml
    <dependency>
        <groupId>com.fasterxml.jackson.core</groupId>
        <artifactId>jackson-databind</artifactId>
        <version>2.15.0</version>
    </dependency>
    ```

2. 直接返回该对象即可 ==（`User` 实体的 `getter` 和 `setter` 方法一定要写）==

    ```java
    @Data
    public class User {
        private String name;
    
        private int age = 18;
    }
    ```

    ```java
    @RequestMapping("json")
    @RestController     // @Controller + @ResponseBody
    public class jsonController {
        
        @GetMapping("user")
        public User getUser() {
            User user = new User();
            user.setAge(18);
            user.setName("bin");
            System.out.println("user: " + user.toString());
            return user;
        }
    }
    ```




## 2.2 静态资源

```java
@EnableWebMvc  // json 数据处理，必须使用此注解，因为他会加入 json 处理器
@Configuration
@ComponentScan("com.springmvc")
public class MvcConfig implements WebMvcConfigurer {

    // 配置 jsp 视图解析器
    @Override
    public void configureViewResolvers(ViewResolverRegistry registry) {
        registry.jsp("/WEB-INF/views/", ".jsp");
    }

    // 开启静态资源查找
    // handlerMappin g匹配不到的时候就找静态资源
    @Override
    public void configureDefaultServletHandling(DefaultServletHandlerConfigurer configurer) {
        configurer.enable();
    }
}

```



## 2.3 转发和重定向

1. 转发：`forward:***`

    ```java
    @RequestMapping("/forward")
    public String forward() {
        // 转发到 /jsp/index，地址栏是/forward
        return "forward:/jsp/index";
    }
    ```

2. 重定向：`redirect:***`

    ```java
    @RequestMapping("/redirect")
    public String redirect() {
        // 重定向到 /jsp/index。地址栏是/index
        return "redirect:/jsp/index";
    }
    
    // 外部网站
    @RequestMapping("/redirectBilibli")
    public String redirectBilibli() {
        // 重定向到 /jsp/index
        return "redirect:https://www.bilibili.com";
    }
    ```



## 2.4 返回模板视图

>   混合开发专用，前后端分离不用管

1. 导入 `jsp` 页面和依赖（`Spring Boot` 项目不用管）

    ```xml
    <!-- jsp 需要的依赖 -->
    <dependency>
        <groupId>jakarta.servlet.jsp.jstl</groupId>
        <artifactId>jakarta.servlet.jsp.jstl-api</artifactId>
        <version>3.0.0</version>
    </dependency>
    ```

2. 配置 `jsp` 视图解析器

    ```java
    @EnableWebMvc  // json 数据处理，必须使用此注解，因为他会加入 json 处理器
    @Configuration
    @ComponentScan("com.springmvc")
    public class MvcConfig implements WebMvcConfigurer {
    
        // 配置 jsp 视图解析器
        @Override
        public void configureViewResolvers(ViewResolverRegistry registry) {
            registry.jsp("/WEB-INF/views/", ".jsp");
        }
    
        // 开启静态资源查找
        // handlerMappin g匹配不到的时候就找静态资源
        @Override
        public void configureDefaultServletHandling(DefaultServletHandlerConfigurer configurer) {
            configurer.enable();
        }
    }
    
    ```

3. 返回视图

    ```java
    @Controller
    @RequestMapping("jsp")
    public class JspController {
    
        /**
         * @description 快速查找视图
         *  1. 方法返回字符串类型
         *  2. 不能添加 @ResponseBody 注解
         *  3. 返回值：对应视图名称即可
         */
        @RequestMapping("/index")
        public String jumpJsp(HttpServletRequest request) {
            // 往前端视图注入数据
            request.setAttribute("data", "hello jsp!!!");
    
            System.out.println("JspController");
    
            return "index";
        }
    }
    ```
