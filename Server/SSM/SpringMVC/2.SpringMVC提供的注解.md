# `Spring MVC` 注解

这一类注解主要用于定义控制器、请求映射以及 `HTTP` 请求处理方法

1.   `Controller` 层核心注解：

     | 注解              | 作用                                               | 使用说明                                                     |
     | ----------------- | -------------------------------------------------- | ------------------------------------------------------------ |
     | `@Controller`     | 声明控制器                                         | 标记一个类为 `Spring MVC` 控制器，通常返回视图名称           |
     | `@ResponseBody`   | 将返回值写入 `HTTP` 响应体                         | 通常将 `Java` 对象转换为 `JSON`                              |
     | `@RestController` | 统一响应体处理                                     | 相当于 `@Controller + @ResponseBody`<br />类级别的 `@ResponseBody` |
     | `@ResponseStatus` | 指定 `HTTP` 响应状态码                             | 例如 200、201、404                                           |
     |                   |                                                    |                                                              |
     | `@RequestMapping` | 映射请求路径，可以用于类或方法，也可以指定请求方式 | 可以作用于类或方法，指定请求路径、请求方式等                 |
     | `@GetMapping`     | 映射 `GET` 请求                                    | 查询数据                                                     |
     | `@PostMapping`    | 映射 `POST` 请求                                   | 新增数据、提交数据                                           |
     | `@DeleteMapping`  | 映射 `DELETE` 请求                                 | 删除数据                                                     |
     | `@PutMapping`     | 映射 `PUT` 请求                                    | 更新数据                                                     |

2.   请求参数绑定注解：

     | 注解              | 作用                                         | 使用说明              |
     | ----------------- | -------------------------------------------- | --------------------- |
     | `@PathVariable`   | 将 `URL` 路径中的变量 与控制器方法的形参绑定 | `URL` 路径            |
     | `@RequestParam`   | 将 请求参数 与控制器方法的形参绑定           | `URL Query`、表单参数 |
     | `@RequestBody`    | 将 请求体中的 `JSON` 数据 转换为 `Java` 对象 | `HTTP Body`           |
     |                   |                                              |                       |
     | `@RequestHeader`  | 获取 `HTTP` 请求头                           | `HTTP Header`         |
     | `@CookieValue`    | 获取指定 `Cookie`                            | `Cookie`              |
     | `@RequestPart`    | 获取 `multipart` 文件或数据部分              | `Multipart`           |
     | `@ModelAttribute` | 绑定请求参数到 `Java` 对象                   | `Query`、表单参数等   |

3.   异常处理注解

     | 注解                    | 作用                  | 使用说明                                   |
     | ----------------------- | --------------------- | ------------------------------------------ |
     | `@ExceptionHandler`     | 异常处理              | 处理指定类型的异常                         |
     | `@ControllerAdvice`     | 全局控制器增强        | 对多个 `Controller` 生效                   |
     | `@RestControllerAdvice` | `REST` 全局控制器增强 | 相当于 `@ControllerAdvice + @ResponseBody` |

4.   数据校验与数据绑定注解

     | 注解              | 作用                   | 使用说明                           |
     | ----------------- | ---------------------- | ---------------------------------- |
     | `@Valid`          | `Java Bean Validation` | 触发对象字段的级联校验             |
     | `@Validated`      | `Spring`               | 支持数据校验及校验分组             |
     | `@InitBinder`     | `Spring MVC`           | 自定义请求参数绑定、类型转换和校验 |
     | `@ModelAttribute` | `Spring MVC`           | 将请求参数绑定到对象               |

5.   会话及请求属性注解

     | 注解                 | 作用                            | 使用说明     |
     | -------------------- | ------------------------------- | ------------ |
     | `@SessionAttributes` | 将 `Model` 属性保存到 `Session` | 类级别使用   |
     | `@SessionAttribute`  | 获取已有 `Session` 属性         | 方法参数使用 |
     | `@RequestAttribute`  | 获取请求域属性                  | 方法参数使用 |

6.   其他常用注解

     | 注解                    | 作用                  | 使用说明                       |
     | ----------------------- | --------------------- | ------------------------------ |
     | `@CrossOrigin`          | 配置跨域访问          | 可以作用于类或方法             |
     | `@MatrixVariable`       | 获取 `URL` 矩阵变量   | 较少使用                       |
     | `@ControllerAdvice`     | 全局控制器增强        | 可统一配置异常处理、数据绑定等 |
     | `@RestControllerAdvice` | `REST` 全局控制器增强 | 常用于统一异常处理             |



## 1. `@Controller`

`@Controller` 只能加在**类**上

```java
@Controller
@RequestMapping("/user")
public class UserController {

    @RequestMapping("/index")
    public String index() {
        return "index";
    }
}
```

默认情况下，方法返回的字符串会被视为**视图名称**，而不是响应文本



## 2. `@ResponseBody`

`@ResponseBody` 可以加在**类**或**方法**上，声明 `REST` 风格控制器

```java
@Controller
@ResponseBody
// @RestController
@RequestMapping("/user")
public class UserController {

    @GetMapping("/info")
    public UserInfoVO getUserInfo() {
        return new UserInfoVO();
    }
}
```

>   `@RestController` = `@Controller` + `@ResponseBody`，可以使用 `@RestController` 代替两个，就不用写那么多了



## 3. `@ResponseStatus`

指定 `HTTP` 响应状态码

```java
@PostMapping("/create")
@ResponseStatus(HttpStatus.CREATED)
public void createUser() {
    // 创建用户
}
```

响应状态码为 `201 Created`

也可以用于异常类：

```java
@ResponseStatus(HttpStatus.NOT_FOUND)
public class UserNotFoundException extends RuntimeException {

}
```



### `ResponseEntity`

严格来说，`ResponseEntity` 是 `Spring MVC` 提供的响应类型，不是注解

它可以同时设置 `HTTP` 状态码、响应头和响应体

```java
@GetMapping("/info")
public ResponseEntity<UserInfoVO> getUserInfo() {

    UserInfoVO user = new UserInfoVO();

    return ResponseEntity
            .status(HttpStatus.OK)
            .body(user);
}
```





## 4. `@RequestMapping`

定义请求映射，可以作用于**类**和**方法**

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @RequestMapping(
        value = "/info",
        method = RequestMethod.GET
    )
    public UserInfoVO getUserInfo() {
        return new UserInfoVO();
    }
}
```

| 属性       | 作用                      | 示例                                                         |
| ---------- | ------------------------- | ------------------------------------------------------------ |
| `value`    | 请求路径                  | `"/info"`                                                    |
| `path`     | 请求路径，和 `value` 等价 | `"/info"`                                                    |
| `method`   | 请求方式                  | `RequestMethod.GET`、`RequestMethod.POST`<br />可以指定一个或多个，不指定就是任意方法都可以 |
| `params`   | 请求参数匹配条件          | `"id=1"`                                                     |
| `headers`  | 请求头匹配条件            | `"token"`                                                    |
| `consumes` | 限制请求 `Content-Type`   | `"application/json"`                                         |
| `produces` | 指定响应媒体类型          | `"application/json"`                                         |

>   `@GetMapping`、`@PostMapping` 等都是 `@RequestMapping` 的快捷注解
>
>   `@GetMapping`、`@PostMapping` 等只能用在方法上



### `value` / `path`

`value` / `path`：指定请求的 URI 路径。它是数组类型，意味着可以将多个路径映射到同一个方法。支持通配符（`*`、`**`）、占位符（`{name}`）和正则表达式（`{name:regex}`）

1.   `value / path` 可以选择以 `/` 开始：`@RequestMapping("info"` 或者 `@RequestMapping("/info"` 都可以

2.   `value / path` 可以接收多个值

     接收一个：`@RequestMapping("/info")`

     接收多个：`@GetMapping({"/user/list", "/users"})`

3.   `value / path` 支持正则

     -   `?`：匹配路径段中的一个字符
     -   `\*`：匹配路径段中的零个或多个字符（不跨越 `/`）
     -   `\**`：匹配零个或多个路径段（可跨越 `/`），通常用于通配所有子路径，且只能出现在模式末尾
     -   `{name}`：路径变量，匹配一个路径段并捕获为变量，配合 `@PathVariable` 使用
     -   `{name:regex}`：带正则约束的路径变量，只有符合正则的 `URL` 才会匹配
     -   `{\*path}`：匹配剩余的所有路径段并捕获为变量（类似于 `**` 但可获取值）

     ```java
     // 匹配下一层任意的
     @RequestMapping("/files/*")
     
     // 匹配下一层以 .png 结尾的
     @RequestMapping("/image/*.png")
     
     // 匹配多层任意的
     @RequestMapping("/files/**")
     ```



## 5. `@PathVariable` 获取路径参数

获取 `URL` 路径中的参数

```java
// GET /user/info/1001 -> userId = 1001
@GetMapping("/user/info/{userId}")
public BaseResponse<UserInfoVO> getUserInfo(@PathVariable("userId") Long userId) {

    return BaseResponse.success(userService.getUserInfo(userId));
}
```



## `@PathVariable` 获取路径参数6. `@RequestParam` 获取 `query` 参数

获取 `URL Query` 参数或表单参数

```java
// GET /user/list?pageNum=1&pageSize=10&keyword=bin
@GetMapping("/list")
public BaseResponse<?> getUserList(
        @RequestParam("pageNum") Integer pageNum,
        @RequestParam(value = "pageSize", defaultValue = "10") Integer pageSize,
        @RequestParam(value = "keyword", required = false) String keyword) {

    return BaseResponse.success();
}
```

常用属性：

| 属性             | 作用                                                         | 默认值                                          |
| ---------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| `value` / `name` | 指定参数名称                                                 | `@RequestParam Integer age`<br />参数名称 `age` |
| `required`       | 是否必传<br />不传报 400 参数错误异常                        | `true`                                          |
| `defaultValue`   | 设置默认值<br />提供 `defaultValue` 后会隐式地将 `required` 设置为 `false` | 无                                              |

>   注意：`defaultValue` 设置后，即使参数不存在或者值为空，也会使用默认值



## 7. `@RequestBody` 获取请求体

将 `HTTP` 请求体中的 `JSON` 数据转换为 `Java` 对象

```java
@PostMapping("/create")
public BaseResponse<?> createUser(@RequestBody UserCreateDTO request) {

    userService.createUser(request);

    return BaseResponse.success();
}
```

```json
// 前端 json
{
    "userName": "bin",
    "realName": "hhuabin",
    "phone": "13800138000"
}
```

>   `Spring MVC` 会通过 `HttpMessageConverter` 将 `JSON` 转换为 `UserCreateDTO` 对象

常用属性：

| 属性       | 作用           | 默认值 |
| ---------- | -------------- | ------ |
| `required` | 请求体是否必传 | `true` |



## 8. `@RequestHeader` 获取请求头

获取 `HTTP` 请求头

```java
@GetMapping("/info")
public BaseResponse<?> getUserInfo(@RequestHeader("Authorization") String authorization) {

    return BaseResponse.success();
}
```

请求头

```html
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9
```

常用属性：

| 属性             | 作用       | 默认值 |
| ---------------- | ---------- | ------ |
| `value` / `name` | 请求头名称 |        |
| `required`       | 是否必传   | `true` |
| `defaultValue`   | 默认值     |        |



## 9. `@CookieValue` 获取指定 `Cookie`

获取指定 `Cookie`

```java
@GetMapping("/info")
public BaseResponse<?> getUserInfo(@CookieValue("token") String token) {

    return BaseResponse.success();
}
```

常用属性与 `@RequestHeader` 基本一致



## 10. `@RequestPart` 获取 `multipart` 文件部分

获取 `multipart/form-data` 请求中的文件或其他数据部分

```java
@PostMapping("/upload")
public BaseResponse<?> uploadFile(@RequestPart("file") MultipartFile file) {

    return BaseResponse.success();
}
```

前端使用 `FormData` 上传文件

```javascript
const formData = new FormData()
formData.append('file', file)

fetch('/user/upload', {
    method: 'POST',
    body: formData
})
```



## 11. `@ModelAttribute` 参数绑定 `Java` 对象

将请求参数自动绑定到 `Java` 对象，常用于表单提交

```java
// GET /user/search?userName=bin&status=1
@GetMapping("/search")
public BaseResponse<?> search(UserSearchDTO request) {

    return BaseResponse.success();
}
```

也可以显式声明

```java
@GetMapping("/search")
public BaseResponse<?> search(@ModelAttribute UserSearchDTO request) {

    return BaseResponse.success();
}
```

>   `@ModelAttribute` 主要用于请求参数绑定，不用于将 `JSON` 请求体反序列化为对象。`JSON` 请求体应该使用 `@RequestBody`



## 12. `@ExceptionHandler` 处理指定异常

处理指定异常

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @GetMapping("/info")
    public BaseResponse<?> getUserInfo() {

        throw new RuntimeException("用户不存在");
    }

    @ExceptionHandler(RuntimeException.class)
    public BaseResponse<?> handleException(RuntimeException e) {

        return BaseResponse.error(e.getMessage());
    }
}
```

这里的异常处理方法只处理当前 `Controller` 范围内的异常。



## 13. `@RestControllerAdvice` 全局异常处理器

定义全局异常处理器

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    public BaseResponse<?> handleException(Exception e) {

        return BaseResponse.error("系统异常");
    }

    @ExceptionHandler(RuntimeException.class)
    public BaseResponse<?> handleRuntimeException(RuntimeException e) {

        return BaseResponse.error(e.getMessage());
    }
}
```

>   项目中通常建议统一使用 `@RestControllerAdvice` 管理全局异常处理。

注意：如果异常处理方法返回统一响应对象，`HTTP` 状态码默认仍可能是 200。需要根据业务情况使用 `ResponseEntity` 或 `@ResponseStatus` 设置真正的 `HTTP` 状态码



## 14. `@Valid` 触发校验

用于触发 `Java Bean Validation` 校验

1.   `DTO`：

     ```java
     public class UserCreateDTO {
     
         @NotBlank(message = "用户名不能为空")
         private String userName;
     
         @NotBlank(message = "手机号不能为空")
         private String phone;
     }
     ```

     >   仅仅定义 `@NotBlank` 并不会自动执行校验，需要通过 `@Valid` 或 `@Validated` 等机制触发

2.   `Controller`：

     ```java
     @PostMapping("/create")
     public BaseResponse<?> createUser(@Valid @RequestBody UserCreateDTO request) {
     
         userService.createUser(request);
     
         return BaseResponse.success();
     }
     ```

     当参数不满足校验条件时，默认会抛出 `MethodArgumentNotValidException`







## 15. `@Validated` 校验分组

`Spring` 提供的校验增强注解，支持校验分组

```java
@PostMapping("/create")
public BaseResponse<?> createUser(@Validated @RequestBody UserCreateDTO request) {

    return BaseResponse.success();
}
```

与 `@Valid` 的主要区别：

| 对比              | `@Valid`               | `@Validated`      |
| ----------------- | ---------------------- | ----------------- |
| 提供方            | `Java Bean Validation` | `Spring`          |
| 基本校验          | 支持                   | 支持              |
| 分组校验          | 支持                   | 支持              |
| `Spring` 方法校验 | 不直接提供             | 可配合 `AOP` 使用 |

注意： `@Valid` 并不是 `Spring MVC` 提供的注解，而是 `Bean Validation` 规范提供的注解。`Spring MVC` 支持识别并处理它



## 16. `@SessionAttributes`

将指定的 `Model` 属性保存到 `HTTP Session`

```java
@Controller
@SessionAttributes("user")
public class UserController {

    @GetMapping("/save")
    public String save(Model model) {

        model.addAttribute("user", "bin");

        return "index";
    }
}
```



## 17. `@SessionAttribute` 获取指定 `Session`

获取 `Session` 中已经存在的属性

```java
@GetMapping("/info")
@ResponseBody
public String getUserInfo(@SessionAttribute("user") String user) {

    return user;
}
```



## 18. `@RequestAttribute`

获取当前 `HTTP` 请求中已经存在的属性

```java
@GetMapping("/info")
public BaseResponse<?> getUserInfo(@RequestAttribute("userId") Long userId) {

    return BaseResponse.success();
}
```

例如，可以由拦截器提前将用户 `ID` 放入 `request`：

```java
request.setAttribute("userId", 1001L);
```

`Controller` 再通过 `@RequestAttribute` 获取。



## 19. `@CrossOrigin` 跨域

配置跨域访问

```java
@RestController
@CrossOrigin(
    origins = "http://localhost:3000",
    methods = {
        RequestMethod.GET,
        RequestMethod.POST
    }
)
@RequestMapping("/user")
public class UserController {

}
```

常用属性：

| 属性               | 作用                                           |
| ------------------ | ---------------------------------------------- |
| `origins`          | 允许访问的源                                   |
| `methods`          | 允许的 `HTTP` 请求方式                         |
| `allowedHeaders`   | 允许的请求头                                   |
| `exposedHeaders`   | 允许前端读取的响应头                           |
| `allowCredentials` | 是否允许携带凭证                               |
| `maxAge`           | 预检请求缓存时间8. `@RequestHeader` 获取请求头 |
