# 一、参数校验

>   [@Valid 笔记](./2.SpringMVC提供的注解.md#14. `@Valid` 触发校验)
>
>   光在 `DTO` 上添加 `@NotBlank` 等校验注解并不会自动执行校验，需要在 `Controller` 参数上添加 `@Valid`，触发参数校验



### 1.1 空值校验

| 注解        | 作用          | 校验规则                                      |
| ----------- | ------------- | --------------------------------------------- |
| `@NotNull`  | 不能为 `null` | 值不能为 `null`                               |
| `@NotEmpty` | 不能为空      | 不能为 `null`，且长度或元素数量必须大于 0     |
| `@NotBlank` | 不能为空白    | 不能为 `null`，且去除空白字符后长度必须大于 0 |

三者的区别：

| 注解        | null   | `""`   | `" "`  | `"abc"` |
| ----------- | ------ | ------ | ------ | ------- |
| `@NotNull`  | 不通过 | 通过   | 通过   | 通过    |
| `@NotEmpty` | 不通过 | 不通过 | 通过   | 通过    |
| `@NotBlank` | 不通过 | 不通过 | 不通过 | 通过    |



### 1.2 长度校验

| 注解    | 作用                                   | 示例                       |
| ------- | -------------------------------------- | -------------------------- |
| `@Size` | 校验字符串、集合、数组的长度或元素数量 | `@Size(min = 2, max = 20)` |

```java
@Size(min = 2, max = 20, message = "用户名长度必须在2-20位")
private String username;
```



### 1.3 数值范围校验

| **注解**          | **作用**           | **示例**                             |
| ----------------- | ------------------ | ------------------------------------ |
| `@Min`            | 最小值             | `@Min(18)`                           |
| `@Max`            | 最大值             | `@Max(100)`                          |
| `@DecimalMin`     | 最小数值，支持小数 | `@DecimalMin("0.5")`                 |
| `@DecimalMax`     | 最大数值，支持小数 | `@DecimalMax("99.9")`                |
| `@Positive`       | 必须大于 0         | `@Positive`                          |
| `@PositiveOrZero` | 必须大于等于 0     | `@PositiveOrZero`                    |
| `@Negative`       | 必须小于 0         | `@Negative`                          |
| `@NegativeOrZero` | 必须小于等于 0     | `@NegativeOrZero`                    |
| `@Digits`         | 限制整数位和小数位 | `@Digits(integer = 8, fraction = 2)` |

```java
@Min(value = 18, message = "年龄不能小于18岁")
@Max(value = 100, message = "年龄不能大于100岁")
private Integer age;
```

```java
@DecimalMin(value = "0.01", message = "金额不能小于0.01")
@DecimalMax(value = "999999.99", message = "金额不能大于999999.99")
private BigDecimal amount;
```

```java
@Digits(integer = 8, fraction = 2, message = "最多8位整数，2位小数")
private BigDecimal price;
```

>   注意：数值范围校验注解通常允许 `null`，必填时需要配合 `@NotNull`



### 1.4 格式校验

| **注解**   | **作用**       | **示例**                   |
| ---------- | -------------- | -------------------------- |
| `@Email`   | 邮箱格式校验   | `@Email`                   |
| `@Pattern` | 正则表达式校验 | `@Pattern(regexp = "...")` |

```java
@Email(message = "邮箱格式不正确")
private String email;
```

```java
@Pattern(
    regexp = "^1[3-9]\\d{9}$",
    message = "手机号格式不正确"
)
private String phone;
```

>   注意：`@Email` 和 `@Pattern` 通常允许 `null`，必填时需要配合 `@NotBlank`



### 1.5 布尔值校验

| **注解**       | **作用**       | **校验规则**     |
| -------------- | -------------- | ---------------- |
| `@AssertTrue`  | 必须为 `true`  | 值必须为 `true`  |
| `@AssertFalse` | 必须为 `false` | 值必须为 `false` |

```java
@AssertTrue(message = "必须同意用户协议")
private Boolean agree;

@AssertFalse(message = "该状态必须为关闭")
private Boolean disabled;
```

>   注意：`null` 默认通过，如果要求必须提供值，需要配合 `@NotNull`



### 1.6 日期校验

| **注解**           | **作用**             | **校验规则**         |
| ------------------ | -------------------- | -------------------- |
| `@Past`            | 必须是过去的日期     | 日期必须早于当前时间 |
| `@PastOrPresent`   | 必须是过去或当前日期 | 日期不能晚于当前时间 |
| `@Future`          | 必须是未来的日期     | 日期必须晚于当前时间 |
| `@FutureOrPresent` | 必须是未来或当前日期 | 日期不能早于当前时间 |

```java
@Past(message = "出生日期必须是过去的时间")
private LocalDate birthday;

@Future(message = "预约时间必须是未来的时间")
private LocalDateTime appointmentTime;
```

注意：日期校验注解通常允许 `null`，必填时需要配合 `@NotNull`



### 1.7 空值校验（必须为空）

| **注解** | **作用**      | **校验规则**    |
| -------- | ------------- | --------------- |
| `@Null`  | 必须为 `null` | 值必须为 `null` |

```java
@Null(message = "新增时用户ID必须为空")
private Long userId;
```



### 1.8 嵌套对象校验

| **注解** | **作用** | **校验规则**                   |
| -------- | -------- | ------------------------------ |
| `@Valid` | 级联校验 | 递归校验对象内部属性的校验规则 |

```java
public class UserDTO {

    @Valid
    @NotNull(message = "地址信息不能为空")
    private AddressDTO address;

}
```

```java
public class AddressDTO {

    @NotBlank(message = "省份不能为空")
    private String province;

    @NotBlank(message = "城市不能为空")
    private String city;

}
```



### 1.9 校验分组

| 注解         | 作用         | 说明                             |
| ------------ | ------------ | -------------------------------- |
| `@Validated` | 指定校验分组 | `Spring` 提供，支持分组校验      |
| `@Valid`     | 触发参数校验 | 支持使用 `groups` 定义的分组规则 |

推荐使用方式：

-   普通 `DTO` 参数校验：`@Valid`
-   需要分组校验：`@Validated`
-   嵌套对象校验：`@Valid`



1.   定义分组：

     ```java
     public interface AddGroup {
     }
     
     public interface UpdateGroup {
     }
     ```

2.   `DTO`：

     ```java
     public class UserDTO {
     
         @Null(groups = AddGroup.class, message = "新增时用户ID必须为空")
         @NotNull(groups = UpdateGroup.class, message = "修改时用户ID不能为空")
         private Long userId;
     
         @NotBlank(
             groups = {AddGroup.class, UpdateGroup.class},
             message = "用户名不能为空"
         )
         private String username;
     
     }
     ```

3.   `Controller`：

     ```java
     @PostMapping("/add")
     public String add(@RequestBody @Validated(AddGroup.class) UserDTO dto) {
         return "新增成功";
     }
     
     @PutMapping("/update")
     public String update(@RequestBody @Validated(UpdateGroup.class) UserDTO dto) {
         return "修改成功";
     }
     ```



# 二、`Spring MVC` 参数校验使用

## 2.1 `SSM` 中使用参数校验

1.   引入依赖

     ```xml
     <!-- 校验注解 -->
     <dependency>
         <groupId>jakarta.platform</groupId>
         <artifactId>jakarta.jakartaee-web-api</artifactId>
         <version>9.1.0</version>
         <scope>provided</scope>
     </dependency>
             
     <!-- 校验注解实现-->        
     <!-- https://mvnrepository.com/artifact/org.hibernate.validator/hibernate-validator -->
     <dependency>
         <groupId>org.hibernate.validator</groupId>
         <artifactId>hibernate-validator</artifactId>
         <version>8.0.0.Final</version>
     </dependency>
     
     <!-- https://mvnrepository.com/artifact/org.hibernate.validator/hibernate-validator-annotation-processor -->
     <dependency>
         <groupId>org.hibernate.validator</groupId>
         <artifactId>hibernate-validator-annotation-processor</artifactId>
         <version>8.0.0.Final</version>
     </dependency>
     ```

2.   应用校验注解

     ```java
     @Data
     public class User {
         @Length(min = 3,max = 10)
         private String name;
     }
     ```

     ```java
     @RestController
     @RequestMapping("user")
     public class UserController {
     
         /**
          * @Validated 代表应用校验注解! 必须添加!
          */
         @PostMapping("save")
         public Object save(@Validated @RequestBody User user,
                            //在实体类参数和 BindingResult 之间不能有任何其他参数, BindingResult可以接受错误信息,避免信息抛出!
                            BindingResult result){
            // 判断是否有信息绑定错误! 有可以自行处理!
             if (result.hasErrors()){
                 System.out.println("错误");
                 String errorMsg = result.getFieldError().toString();
                 return errorMsg;
             }
             // 正常处理业务即可
             System.out.println("正常");
             return user;
         }
     }
     ```

3.   全局异常处理

     ```java
     @ControllerAdvice
     public class GlobalExceptionHandler {
     
         // 加入 MethodArgumentNotValidException 异常处理
         @ExceptionHandler(MethodArgumentNotValidException.class)
         @ResponseBody
         public String handleValidationException(
                 MethodArgumentNotValidException exception) {
     
             String message = exception.getBindingResult()
                     .getFieldError()
                     .getDefaultMessage();
     
             return message;
         }
     }
     ```




## 2.2 `Spring Boot` 中使用参数校验

1.   引入依赖

     `Spring Boot 2.7.18`：

     ```xml
     <dependency>
         <groupId>org.springframework.boot</groupId>
         <artifactId>spring-boot-starter-validation</artifactId>
     </dependency>
     ```

     注意：

     -   `Spring Boot 2.7.18` 使用 `javax.validation`
     -   `Spring Boot 3.x` 使用 `jakarta.validation`

2.   常用导入包

     ```java
     import javax.validation.Valid;
     import javax.validation.constraints.*;
     import org.springframework.validation.BindingResult;
     import org.springframework.validation.annotation.Validated;
     ```

3.   `Controller` 参数校验

     使用 `@Valid` 或 `@Validated` 触发校验：

     ```java
     @PostMapping("/register")
     public String register(@RequestBody @Valid UserRegisterDTO dto) {
     
         return "注册成功";
     }
     ```

4.   获取校验结果

     使用 `BindingResult` 接收校验结果：

     ```java
     @PostMapping("/register")
     public String register(
             @RequestBody @Valid UserRegisterDTO dto,
             BindingResult bindingResult) {
     
         if (bindingResult.hasErrors()) {
             String message = bindingResult.getFieldError().getDefaultMessage();
             return message;
         }
     
         return "注册成功";
     }
     ```

5.   全局异常处理

     ```java
     @RestControllerAdvice
     public class GlobalExceptionHandler {
     
         // 加入 MethodArgumentNotValidException 异常处理
         @ExceptionHandler(MethodArgumentNotValidException.class)
         public BaseResponse<Void> handleValidationException(MethodArgumentNotValidException exception) {
     
             String message = exception.getBindingResult()
                     .getFieldError()
                     .getDefaultMessage();
     
             return BaseResponse.error(message);
         }
     }
     ```
