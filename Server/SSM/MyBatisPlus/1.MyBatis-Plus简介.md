# `MyBatisPlus`

[MyBatis官网](https://mybatis.org/mybatis-3/zh_CN/ "Mybatis")、[MyBatisPlus官网](https://baomidou.com/introduce/ "MyBatisPlus")

`MyBatis-Plus` 是一个 `MyBatis` 的增强工具，在 `MyBatis` 的基础上只做增强不做改变，为简化开发、提高效率而生



1.  **强大的 `CRUD` 操作**：内置通用 `Mapper`、通用 `Service`，仅仅通过少量配置即可实现单表大部分 `CRUD` 操作，更有强大的条件构造器，满足各类使用需求



## 1.1 `Spring Boot` 整合 `MyBatis Plus`

### 1.1.1 引入依赖

1.   `Spring Boot2`


### 1.1.2 在 `application.yml` 配置文件配置数据库等

>   [MybatisPlus 使用配置](https://baomidou.com/reference/ "使用配置")

```yaml
# DataSource Config
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: 123456

mybatis-plus:
  # Mapper XML 文件位置，默认值就是 classpath*:/mapper/**/*.xml
  mapper-locations: classpath*:/mapper/**/*.xml

  # 实体类包路径（配置后 XML 中可以直接使用类名）
  type-aliases-package: com.springboot2.modules.user.info.entity

  configuration:
    # 数据库字段下划线自动映射 Java 驼峰属性（默认开启）
    map-underscore-to-camel-case: true
    # 开启 SQL 日志
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```



### 1.1.3 配置 `Mapper` 扫描

>   参考 `Mybatis`，一样的

1.   使用 `@Mapper`

     在每个 `Mapper` 接口上添加注解：

     ```java
     @Mapper
     public interface UserMapper extends BaseMapper<User> {
     
     }
     ```

2.   使用 `@MapperScan`

     在 `Spring Boot` 启动类上统一配置：

     ```java
     @SpringBootApplication
     @MapperScan("com.springboot2.mapper")
     public class Application {
     
         public static void main(String[] args) {
             SpringApplication.run(Application.class, args);
         }
     
     }
     ```

3.   多个 `mapper` 包的情况

     ```java
     // @MapperScan 指定多个包
     @MapperScan(basePackages = {
         "com.springboot2.mapper",
         "com.springboot2.module.user.mapper",
         "com.springboot2.module.order.mapper"
     })
     
     // 使用通配符指定多个包（使用这个方式更好）
     @MapperScan("com.springboot2.**.mapper")
     ```
     



### 1.1.4 配置插件

```java
@Configuration
public class MybatisPlusConfig {

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {

        // 定义 MybatisPlus 的插件集合
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();

        // 添加分页拦截器
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        
        // 防全表更新、删除插件
        interceptor.addInnerInterceptor(new BlockAttackInnerInterceptor());
        
        // 乐观锁插件
        interceptor.addInnerInterceptor(new OptimisticLockerInnerInterceptor());

        return interceptor;
    }
}
```
