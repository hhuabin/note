# 常见字符串函数 %s

```c
#include <string.h>
```

```c
int strcmp(char *s, char *t);             // 逐个比较字符串 s 和 t 的对应字符，直到字符不相等。全相等返回 0，不相等返回不相等字符串的差值
char * strcat(char *s, char *t);          // 把字符串 t 连接到字符串 s
char * strcpy(char *s, char *t);          // 把字符串 t 复制到字符串 s
unsigned int strlen(char *s);             // 计算字符串 s 的长度
char * strchr(char *s, char c);           // 在字符串 s 中查找字符 c 首次出现的地址
char * strstr(char *s, char *t);          // 在字符串 s 中查找字符串 t 首次出现的地址
```



## 1.`strcmp` 字符串相等

C语言中不能用 `==`（`str1 == str2)`）判定字符串相等，因为 `str1` 和 `str2` 在表达式中会转换成**指针**，`==` 比较的是它们的**地址**，不是字符串内容

```c
strcmp(str1, str2)
```

| 返回值 | 含义               |
| ------ | ------------------ |
| `== 0` | 两个字符串相等     |
| `< 0`  | `str1` 小于 `str2` |
| `> 0`  | `str1` 大于 `str2` |

```c
int main() {
    char str1[] = "hello";
    char str2[] = "hello";

    if (strcmp(str1, str2) == 0) {
        printf("字符串相等\n");
    } else {
        printf("字符串不相等\n");
    }

    return 0;
}
```



## 2.`strcat` 字符串拼接

```c
int main() {
    char s[20] = "Hello ";    // 字符串空间要留够
    char t[] = "World";

    strcat(s, t);

    printf("%s\n", s);        // Hello World

    return 0;
}
```



## 3.`strcpy` 字符串复制

```c
int main() {
    char s[20];
    char t[] = "Hello";

    strcpy(s, t);

    printf("%s\n", s);       // Hello

    return 0;
}
```



## 4. `strlen`获取字符串长度

```c
int main() {
    char s[] = "Hello";

    printf("%zu\n", strlen(s));       // 5，不包含 \0

    return 0;
}
```

## 5.`strchr` 查找字符

在字符串 `s` 中查找字符 `c` **第一次出现的位置**，返回这个字符的**地址**

```c
int main() {
    char s[] = "hello";

    char *p = strchr(s, 'l');

    printf("%s\n", p);          // llo

    return 0;
}
```

```c
char *p = strchr(s, 'x');

if (p != NULL) {
    printf("找到了\n");
} else {
    printf("没找到\n");
}
```



## 6.`strstr` 查找字符串

```c
int main() {
    char s[] = "hello world";
    char t[] = "world";

    char *p = strstr(s, t);

    printf("%s\n", p);

    return 0;
}
```

```c
char s[] = "hello world";

char *p = strstr(s, "java");

if (p != NULL) {
    printf("找到了\n");
} else {
    printf("没找到\n");
}
```
